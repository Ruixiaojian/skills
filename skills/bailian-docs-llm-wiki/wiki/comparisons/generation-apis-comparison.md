# [多模态](../concepts/multi-modal.md)生成能力对比：图像、视频、3D 生成

## 对比目的与背景

随着AIGC技术快速发展，百炼平台已构建覆盖图像、视频、3D三大核心模态的全栈生成能力。开发者在构建创意设计、数字内容生产、虚拟人、电商展示等应用时，常需在不同模态间选型或组合使用。本对比旨在从**工程落地视角**出发，系统梳理三类能力在输入输出、模型生态、调用机制、计费策略及适用边界上的关键差异，帮助技术团队快速识别能力边界、规避常见集成陷阱，并做出符合业务目标与成本效益的技术决策。

## 各方案适用场景建议

### ✅ 图像生成 —— 适合「高频、轻量、强可控」需求  
- **推荐场景**：需要快速产出大量静态视觉内容，且对生成质量、文本遵循度、细节控制（如文字渲染）有明确要求；  
- **优先选用模型**：`qwen-image-3.0-pro`（高保真语义表达）、`wan2.7-image-pro`（4K高清输出）、`z-image-turbo`（低延迟实时交互）；  
- **避坑提示**：避免在V1旧模型（如`wanx-v1`）上新建项目；跨地域密钥不可复用；输入图URL需确保公网可访问且无中文路径。

### ✅ 视频生成 —— 适合「动态叙事、[多模态](../concepts/multi-modal.md)融合、角色驱动」需求  
- **推荐场景**：需生成具备时间维度的内容，尤其涉及动作、语音、镜头语言或人物表现力；  
- **优先选用模型**：`wan2.7-t2v`（多镜头叙事）、`wan2.7-i2v`（首尾帧精准控制）、`liveportrait`（高质量图生播报）；  
- **避坑提示**：所有视频API必须异步调用，轮询间隔建议≥2秒；务必校验Endpoint、API Key、模型三者地域一致性；数字人任务需前置图像检测（如`emo-detect-v1`）。

### ✅ 3D生成 —— 适合「空间建模、工业/游戏/AR应用、结构化输出」需求  
- **推荐场景**：需生成可导入Unity/Unreal/Blender等引擎的标准化3D资产，强调几何拓扑合理性与PBR材质兼容性；  
- **优先选用模型**：`Tripo/Tripo-H3.1`（高精度工业级建模）、`Tripo/Tripo-P1.0`（快速原型验证）；  
- **避坑提示**：**仅限北京地域**，其他地域调用必失败；多图输入必须严格4元素数组（缺位用`{}`）；结果URL有效期仅2小时，需及时下载并持久化存储。

## 面向开发者的选型参考指南

| 选型考量因素 | 推荐决策依据 |
|--------------|--------------|
| **响应时效性要求高（<1s）** | 仅图像生成支持同步调用（`qwen-image-3.0-pro`等），视频/3D必须异步，不适合实时交互类前端应用。 |
| **需多地域部署** | 图像/视频生成支持北京、新加坡、弗吉尼亚等多地；3D生成**仅限北京**，若业务需全球部署，应规划独立3D服务集群或采用边缘缓存策略。 |
| **输入数据以图像为主** | 若已有大量产品图/设计稿：优先评估图生图（图像）→ 图生视频（视频）→ 单图生3D（3D）链路，模型间输入格式复用度高，降低预处理成本。 |
| **输出需直接集成至渲染引擎** | 3D生成原生输出标准GLB，兼容性最佳；视频输出为MP4，需转码适配WebGL播放；图像输出为PNG/JPEG，需自行处理透明通道与DPR适配。 |
| **预算敏感型项目** | 图像生成免费额度最丰厚（500张）；视频任务单价普遍高于图像；3D生成虽单价中等，但H3.1任务耗时长，单位时间成本更高，建议P1.0先行验证再升配。 |
| **合规与内容安全要求严** | 所有模态均默认启用内容安全过滤；图像/视频支持`watermark:true`强制水印；3D生成暂不支持水印，需业务层自行添加模型元数据标识。 |

> **最后提醒**：三类能力虽同属“生成”，但底层架构与资源调度逻辑差异显著——图像侧重像素级扩散优化，视频依赖时空一致性建模，3D聚焦神经辐射场（NeRF）与网格重建。**切勿将图像[prompt](../guides/prompt.md)直接复用于视频或3D任务**；应针对模态特性重构提示词（如视频需强调运动动词与镜头切换，3D需描述拓扑结构与材质属性）。建议通过百炼沙箱环境进行跨模态联调验证。
