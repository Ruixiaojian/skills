# [多模态](../concepts/multi-modal.md)生成能力对比：图像、视频与3D生成

为帮助开发者快速理解百炼平台在[多模态](../concepts/multi-modal.md)生成领域的技术布局与能力边界，本文系统对比图像生成、视频生成与3D生成三大核心能力模块。对比聚焦实际工程落地的关键维度——包括调用方式、模型生态、输入输出约束、计费逻辑及适用场景，旨在提供清晰、可操作的技术选型依据。所有信息均基于当前（2024年Q3）百炼平台正式发布的API文档与服务规范。

## 关键能力维度对比

| 维度 | 图像生成 | 视频生成 | 3D生成 |
|--------|-----------|------------|----------|
| **输入格式** | 文本（[prompt](../guides/prompt.md)）、单图URL（支持JPG/PNG/WEBP/BMP/AVIF）、多图URL（部分编辑模型支持≤14张参考图） | 文本（[prompt](../guides/prompt.md)）、单图URL（首帧）、双图URL（首尾帧）、多图URL（参考图）、视频URL + 音频URL（口型同步/编辑） | 文本（[prompt](../guides/prompt.md)）、单图URL（JPEG/PNG）、四视角图数组（前/左/后/右，空位填 `{}`） |
| **输出格式** | JPG/PNG（直接返回Base64或公网URL），部分模型支持WebP；输出为静态图像文件 | MP4（H.264编码），公网可下载URL；含预览缩略图（JPG） | GLB（PBR材质模型，默认）、OBJ/STL（需额外参数启用）；附带渲染预览图（JPG）；无贴图基础模型（`base_model_url`） |
| **支持模型（主力推荐）** | `qwen-image-3.0-pro`（T2I+I2I）、`wan2.6-t2i`（高自由度尺寸）、`wan2.7-image-pro`（4K图文混排） | `wan2.7-t2v-*`（三合一：T2V/I2V/续写）、`vidu/viduq3-turbo_text2video`（高速）、`pixverse-c1-r2v`（强参考一致性） | `Tripo/Tripo-H3.1`（高精度，≤200万面）、`Tripo/Tripo-P1.0`（快速，≤2万面） |
| **API端点（统一路径）** | `/api/v1/services/aigc/multimodal-generation/generation`（同步/异步共用） | `/api/v1/services/aigc/video-generation/video-synthesis`（仅异步） | `/api/v1/services/aigc/video-generation/3d-generation`（仅异步） |
| **调用模式** | **混合模式**：`wan2.6-t2i`/`z-image-turbo`等支持同步调用（低延迟）；局部重绘/虚拟模特等复杂任务强制异步 | **强制异步**：所有模型均需 `task_id` 轮询；不支持同步调用；`X-DashScope-Async: enable` 必填 | **强制异步**：所有请求必须携带 `X-DashScope-Async: enable`；无同步接口 |
| **地域支持** | 华北2（北京）、新加坡、美国（弗吉尼亚）等多地域可用，但Key/Endpoint/WorkspaceId须严格同地域 | 同图像生成，支持华北2、新加坡、美国（弗吉尼亚）；跨地域调用将鉴权失败 | **仅华北2（北京）**：API Key、WorkspaceId、Endpoint均限定该地域，其他地域不可用 |
| **计费方式** | 按**成功生成的图片张数**计费（如 `wan2.6-t2i` 0.25元/张）；失败/无效输入不计费；多数模型含500张免费额度（90天） | 按**模型+时长/任务**计费：文生视频按秒（如 `happyhorse-1.1-t2v` 0.8元/秒）、图生视频按任务（如 `wan2.7-i2v` 1.2元/次）、数字人按秒（`liveportrait` 0.02元/秒）；免费额度独立计算 | 按**任务次数**计费：`Tripo-P1.0` 1.5元/次，`Tripo-H3.1` 3.0元/次（含`ultra`质量）；无通用免费额度，新用户需单独申请试用包 |
| **典型场景** | 电商主图生成、营销海报设计、AI试衣、背景替换、创意文字艺术、人像写真增强 | 短视频广告制作、产品动态展示、数字人播报、口型同步短视频、风格化视频重绘、动作模仿 | 工业零件建模、游戏资产生成、电商3D商品展示、AR/VR内容快速原型、建筑可视化初稿 |

## 各方案适用场景建议

### ✅ 图像生成 —— 适合「高吞吐、低延迟、强可控」需求  
- **首选场景**：需要批量生成高质量静态图（如每日千张商品图）、实时交互式编辑（如在线设计工具中的即时重绘）、对响应时间敏感（<3s）的应用。  
- **推荐组合**：`qwen-image-3.0-pro`（兼顾T2I/I2I与多图输入） + 同步调用；`wan2.7-image-pro`（处理复杂图文混排与4K输出）。  
- **规避风险**：避免长期依赖已标注“仅免费体验”的模型（如 `shoemodel-v1`、`wanx-x-painting`），应迁移至 `qwen-image-3.0-pro` 或 `wan2.7-image-pro`。

### ✅ 视频生成 —— 适合「动态表达、[多模态](../concepts/multi-modal.md)协同、中低频生成」需求  
- **首选场景**：短视频内容生产（如营销脚本自动成片）、数字人驱动（新闻播报、客服对话）、已有素材的智能增强（老视频超清+风格迁移）、跨模态对齐（音频→口型→视频）。  
- **推荐组合**：`wan2.7-t2v-*`（统一接口支持多任务类型，降低集成复杂度） + 异步轮询 + 回调通知；`pixverse/pixverse-lipsync`（高精度口型同步专用）。  
- **规避风险**：勿混用旧版Endpoint（如 `/image2video/`）与新模型；注意Prompt需显式分镜（如“镜头1：...；镜头2：...”）以提升多镜头一致性。

### ✅ 3D生成 —— 适合「专业建模前置、轻量化资产、结构化输入」需求  
- **首选场景**：非专业设计师快速获取3D原型（如电商卖家上传产品图生成3D展示模型）、游戏/AR团队批量生成基础资产、工业设计概念验证。  
- **推荐组合**：`Tripo/Tripo-P1.0`（平衡速度与质量，5–15秒出模）用于高频试产；`Tripo/Tripo-H3.1`（配合 `geometry_quality: "ultra"`）用于关键部件高保真建模。  
- **规避风险**：严格校验输入——`input.images` 必须为长度4的数组；多图生3D时缺失视角必须显式填 `{}`；务必在华北2地域开通服务并配置对应Key。

## 开发者技术选型参考

| 选型维度 | 决策建议 |
|----------|----------|
| **延迟敏感型应用（如实时UI反馈）** | 优先选用图像生成的同步接口（`wan2.6-t2i`/`z-image-turbo`）；视频与3D生成因强制异步，不适用于亚秒级交互。 |
| **成本敏感型项目** | 对图像类任务，善用500张免费额度并监控用量；对视频类任务，优先选择`viduq3-turbo`系列（单价较低）；对3D任务，`P1.0`模型成本仅为`H3.1`的一半，建议先验证效果再升级。 |
| **跨地域部署需求** | 若业务覆盖全球用户，图像与视频生成可灵活部署于新加坡/美东节点以降低延迟；3D生成必须集中于华北2，需规划边缘缓存或CDN分发策略。 |
| **输入数据形态** | 若仅有文本描述 → 图像/视频/3D均可支持；若仅有单张产品图 → 图像编辑（`qwen-image-edit`）或图生视频（`wan2.7-i2v`）更高效；若具备四视角正交图 → 直接选用`Tripo-P1.0`多图生3D，精度显著优于单图方案。 |
| **长期维护性** | 一律避开文档中标注“推荐使用升级版”或“仅免费体验”的模型（如`wanx-v1`、`wan2.5`系列）；主力模型应锁定`qwen-image-3.0-pro`、`wan2.7-*`系列、`Tripo-*`，其API与功能迭代有明确SLA保障。 |
| **错误处理与重试** | 图像同步调用失败可立即重试；视频/3D异步任务需实现幂等轮询（建议≥15秒间隔）+ 任务ID有效期检查（24小时）+ 下载URL及时持久化（2小时过期）。 |

> **重要提醒**：所有多模态生成服务均要求 **API Key、WorkspaceId、Endpoint 严格同地域绑定**。开发环境调试阶段，请务必通过百炼控制台确认所用Key的归属地域，并构造对应专属域名（如 `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com`），避免因地域错配导致的401/404错误。
