# [多模态](../concepts/multimodal.md)生成能力对比：图像生成、视频生成与3D生成

为帮助开发者快速理解百炼平台在[多模态](../concepts/multimodal.md)生成领域的技术布局与能力边界，本文系统对比图像生成（Image Generation）、视频生成（Video Generation）与3D生成（3D Generation）三大核心能力。对比聚焦实际工程落地的关键维度——包括输入输出规范、模型生态、调用协议、计费逻辑与适用场景，旨在为技术选型提供客观、可操作的决策依据。所有能力均基于百炼平台当前（2024年Q3）正式发布的API服务，不包含实验性或内测功能。

## 关键能力维度对比

| 维度 | 图像生成 | 视频生成 | 3D生成 |
|------|----------|----------|--------|
| **核心输入格式** | 文本（[prompt](../guides/prompt.md)）、单图URL、局部掩码（mask）、涂鸦草图（sketch）等；支持多图融合（如 `wan2.5-i2i-preview`） | 文本（T2V）、单图/首帧（I2V）、首尾帧（I2V-smooth）、多参考图（R2V）、音频+人像图（数字人）、原始视频（编辑类） | 文本（文生3D）、单图URL（单图生3D）、四视角图数组（前/左/后/右，多图生3D）；三者严格互斥 |
| **核心输出格式** | JPG/PNG/WEBP 格式图片（含高分辨率4K）、带水印/无水印可选；部分模型返回优化提示词（`prompt_extend`） | MP4 格式视频（含音轨可选）、预览图（thumbnail）、元数据（时长/分辨率/帧率）；无原生3D资产输出 | GLB 格式3D模型（PBR材质版 `pbr_model_url` 或基础网格版 `base_model_url`）、渲染预览图（`rendered_image_url`）；所有URL有效期仅2小时 |
| **主流支持模型** | `wan2.6-t2i`, `qwen-image-3.0-pro`, `kling/kling-v3-omni-image-generation`, `wanx-x-painting`, `virtualmodel-v2`, `shoemodel-v1` 等超15个专用模型 | `wan2.7-video`, `pixverse/pixverse-c1-t2v`, `vidu/viduq3-turbo_text2video`, `happyhorse/hh-t2v-pro`, `emo/emotion-video-retalk` 等覆盖T2V/I2V/R2V/编辑全链路 | 仅 `Tripo/Tripo-P1.0`（专业版，≤2万面）和 `Tripo/Tripo-H3.1`（高精度版，≤200万面）两个模型；无通用替代方案 |
| **API端点（统一路径）** | `/api/v1/services/aigc/{service}/generation`（主流异步）<br>部分模型支持 `/multimodal-generation/generation`（同步） | `/api/v1/services/aigc/video-generation/video-synthesis`（万相2.7+及新协议模型）<br>旧版万相2.1–2.6 使用 `/image2video/video-synthesis`（已不推荐） | `/api/v1/services/aigc/video-generation/3d-generation`<br>⚠️ 注意：路径中仍含 `video-generation` 字段，属历史命名遗留，实际为3D专属端点 |
| **调用模式** | **主流为异步**（创建任务 → 轮询结果）；少数模型（如 `wan2.6+` [多模态](../concepts/multimodal.md)接口）支持同步直出 | **强制异步**（所有模型均需 `X-DashScope-Async: enable`）；无同步模式 | **强制异步**（必须携带 `X-DashScope-Async: enable`，否则报错）；无同步模式 |
| **地域支持范围** | 全地域支持：北京、新加坡、弗吉尼亚、法兰克福、东京等（模型与Key/Endpoint须同地域） | 全地域支持：与图像生成一致，各模型按地域独立部署 | **仅华北2（北京）地域支持**；其他地域Endpoint不可用，API Key必须在北京地域生成 |
| **计费方式** | 按成功生成图片张数计费（如 `wanx-v1`: 0.16元/张）；500张/90天免费额度；部分模型（如 `wanx-x-painting`）限免体验 | 按成功生成视频条数计费（如 `wan2.7-video`: 1.2元/条）；500条/90天免费额度；数字人/口型同步等子能力单独计价 | 按成功生成3D模型个数计费（`Tripo-P1.0`: 0.8元/个；`Tripo-H3.1`: 3.5元/个）；无公开免费额度，需开通后按量付费 |
| **典型处理耗时** | 异步任务：3–30秒（取决于模型与分辨率）；同步模式：≤2秒 | 异步任务：1–10分钟（T2V约1–3分钟；复杂视频编辑/数字人可达5–10分钟） | 异步任务：2–8分钟（`P1.0`约2–4分钟；`H3.1`约5–8分钟）；任务状态轮询建议间隔 ≥15秒 |
| **输入约束强度** | 中等：图像URL需公网可访问、无中文路径、格式合规（JPG/PNG/WEBP）；分辨率有模型级限制（如 `wan2.6-t2i` 要求1280×1280~1440×1440） | 较高：图像需清晰正面主体居中；视频需画面稳定、人声清晰；URL必须HTTPS；文件大小 ≤200MB；首尾帧需语义连贯 | 高：单图尺寸20–6000px且 ≤20MB；多图必须严格4元素数组，缺失视角用 `{}` 占位；文本[prompt](../guides/prompt.md) ≤1024字符；三类输入严格互斥 |

## 各方案适用场景建议

- **图像生成**  
  ✅ **首选场景**：内容创作（营销海报、社交媒体配图）、电商素材生产（商品图生成/背景替换/鞋靴试穿）、设计辅助（风格迁移、局部重绘、扩图）、AI绘画工具集成。  
  ⚠️ **慎用场景**：对实时性要求极高的前端交互（应优先选用同步模型并压测延迟）；需长期存储原始像素资产（注意URL有效期24小时，需及时下载）。  
  💡 **推荐组合**：通用需求用 `qwen-image-3.0-pro`（T2I+I2I一体化）；电商人像用 `virtualmodel-v2`（支持自定义宽高比）；精细化编辑用 `wanx2.1-imageedit`（全局/局部风格化）。

- **视频生成**  
  ✅ **首选场景**：短视频内容批量生产（广告片、教程动画）、数字人播报（新闻/客服）、AIGC营销视频（图文转视频）、视频增强（超分、动作迁移、口型同步）、IP形象动态化（参考生视频）。  
  ⚠️ **慎用场景**：长视频生成（当前最大时长30秒，不支持分段拼接）；高精度物理仿真（如流体/布料动力学，非本能力范畴）；低延迟直播推流（异步架构无法满足毫秒级响应）。  
  💡 **推荐组合**：快速原型用 `vidu/viduq3-turbo_text2video`（T2V极速版）；高质量数字人用 `emo/emotion-video-retalk`（声动人像）；跨角色一致性需求用 `pixverse/pixverse-c1-t2v`（参考生视频）。

- **3D生成**  
  ✅ **首选场景**：3D电商展示（商品白模生成）、游戏/AR快速建模（概念验证阶段）、工业设计初稿（结构件可视化）、教育可视化（分子/器官模型）。  
  ⚠️ **慎用场景**：影视级高精模型（`H3.1`上限200万面，远低于ZBrush等专业工具）；拓扑复杂模型（如有机生物、缠绕管线，易出现几何畸变）；实时渲染引擎直连（需额外GLB解析与PBR材质适配）。  
  💡 **推荐组合**：快速迭代选 `Tripo-P1.0`（2万面，秒级生成）；交付级资产选 `Tripo-H3.1` + `geometry_quality: ultra`（200万面，需预留8分钟处理时间）；需轻量化部署时显式设置 `texture: false, pbr: false` 获取无材质基础网格。

## 面向开发者的选型参考指南

1. **先明确输入源与输出目标**  
   - 若输入为纯文本→优先评估图像/视频/3D的T2X能力是否匹配业务目标（如“生成产品宣传图”选图像，“生成产品演示短视频”选视频，“生成产品3D白模”选3D）；  
   - 若输入含图像→检查是否需保留空间结构（选3D）、时序动态（选视频）或静态美学（选图像）；  
   - 若需多模态协同（如“根据产品图生成3D模型，再驱动数字人讲解”）→需组合调用3D+视频API，注意任务编排与URL时效性管理。

2. **严格校验地域与环境一致性**  
   - 图像/视频：务必确保 API Key、Endpoint URL、模型列表三者同地域（如新加坡Key不可调用北京Endpoint）；  
   - 3D：**唯一例外**——仅北京地域可用，若业务已部署于法兰克福，需额外申请北京地域API Key并配置专属域名。

3. **异步任务需设计健壮轮询机制**  
   - 图像：轮询间隔 ≥5秒，超时阈值设为60秒；  
   - 视频：轮询间隔 ≥10秒，超时阈值设为15分钟（复杂任务）；  
   - 3D：轮询间隔 ≥15秒，超时阈值设为10分钟，并立即下载 `pbr_model_url`（2小时有效期）。

4. **成本与性能平衡策略**  
   - 图像：高并发场景避免使用 `kling` 系列（支持1–9张但单价高），改用 `z-image-turbo`（固定1张，性价比优）；  
   - 视频：长时长需求（如30秒）优先选 `vidu` 系列（稳定性强），避免 `happyhorse` 在高负载下超时；  
   - 3D：`P1.0` 与 `H3.1` 价格相差4.4倍，建议先用 `P1.0` 快速验证提示词效果，再升级至 `H3.1` 生成终版。

5. **规避常见陷阱**  
   - ❌ 图像API误用 `wan2.6-image` 模型执行文生图（应使用 `wan2.6-t2i`）；  
   - ❌ 视频API混用新旧协议路径（万相2.7+ 必须用 `/video-synthesis`，禁用 `/image2video/`）；  
   - ❌ 3DAPI同时传入 `input.prompt` 和 `input.image`（触发 `InvalidParameter` 错误）；  
   - ❌ 所有能力忽略 `X-DashScope-WorkSpace` 头（RAM子账号调用必填）。

> **最后提醒**：所有能力均依赖百炼控制台开通对应模型服务，并授予业务空间调用权限。建议新项目上线前，使用免费额度完成全链路验证（输入→任务创建→轮询→下载→渲染），再切换至付费模式。
