# 图像生成与视频生成对比

为帮助开发者快速理解百炼平台中图像生成与视频生成两类能力的差异，明确技术选型边界与集成路径，本文从核心能力、调用方式、资源约束及适用场景等维度进行系统性对比。两类服务虽同属多模态生成范畴，但在计算范式、工程实现与业务落地层面存在显著差异，需结合具体需求谨慎评估。

## 关键维度对比

| 维度 | 图像生成 | 视频生成 |
|------|----------|----------|
| **输入格式** | 支持纯文本（`prompt`）、单图（`image_url`）、多图（局部重绘/参考图）、结构化消息（`messages`）；部分模型支持涂鸦、草图、文字纹理等特殊输入 | 严格按任务类型区分：<br>• 文生视频：仅文本 `prompt`<br>• 图生视频：单张图像（`first_frame`）或首尾帧（`first_frame` + `last_frame`）<br>• 参考生视频：1–4 张图像 + 可选视频/音频<br>• 视频编辑：原始视频 URL + 控制 [prompt](../guides/prompt.md)<br>• 人物驱动：需前置调用 `detect` 模型验证人脸/姿态 |
| **输出格式** | 单张或多张静态图像（JPEG/PNG），返回直链 URL（有效期 24 小时）；支持 `n` 参数批量生成（如 `n=6`） | 单段 MP4 视频（H.264 编码），返回 `video_url`（有效期 24 小时）；**不支持多段输出**，每任务仅生成 1 条视频（时长通常为 3–5 秒） |
| **支持模型（典型代表）** | • 通用模型：`qwen-image-3.0-pro`、`wan2.7-image-pro`、`z-image-turbo`<br>• 垂直模型：`wanx-sketch-to-image-lite`、`vidu/vidu-image_reference2image`、`FaceChain`<br>• 创意工具：`WordArt锦书`、`OutfitAnyone` | • 文生视频：`wan2.7-t2v-2026-06-12`、`vidu/viduq3-turbo_text2video`<br>• 图生视频：`pixverse/pixverse-c1-it2v`、`vidu/viduq3-pro-fast_img2video`<br>• 首尾帧：`pixverse/pixverse-c1-kf2v`、`vidu/viduq3-turbo_start-end2video`<br>• 参考生视频：`happyhorse-reference-to-video`、`wan2.7-r2v-2026-06-12`<br>• 人物驱动：`emo-v1`、`liveportrait`、`animate-anyone-gen2` |
| **API 端点** | • 同步调用：`POST /api/v1/services/aigc/multimodal-generation/generation`<br>• 异步调用：同上，但需添加 `X-DashScope-Async: enable` 请求头 | **仅支持异步**：<br>`POST /api/v1/services/aigc/video-generation/video-synthesis`<br>（注意：旧版 `image2video` 路径已废弃，不可混用） |
| **调用模式** | **同步与异步双模支持**：<br>• 快速模型（如 `z-image-turbo`、`qwen-image-3.0-pro`）推荐同步调用（毫秒级响应）<br>• 复杂任务（如虚拟模特、背景扩展）强制异步 | **强制异步**：<br>所有视频任务均需两步操作：<br>1. 创建任务获取 `task_id`<br>2. 轮询 `/api/v1/tasks/{task_id}` 直至 `status == "SUCCESS"`<br>（处理耗时：1–10 分钟，取决于模型与分辨率） |
| **计费方式** | 按**成功生成图片张数**计费（如 `wan2.1-t2i-plus`：0.16 元/张）；免费额度为 **500 张/90 天** | 按**成功生成视频条数**计费（单价因模型而异，如 `wan2.7-t2v` 约 1.2 元/条）；免费额度通常为 **50 条/90 天**（部分模型无免费额度） |
| **地域与域名约束** | 所有模型严格绑定地域（北京/新加坡/弗吉尼亚），且必须使用**业务空间专属域名**（如 `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com`）；跨地域调用将鉴权失败 | 同样强绑定地域，但**支持范围更窄**：<br>• `kling`、`Vidu`、`HappyHorse`、`LivePortrait` 等主流模型**仅限华北2（北京）**<br>• 新加坡/德国等地域仅支持有限模型（如 `wan2.7-t2v`），需查阅各模型文档确认 |
| **典型场景** | • 电商主图生成与换背景<br>• 社媒配图、海报设计<br>• UI/图表渲染（`vidu-image_reference2image`）<br>• AI 试衣（`OutfitAnyone`）<br>• 汉字艺术字生成（`WordArt锦书`） | • 短视频内容创作（T2V）<br>• 产品动态展示（I2V / KF2V）<br>• 数字人播报、AI 表情包、唱演视频<br>• 视频风格迁移、超分、口型同步<br>• 多图角色一致性动画（R2V） |

## 各方案适用场景建议

### ✅ 图像生成更适合：
- **高频、轻量、确定性输出需求**：如每日批量生成数百张商品图、A/B 测试多版本 Banner、自动化报告插图。
- **强可控性与高精度要求场景**：需精细控制构图、文字渲染、局部修改（如擦除/重绘特定区域）、风格迁移（如将照片转为水彩画）。
- **前端实时交互应用**：基于用户输入即时返回图像（如设计工具中的“一键改图”），同步调用可保障低延迟体验。
- **成本敏感型项目**：单张图像成本显著低于单条视频，适合预算有限但需大量视觉素材的场景。

### ✅ 视频生成更适合：
- **动态表达与叙事需求**：需呈现时间维度变化（如产品功能演示、角色动作、镜头运镜、情绪演绎）。
- **数字人与虚拟内容生产**：构建企业 IP 形象、客服播报、课程讲解、短视频账号运营。
- **视频增强与再创作**：对存量视频做风格化、画质提升、语音驱动口型、动作迁移等专业编辑。
- **创意营销与社交传播**：生成 3–5 秒高冲击力短视频用于信息流投放、私域裂变、活动预热。

### ⚠️ 不建议交叉替代的情况：
- ❌ 用图像生成替代视频生成：无法表达运动、时序逻辑、镜头语言；拼接多图成视频会丢失连贯性与物理合理性。
- ❌ 用视频生成替代图像生成：成本高、耗时长、输出不可控（帧间抖动、语义漂移）；无法满足精确像素级编辑需求（如证件照修图、UI 元素替换）。

## 面向开发者的选型参考

作为技术决策者，请在启动集成前明确以下关键问题：

1. **输出本质是「静态结果」还是「动态过程」？**  
   → 若目标为一张图、一个设计稿、一个可嵌入网页的 PNG，则选图像生成；若需播放、需时间轴、需音画同步，则必须选视频生成。

2. **对响应时效与调用链路有何要求？**  
   → 若需 <2 秒内返回结果（如搜索页实时预览），优先选用图像生成的同步模式；若可接受分钟级延迟且需异步通知（如后台任务队列），视频生成亦可纳入架构。

3. **输入数据是否具备视频生成前提？**  
   → 检查是否拥有合规首帧图（清晰人脸/主体）、是否能提供首尾帧（需构图一致）、是否已通过 `detect` 模型验证（数字人场景）。缺失则无法调用对应视频模型。

4. **成本与规模是否匹配？**  
   → 对比单位成本：1 条视频 ≈ 5–8 张高质量图像；若日均需生成 1000+ 视觉单元，图像生成更具性价比；若每月仅需 50 条精品视频，视频生成更高效。

5. **地域与基础设施是否就绪？**  
   → 图像生成支持三地部署，视频生成主力模型集中于北京；若业务部署在新加坡，需确认所选视频模型是否可用，否则需调整架构或切换模型。

最后提醒：两类服务均**强烈推荐使用业务空间专属域名**，避免公共域名限流与稳定性风险；所有模型务必查阅最新版 API 文档确认参数细节（尤其 `size`/`resolution` 格式、`media` 结构、`prompt` 描述规范），切勿复用旧版 V1/V2 参数逻辑。
