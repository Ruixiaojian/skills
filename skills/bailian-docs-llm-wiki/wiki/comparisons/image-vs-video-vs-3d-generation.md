# 图像生成、视频生成与3D生成对比

百炼平台提供了覆盖图像、视频和3D模型的完整内容生成能力。三类生成 API 在输入输出格式、调用方式、模型生态和适用场景上各有特点。本文从开发者技术选型的角度，对三者进行系统性对比，帮助您根据业务需求快速选择合适的生成方案。

## 核心维度对比

| 对比维度 | 图像生成 | 视频生成 | 3D生成 |
|---------|---------|---------|--------|
| **输入格式** | 文本提示词、图片 URL/Base64 | 文本提示词、图片 URL、视频 URL、音频 URL | 文本提示词、单张/多张图片 URL |
| **输出格式** | 图片（JPG/PNG 等），返回图片 URL | 视频文件，返回视频 URL | GLB 格式 3D 模型 + 预览渲染图，返回下载 URL |
| **主要模型系列** | 千问-文生图、万相（Wan/Wanx）、Z-Image、可灵 Kling | 万相 2.1–2.7、HappyHorse、爱诗 PixVerse、可灵 Kling、Vidu | Tripo-H3.1、Tripo-P1.0 |
| **API 端点路径** | `/api/v1/services/aigc/multimodal-generation/generation`（同步）或模型专用路径（异步） | `/api/v1/services/aigc/video-generation/video-synthesis`（主路径） | `/api/v1/services/aigc/video-generation/3d-generation` |
| **调用方式** | 新模型支持**同步调用**；旧版/耗时任务为异步调用 | **全部异步调用**（创建任务 → 轮询结果） | **全部异步调用**（创建任务 → 轮询结果） |
| **典型响应时间** | 同步模型秒级返回；[异步任务](../concepts/async-task.md)数十秒至数分钟 | 通常 1–5 分钟 | 数十秒至数分钟（建议轮询间隔 15 秒） |
| **输出链接有效期** | 24 小时 | 24 小时 | **2 小时**（需更及时下载） |
| **task_id 有效期** | 24 小时 | 24 小时 | 24 小时 |
| **最大输出分辨率/规格** | 最高 4K（如万相 2.7、可灵） | 最高 720P | 最高 200 万面（Tripo-H3.1 ultra） |
| **支持地域** | 北京、新加坡、弗吉尼亚（因模型而异） | 北京、新加坡、弗吉尼亚、法兰克福（因模型而异） | **仅北京** |
| **计费方式** | 按成功输出的图片张数计费，输入图片和失败任务不计费 | 按任务/时长计费（因模型而异） | 按任务类型计费（text-to-3d / image-to-3d / multi-image-to-3d） |
| **免费额度** | 开通后自动发放 500 张，有效期 90 天 | 因模型而异，部分模型需单独开通 | 需在控制台搜索"Tripo"单独开通 |
| **异步请求头要求** | [异步任务](../concepts/async-task.md)需 `X-DashScope-Async: enable` | **必须**设置 `X-DashScope-Async: enable` | **必须**设置 `X-DashScope-Async: enable` |

## 功能能力对比

| 功能 | 图像生成 | 视频生成 | 3D生成 |
|------|---------|---------|--------|
| 文本生成（文生X） | ✅ 文生图 | ✅ 文生视频 | ✅ 文生3D |
| 图片驱动生成 | ✅ 图生图、参考图生图 | ✅ 图生视频（首帧/首尾帧） | ✅ 单图生3D、多图生3D |
| 编辑/修改 | ✅ 局部重绘、物体增删、扩图、超分、上色 | ✅ 视频编辑、视频续写 | ❌ 不支持 |
| 风格迁移/转换 | ✅ 风格化、人像风格重绘 | ✅ 视频风格重绘（8 种预设） | ❌ 不支持 |
| 参考内容生成 | ✅ 参考图生图 | ✅ 参考生视频（参考图/参考视频） | ✅ 多视角参考图生3D |
| 数字人/人物驱动 | ✅ AI试衣、虚拟模特 | ✅ 数字人、舞动人像、悦动人像、声动人像 | ❌ 不支持 |
| 文字渲染 | ✅ 中英文字渲染、创意文字 | ❌ 不支持 | ❌ 不支持 |
| 提示词优化 | ✅ `prompt_extend` 参数 | ✅ `prompt_extend` 参数 | ❌ 不支持 |
| PBR 材质 | — | — | ✅ 支持 PBR 材质输出 |

## 输入要求对比

| 维度 | 图像生成 | 视频生成 | 3D生成 |
|------|---------|---------|--------|
| **图片格式** | JPG、JPEG、PNG、BMP、WEBP | JPG、PNG 等（因模型而异） | JPEG、PNG |
| **图片传入方式** | 公网 HTTP/HTTPS URL，部分支持 Base64 | 公网 HTTP/HTTPS URL | 公网 HTTP/HTTPS URL；多图模式使用 `file_token` |
| **图片尺寸范围** | 通常 512×512 ~ 4096×4096 | 因模型而异 | 20×20px ~ 6000×6000px |
| **图片大小限制** | 通常 ≤10MB | 因模型而异 | ≤20MB |
| **提示词长度** | 因模型而异 | 因模型而异 | 最大 1024 字符 |
| **多图输入** | ✅ 部分模型支持多图融合 | ✅ 首帧+尾帧、参考图+视频等 | ✅ 固定 4 元素数组（前、左、后、右视角） |

## 调用流程对比

### 图像生成（同步模式）

```
客户端 → POST 请求（含提示词/图片） → 服务端直接返回图片 URL
```

适用模型：qwen-image-2.0 系列、wan2.6-t2i、wan2.7-image、z-image-turbo。

### 图像生成（异步模式）/ 视频生成 / 3D生成

```
客户端 → POST 创建任务（X-DashScope-Async: enable）→ 返回 task_id
客户端 → GET 轮询任务状态 → PENDING → RUNNING → SUCCEEDED（返回结果 URL）
```

三者的异步流程一致，差异仅在端点路径和返回字段。

## 适用场景建议

### 图像生成

- **营销与设计**：电商商品主图、广告海报、社交媒体配图的快速生产
- **内容创作**：文章插图、故事绘本、概念设计的批量生成
- **图像后处理**：已有图片的局部修改、风格转换、背景替换、超分辨率
- **电商应用**：AI试衣、虚拟模特、商品背景生成
- **文字场景**：需要在图像中渲染清晰中英文字的海报、证书等

### 视频生成

- **短视频制作**：将创意文案或产品图片快速转化为短视频内容
- **数字人应用**：虚拟主播、数字人播报、AI 代言人等场景
- **动画与特效**：人物舞蹈视频、动作迁移、视频风格化
- **广告与营销**：产品展示视频、品牌宣传片的快速原型
- **视频编辑**：对已有视频进行风格重绘、口型替换等后期处理

### 3D生成

- **游戏与元宇宙**：快速生成 3D 角色、道具、场景模型的原型
- **电商展示**：商品 3D 展示模型，支持 360° 旋转预览
- **工业设计**：概念设计阶段的快速 3D 可视化
- **教育与培训**：教学用 3D 模型的批量生成
- **AR/VR 应用**：为增强现实或虚拟现实场景快速生成素材

## 技术选型参考

### 选择图像生成的情况

- 需要**静态视觉内容**且要求快速响应（同步接口秒级返回）
- 需要对已有图片进行**精细编辑**（局部重绘、扩图、超分等）
- 需要**高分辨率输出**（最高支持 4K）
- 需要在图片中**渲染文字**
- 预算有限，按张计费成本可控，且有免费额度可用

### 选择视频生成的情况

- 需要**动态内容**表达，如产品演示、故事叙事
- 需要**数字人**能力，如虚拟主播、口型驱动
- 需要将静态图片"**动起来**"（图生视频）
- 可以接受**分钟级的异步等待时间**
- 有**多地域部署**需求（最多支持四个地域）

### 选择3D生成的情况

- 需要生成可在 3D 引
