# model data overview

百炼平台的模型数据体系围绕训练集与评测集构建，支持从日志回流、人工构造到清洗增强的全链路数据管理。所有数据均以结构化格式（如 JSONL）组织，服务于模型调优与评测两大核心场景。数据功能深度集成于控制台，但部分能力（如日志回流、数据处理）存在地域与模型类型限制，开发者需按规范配置并验证兼容性。

## 支持的模型/功能

- **日志回流**：将 SLS 推理日志自动转化为结构化训练集或评测集，仅在华北2（北京）和新加坡 Region 可用，详见[日志回流](../../raw/model-user-guide/model-data-overview/model-log-backflow.md)。  
- **训练集类型**：支持文本生成（SFT/DPO/CPT）、多模态理解（Qwen-VL）、图生视频（首帧/首尾帧）三类训练集；其中 SFT 和 DPO 采用 ChatML 格式，CPT 为纯文本 JSONL 格式。  
- **评测集类型**：当前仅支持文本生成类评测集（Excel 或 JSONL 格式单轮对话），不支持多模态或图生视频评测。  
- **数据处理**：提供数据清洗（如敏感信息打码、特殊内容移除）与数据增强（基于千问-Max 的 Few-Shot 生成）能力，但**仅支持 SFT-文本生成训练集（ChatML 格式）**，暂不支持 DPO、CPT 或多模态训练集，详见[数据清洗或增强](../../raw/model-user-guide/model-data-overview/data-processing.md)。  
- **地域限制**：日志回流、训练集与评测集管理、数据清洗/增强等功能均**仅限华北2（北京）地域**，其他 Region 不可用（文档 2 和 3 明确标注“本文档仅适用于华北2（北京）地域”）。  

> **注意**：文档 1 声明日志回流在“华北2（北京）和新加坡”可用，而文档 2 和 3 均强调“仅适用于华北2（北京）地域”。经交叉比对，新加坡 Region 仅支持日志回流入口，但后续的数据处理、评测集创建等关键功能未在文档中确认支持。实际使用时，请以控制台界面为准——若新加坡 Region 的数据管理页签缺失“数据处理”或“评测集创建”入口，则视为功能不完整。

## 关键参数

| 参数类别 | 参数名 | 说明 | 约束 |
|----------|--------|------|------|
| **通用** | 数据集名称 | 中文/英文/数字/下划线/斜杠/连字符，≤50 字符；建议按 `功能_模型_时间` 命名 | 创建后不可修改 |
| | 数据集描述 | 补充用途说明，≤200 字符 | 可选 |
| **日志回流专用** | 回流位置 | “平台存储”（默认）或“OSS 挂载”；评测集禁用 OSS 挂载 | 创建后不可更改 |
| | 时间范围 | 最近 30 天（含当天），精确到秒；修改会重置 API Key 和模型选择 | 必填 |
| | API Key 过滤 | “全部”、“其他”（排除已列 Key）或具体 Key 多选 | 必填；“其他”包含已删除 Key 或跨工作空间请求 |
| | 模型选择 | 最多选 10 个模型；不匹配训练场景的模型置灰 | 必填 |
| **训练集专用** | 训练方式 | SFT / DPO / CPT（仅训练集显示） | 创建后锁定 |
| | loss_weight | SFT/DPO 中 assistant/chosen 字段的可选浮点参数（0.0–1.0），用于加权训练 | 邀测功能，需联系商务经理开通 |

## 使用方式

- **创建数据集**：  
  - 日志回流：通过[模型监控列表页](https://bailian.console.aliyun.com/#/model-telemetry)顶部“日志回流”入口，或模型监控详情页时间选择器旁按钮进入；也可在**数据管理 → 新建数据集 → 导入方式 = 日志回流**触发（该选项仅在训练集/SFT 或评测集场景下可见）。  
  - 人工上传：在**数据管理**页上传符合格式的 JSONL 或 Excel 文件，详见[训练集与评测集](../../raw/model-user-guide/model-data-overview/training-set-and-evaluation-set.md)。  
- **追加数据**：  
  - 平台存储数据集：支持“新增版本”弹窗或“导入数据”页两种方式；  
  - OSS 挂载数据集：**仅支持“导入数据”页**，不支持“新增版本”（按钮置灰）。  
- **数据处理**：  
  - 在**数据管理 → 数据流**页签创建自定义数据流（如先清洗后增强），再通过“任务列表 → 从数据流列表创建任务”指定训练集执行；处理结果自动生成新版本（如 V1 → V2），原数据集不受影响。  

## 限制和注意事项

- **单次回流上限**：日志回流单次最多回流 10 万条日志，超出部分被截断；但数据集总量无上限，可通过多次回流积累（如分时段、分模型回流），详见[日志回流](../../raw/model-user-guide/model-data-overview/model-log-backflow.md)。  
- **存储方式差异**：  
  - 平台存储：无需额外授权，导入完成自动发布版本；  
  - OSS 挂载：需授权 `AliyunServiceRoleForAccessCusOss` 和 `AliyunServiceRoleForSFMDataHubOSSImport` 角色，且不自动发布版本、不支持新增版本操作。  
- **功能兼容性**：  
  - 数据清洗/增强**仅支持 SFT-文本生成训练集（ChatML 格式）**，明确不支持 SFT-图片理解、DPO、CPT 及图生视频训练集（文档 3 原文明确声明）；  
  - 评测集**不支持 OSS 挂载存储**（文档 1 表单说明中明确“评测集时 OSS 挂载禁用”）。  
- **地域与权限强依赖**：  
  - 日志回流需先开通审计日志（前置）→ 推理日志（后置），并完成 SLS 角色授权；关闭须反序操作，否则已有日志不可复原；  
  - 所有数据功能（除日志回流入口外）均要求 Region 为华北2（北京），新加坡 Region 的功能完整性需以控制台实际呈现为准。
