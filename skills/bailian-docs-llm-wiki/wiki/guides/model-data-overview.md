# model data overview

百炼平台的模型数据管理功能为开发者提供统一的数据集创建、版本控制与处理能力，支撑模型调优（SFT/DPO/CPT）和评测两大核心场景。数据集分为训练集与评测集，支持多种导入方式（本地上传、OSS 导入、日志回流）及后续清洗增强操作。所有操作均通过控制台完成，API 仅支持引用已发布数据集 ID。

## 支持的模型/功能

- **训练集**：支持文本生成、[多模态](../concepts/multimodal.md)理解、图生视频（首帧/首尾帧）四类训练场景；对应训练方法包括 SFT（监督微调）、DPO（直接偏好优化）和 CPT（持续预训练）。
- **评测集**：仅支持文本生成场景，用于模型泛化能力评估。
- **数据处理**：支持对 SFT-文本生成训练集（ChatML 格式）进行数据清洗（如敏感信息打码、特殊内容移除）和数据增强（如 Few-Shot 生成），暂不支持 DPO 训练集或[多模态](../concepts/multimodal.md)训练集 [数据清洗或增强](../../raw/model-user-guide/model-data-overview/data-processing.md)。
- **日志回流**：将 SLS 推理日志转化为结构化 JSONL 数据集，支持训练集（SFT/DPO/CPT）和评测集，当前仅在华北2（北京）和新加坡 Region 可用 [日志回流](../../raw/model-user-guide/model-data-overview/model-log-backflow.md)。

> **注意**：文档1称“DPO/CPT 训练方法、云存储挂载仅支持北京地域”，而文档2明确日志回流在**北京和新加坡**均可用。对于 DPO/CPT 训练本身（非日志回流），仍以文档1为准——即仅北京支持；日志回流作为独立功能，其地域支持范围更广。

## 关键参数

| 参数 | 说明 | 是否必填 | 取值约束 |
|------|------|----------|-----------|
| 数据集名称 | 唯一标识符 | 是 | ≤50 字符，支持中文、英文、数字、下划线、连字符、点（文档1）；斜杠也允许（文档2） |
| 数据集类型 | 训练集 / 评测集 | 是 | 创建后不可变更 |
| 训练场景 | 文本生成 / [多模态](../concepts/multimodal.md)理解 / 图生视频（首帧/首尾帧） | 是 | 评测集仅支持文本生成 |
| 训练方法 | SFT / DPO / CPT | 是 | CPT 和图生视频训练集不支持草稿状态 [训练集与评测集](../../raw/model-user-guide/model-data-overview/training-set-and-evaluation-set.md) |
| 存储位置 | 平台 OSS 存储 / 云存储挂载 | 是 | 评测集不支持云存储挂载；OSS 挂载需额外授权角色 |
| 导入方式 | 本地上传 / OSS 导入 / 日志回流 | 是 | 评测集不支持 OSS 导入；日志回流支持追加至已有数据集版本 |

## 使用方式

1. **创建数据集**：在控制台「数据管理」→「数据集」→「新增数据集」，按向导填写参数并选择导入方式。
2. **导入数据**：
   - *本地上传*：直接上传符合格式要求的文件（如 SFT 的 JSONL），支持多文件。
   - *OSS 导入*：目标 Bucket 需添加标签 `bailian-datahub-access=read`，仅训练集可用。
   - *日志回流*：需先开通审计日志与推理日志，并完成 SLS 角色授权；支持按时间范围（最近30天）、API Key、模型筛选，单次上限 10 万条 [日志回流](../../raw/model-user-guide/model-data-overview/model-log-backflow.md)。
3. **版本管理**：已发布数据集可点击「新增版本」，选择「继承模式」（增量修改）或「新建模式」（全量替换）；CPT 训练集不支持继承，必须新建。
4. **数据处理**：仅限 SFT-文本生成训练集，在「数据管理」→「数据流」中创建清洗/增强任务，输出自动生成新版本，原版本不受影响。

## 限制和注意事项

- **地域限制**：DPO/CPT 训练、云存储挂载、数据清洗/增强功能仅支持华北2（北京）；日志回流额外支持新加坡 Region。
- **草稿限制**：CPT 和图生视频训练集不支持草稿，创建时必须立即发布；SFT/DPO 文本生成训练集支持草稿。
- **数据量限制**：
  - 日志回流单次上限 10 万条（非总量限制，可多次回流累积）；
  - 数据集无总数量或总容量上限，但 CPT 推荐数据量 ≥5000 万 [Token](../concepts/token.md)；
  - 数据处理中「数据增强-通用」节点单次最多生成 2000 条样本。
- **格式与兼容性**：
  - 评测集导出为 XLSX，SFT 训练集导出为 JSONL，多模态训练集导出为 ZIP；
  - 数据处理仅接受 ChatML 格式的 SFT-文本生成训练集，不支持其他格式或场景；
  - OSS 导入不支持评测集；日志回流不支持多模态/图生视频场景。
- **操作不可逆**：发布或删除操作不可恢复；已发布版本不可编辑，仅草稿版本可删除或在线编辑。
- **计费提示**：数据管理功能免费，但存储（平台 OSS 或用户 OSS）、SLS 日志服务、模型调用等下游资源按各自产品计费。
