> /config
Thinking mode: true
```

## OpenCode

**开启思考模式**：在配置文件`opencode.json`中添加以下配置：

```
"options": {
  "thinking": {
    "type": "enabled",
    "budget[Token](../concepts/token.md)s": 1024
  }
}
```
