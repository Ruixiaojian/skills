# model compression

模型压缩是百炼平台提供的量化优化能力，专用于将全精度微调模型转换为低精度版本，在保障推理效果的前提下显著降低部署所需的 MU 规格与成本。该功能属于模型生产链路中的可选环节，位于[模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)之后、[模型部署](https://help.aliyun.com/zh/model-studio/model-deployment-1/#3bc53b23c7shc)之前。压缩操作不可逆，且仅适用于百炼平台内完成的微调模型。

## 支持的模型与功能

- **支持模型**：当前仅支持通过百炼平台微调产出的自定义模型（如 `qwen3.5-flash-2026-02-23`），不支持基础模型、第三方模型或 OSS 导入模型。具体可用模型以控制台实时列表为准。  
- **功能范围**：百炼模型压缩特指**后训练量化（PTQ）**，不包含结构剪枝、知识蒸馏等其他压缩技术。详见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“功能概述”章节。  
- **地域限制**：仅华北2（北京）地域可用。

## 关键参数

创建压缩任务时需配置以下必填参数（均在控制台界面显式暴露）：

| 参数 | 说明 |
|------|------|
| **任务名称** | 最长 50 字符，建议含模型简称、量化方式和版本号，便于追踪。 |
| **选择源模型** | 仅展示当前工作空间中状态为“成功”的微调模型；切换源模型会自动清空已选量化模板。 |
| **量化产出模型名后缀** | 8 位以内小写字母/数字，将拼接至源模型名后形成新模型标识（如 `my-model-quant`）。 |
| **量化模板** | 卡片式选择，模板名中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失可能增加。须先选定源模型后才可加载对应模板列表。 |
| **校准数据** | 条件选填：仅当所选模板要求校准时出现；最多选 5 个已在[数据管理](https://help.aliyun.com/zh/model-studio/manage-data/#9d2f7039bfo1a)中发布完成的数据集，不支持 OSS 挂载数据。 |

> **注意**：参数配置提交后不可修改，务必在单击“开始压缩”前确认所有选项——该约束在 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的“重要”提示中多次强调。

## 使用方式

1. **前提条件**：确保工作空间中已存在状态为“成功”的微调模型（参见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) “前提条件”节）。
2. **入口路径**：控制台 → **模型** > **模型训练** > **模型压缩** → **创建压缩任务**。
3. **执行流程**：
   - 填写任务名称、描述；
   - 选择源模型（触发模板列表刷新）；
   - 选择量化模板；
   - （如需）配置校准数据；
   - 点击“开始压缩”（按钮仅在全部必填项合法后启用）。
4. **监控与排查**：
   - 任务详情页含“详情”与“日志”双页签，支持查看状态、配置、错误信息及着色日志；
   - 失败时优先检查“详情”页错误摘要，再搜索日志中 `ERROR` 级别条目；
   - 可下载全量日志用于深度分析。

## 限制和注意事项

- **不可逆性**：压缩后的模型**不支持继续微调**，也**不支持二次压缩**。任何调整均需回退至原始微调模型重新发起任务。
- **生命周期约束**：仅 `PENDING` 和 `RUNNING` 状态可停止；仅终态（`SUCCEEDED`/`FAILED`/`CANCELED`）可删除任务记录（不影响已产出模型）。
- **计费说明**：压缩任务本身限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按实际 MU 规格单独计费，与压缩是否免费无关。
- **精度权衡**：量化必然引入一定精度损失。建议在免费期内对同一源模型尝试多个量化模板，并使用业务测试集验证效果后再正式部署。
