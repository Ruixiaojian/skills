# model compression

模型压缩是百炼平台提供的量化能力，用于将全精度微调模型转换为低精度版本，在保持推理能力的前提下显著降低部署所需的 MU 规格与成本。该功能属于模型生产链路中的可选环节（微调 → 压缩 → 部署），仅作用于百炼平台产出的自定义微调模型，不支持结构剪枝或知识蒸馏等其他压缩范式。压缩操作不可逆，压缩后模型既不可继续微调，也不支持二次压缩。

## 支持的模型与功能

- **支持范围**：仅限通过百炼平台完成微调训练的自定义模型（即“微调产出模型”），不支持基础模型（如 `qwen3.5-flash-2026-02-23` 本身）或第三方上传模型。  
- **当前支持示例**：`qwen3.5-flash-2026-02-23` 微调模型压缩后部署规格可从 `MU1*2` 降至 `MU8*1`，成本节省约 56%（详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的表格）。  
- **功能边界**：百炼模型压缩特指**后训练量化（PTQ）**，不含剪枝、蒸馏等技术；校准数据仅用于提升量化精度，不参与模型权重更新。  
- **地域限制**：仅华北2（北京）地域可用。

> **注意**：原始文档中将 `qwen3.5-flash-2026-02-23` 列为“基础模型”并出现在“支持压缩的模型”表格中，但正文中明确强调“仅支持通过百炼平台微调产出的自定义模型”。该表述存在矛盾——实际可压缩对象必须是微调任务输出的模型实例（如 `my-qwen-ft-20240501`），而非基础模型名称本身。请以 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“仅支持通过百炼平台微调产出的自定义模型”为准。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符；建议含模型简称、量化方式、版本号（如 `qwen-ft-awq-mu8`） |
| **量化产出模型名后缀** | 是 | 仅小写字母+数字，≤8 位；将拼接至源模型名后（如源模型 `my-model` + 后缀 `awq` → `my-model-awq`） |
| **量化模板** | 是 | 卡片式选择；模板名中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失可能越高。切换源模型会清空已选模板。 |
| **校准数据** | 条件必填 | 仅当所选模板需校准输入时出现；最多选 5 个已发布数据集（不支持 OSS 挂载），需在[数据管理](https://help.aliyun.com/zh/model-studio/manage-data/#9d2f7039bfo1a)中创建并发布。 |

## 使用方式

1. **前提条件**：确保工作空间中已存在状态为“成功”的微调模型（参见 [模型调优](../../raw/model-user-guide/fine-tuning/fine-tuning-introduction.md)）；若无可选模型，请先完成微调。
2. **入口路径**：控制台 → **模型** > **模型训练** > **模型压缩** → **创建压缩任务**。
3. **配置与提交**：
   - 选择源模型（仅显示符合条件的微调模型）；
   - 指定量化模板（依赖源模型动态加载）；
   - 填写任务名称、后缀、可选描述及校准数据（如需）；
   - 点击**开始压缩**（所有必填项完成后按钮才启用）。
4. **监控与排查**：
   - 在任务详情页的**详情**页签查看状态、配置与错误信息；
   - 在**日志**页签筛选 `ERROR` 级别日志，支持下载全量日志；
   - 失败时请结合错误信息与日志分析，必要时提交工单并附任务 ID（参考 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“失败排查”章节）。

## 限制和注意事项

- **不可逆性**：压缩后模型不支持继续微调、不支持二次压缩；如需调整，必须回退至上游全精度微调模型重新发起压缩任务。
- **任务管理**：
  - PENDING / RUNNING 状态可**停止**（不可恢复）；
  - SUCCEEDED / FAILED / CANCELED 状态可**删除**（不影响已产出模型）；
  - QUEUING 状态不可删除。
- **计费说明**：压缩任务当前限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按 MU 规格单独计费，与压缩是否免费无关。
- **精度权衡**：量化必然引入精度损失，建议在免费期内对比多个模板 + 校准数据组合，使用业务测试集验证效果后再正式部署（详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“如何利用免费期确定最佳压缩方案”）。
