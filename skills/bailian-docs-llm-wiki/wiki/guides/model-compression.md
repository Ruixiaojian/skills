# model compression

模型压缩是百炼平台提供的量化能力，用于将全精度微调模型转换为低精度版本，在保持核心推理能力的前提下显著降低部署所需的 MU 规格与成本。该功能仅作用于百炼平台内完成的微调模型，不支持结构剪枝或知识蒸馏等其他压缩范式。压缩操作不可逆，且压缩后的模型无法继续微调或二次压缩。

## 支持的模型与功能

- **适用模型**：仅支持通过百炼平台微调产出的自定义模型（如 `qwen3.5-flash-2026-02-23`），不支持基础模型或第三方模型。具体支持列表以控制台实时展示为准，详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。
- **功能范围**：当前仅提供量化（Quantization）能力，明确区别于剪枝、蒸馏等技术；完整生产链路为：模型调优 → 模型压缩 → 模型部署，参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的功能概述部分。
- **地域限制**：仅华北2（北京）地域可用。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符，建议含模型简称、量化方式和版本号，便于追踪管理。 |
| **选择源模型** | 是 | 仅显示已成功微调的自定义模型；切换源模型会自动清空已选量化模板（因模板与模型强绑定）。 |
| **量化产出模型名后缀** | 是 | 仅限小写字母与数字，≤8 位；将拼接至源模型名后形成压缩模型唯一标识（如 `my-model-quant8`）。 |
| **量化模板** | 是 | 卡片式选择，模板名中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失可能增加；须先选定源模型方可加载对应模板。 |
| **校准数据** | 条件必填 | 仅当所选模板要求校准时出现；最多选 5 个已发布数据集（不支持 OSS 挂载），推荐选用与目标推理场景语义一致的数据，详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的校准数据说明。 |

> **注意**：文档中“压缩前部署规格 MU1\*2（¥108/小时）→ 压缩后 MU8\*1（¥47/小时）”为示例值，实际规格与价格请以控制台最新展示为准；不同模型系列的量化收益存在差异，不可直接套用该比例。

## 使用方式

1. **前提条件**：确保工作空间中已存在状态为“成功”的微调模型（参见 [模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)）。
2. **创建任务**：
   - 控制台路径：**模型 > 模型训练 > 模型压缩** → **创建压缩任务**；
   - 完整填写上述关键参数，确认无误后单击**开始压缩**（按钮仅在所有必填项合法时启用）。
3. **监控与排查**：
   - 任务详情页含**详情**与**日志**两个页签：详情页展示配置与状态，日志页支持按级别着色、行数筛选、自动刷新及全量下载；
   - 任务失败时，优先查看详情页错误信息，再搜索日志中 `ERROR` 级别条目，必要时提交工单并附任务 ID 和日志文件。

## 限制和注意事项

- **不可逆性**：压缩后模型不支持继续微调，也不支持二次压缩；如需调整，必须从原始全精度微调模型重新发起压缩任务。
- **任务管理**：
  - PENDING / RUNNING 状态可手动停止（停止后不可恢复）；
  - 仅终态（SUCCEEDED / FAILED / CANCELED）任务可删除，删除操作不影响已产出的压缩模型。
- **计费说明**：压缩任务当前限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按 MU 规格单独计费，与压缩是否免费无关。
- **精度权衡**：量化必然引入一定精度损失，建议在免费期内对同一源模型尝试多个量化模板，并使用真实业务测试集验证效果，再择优部署——该实践建议已在 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的常见问题章节中强调。
