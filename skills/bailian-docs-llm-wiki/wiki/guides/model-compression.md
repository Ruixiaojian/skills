# model compression

模型压缩是百炼平台提供的量化能力，用于将全精度微调模型转换为低精度版本，在保持可用推理能力的前提下显著降低部署所需的 MU 规格与成本。该功能仅作用于通过百炼完成的微调模型，不支持结构剪枝或知识蒸馏等其他压缩范式。压缩操作不可逆，且压缩后的模型不可继续微调或二次压缩 —— 详细背景请参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持范围**：仅限百炼平台微调产出的自定义模型（如 `qwen3.5-flash-2026-02-23`），不支持基础模型、第三方模型或 OSS 导入模型。  
- **功能边界**：当前仅提供**后训练量化（PTQ）**，不含剪枝、蒸馏或架构重参数化；校准数据可选（最多 5 个已发布数据集），用于提升量化精度。  
- **地域限制**：仅华北2（北京）地域可用。  
- **链路定位**：属于模型生产链路中的可选环节，必须在[模型调优](../../raw/model-user-guide/model-compression/model-compression-introduction.md)完成后执行，后续方可[模型部署](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

> **注意**：文档中示例 `qwen3.5-flash-2026-02-23` 的压缩后规格为 `MU8*1`，但实际控制台展示的模板命名以 `MUx` 编号为主（如 `MU4`、`MU8`），编号越大表示部署资源越小、成本越低，但需权衡精度损失 —— 具体模板支持情况请以控制台实时列表为准。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符，建议含模型简称+量化方式+版本号（如 `qwen35-flash-w4a4-mu8-v1`） |
| **量化产出模型名后缀** | 是 | 仅小写字母与数字，≤8 位；将拼接至源模型名后（如源模型 `my-qwen-ft` + 后缀 `w4a4` → `my-qwen-ft-w4a4`） |
| **量化模板** | 是 | 按源模型动态加载，卡片形式展示；模板名中 `MUx` 数值决定部署规格（如 `MU8` 对应 `MU8*1`） |
| **校准数据** | 条件必填 | 仅当所选模板要求校准时显示；须为已在[数据管理](../../raw/model-user-guide/model-compression/model-compression-introduction.md)中创建并发布的数据集，不支持 OSS 挂载 |

## 使用方式

1. **前提**：确保工作空间中存在状态为「成功」的微调模型（参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“前提条件”章节）。  
2. **入口**：控制台 → **模型** > **模型训练** > **模型压缩** → **创建压缩任务**。  
3. **配置**：依次填写任务名称、选择源模型（触发模板刷新）、设置后缀、选择量化模板、按需添加校准数据。  
4. **提交**：所有必填项完成后点击 **开始压缩**；任务创建后**不可修改配置**，请务必确认量化模板。  
5. **监控**：在任务列表页点击任务名进入详情页，通过 **详情** 页查看状态与配置，通过 **日志** 页排查（支持 ERROR 搜索、全量下载、暗色模式等）。  

失败时优先检查详情页错误信息，再结合日志中 `ERROR` 级别条目分析；仍无法解决请提交工单并附任务 ID 与日志文件。

## 限制和注意事项

- ✅ **仅支持微调模型**：基础模型（如 `qwen2.5-7b` 原始版）或非百炼训练的模型不可压缩。  
- ❌ **不可逆性**：压缩后模型**不支持继续微调**，也不支持再次压缩；如需调整，必须回退至上游全精度微调模型重新发起任务。  
- ⚠️ **状态约束**：仅 `PENDING`/`RUNNING` 任务可停止；仅终态（`SUCCEEDED`/`FAILED`/`CANCELED`）任务可删除；`QUEUING` 状态不可删除。  
- 💰 **计费说明**：压缩任务本身限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按实际 MU 规格计费，与压缩是否免费无关。  
- 📊 **效果验证建议**：利用免费期对同一源模型尝试多个量化模板，分别部署后使用**业务测试集**验证精度与延迟，避免仅依赖理论规格做决策 —— 参考 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“如何利用免费期确定最佳压缩方案”部分。
