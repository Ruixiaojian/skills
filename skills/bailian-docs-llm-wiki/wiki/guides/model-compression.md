# model compression

模型压缩是百炼平台提供的量化能力，通过降低模型参数精度（如 FP16 → INT8），在保持推理能力的前提下显著减少部署所需的 MU 规格与成本。该功能仅作用于百炼平台微调产出的自定义模型，属于模型生产链路中的可选环节（微调 → 压缩 → 部署），且压缩操作不可逆。详细背景与设计目标请参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持范围**：仅限百炼平台微调训练完成的自定义模型（如 `qwen3.5-flash-2026-02-23`），不支持基础模型、第三方模型或 OSS 导入模型。
- **技术范畴**：当前仅支持**量化（Quantization）**，明确不包含结构剪枝、知识蒸馏等其他压缩技术，详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“功能概述”部分。
- **地域限制**：仅华北2（北京）地域可用。
- **典型收益**：以 `qwen3.5-flash-2026-02-23` 为例，部署规格从 MU1\*2（¥108/小时）降至 MU8\*1（¥47/小时），成本节省约 56%。

> **注意**：文档中“压缩前部署规格”与“压缩后部署规格”的 MU 数值为示例，实际规格需以控制台实时展示为准；不同模型系列的量化模板命名规则及对应 MU 编号可能随平台迭代更新，请以 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 页面最新表格为准。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符，建议含模型简称、量化方式、版本号（如 `qwen35-int8-v1`） |
| **选择源模型** | 是 | 仅显示已成功完成微调的自定义模型；切换源模型将自动清空已选量化模板 |
| **量化产出模型名后缀** | 是 | 仅小写字母+数字，≤8 位（如 `int8`），将拼接至源模型名后生成新模型 ID |
| **量化模板** | 是 | 卡片式选择，模板名含 MU 编号（如 `MU8`），编号越大部署规格越小、成本越低，但潜在精度损失风险越高 |
| **校准数据** | 条件选填 | 仅当所选模板要求校准时出现；最多选 5 个已发布数据集（不支持 OSS 挂载），推荐选用与推理场景语义一致的数据 |

## 使用方式

1. **前提条件**：确保工作空间中存在状态为「成功」的微调模型（参见 [模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)）。
2. **入口路径**：控制台 → **模型** > **模型训练** > **模型压缩** → **创建压缩任务**。
3. **配置并提交**：填写上述关键参数，确认无误后单击**开始压缩**（按钮仅在所有必填项完成时启用）。
4. **监控与排查**：
   - 在任务详情页的 **详情** 页签查看状态、配置与错误信息；
   - 在 **日志** 页签筛选 `ERROR` 级别日志，支持下载全量日志用于深度分析；
   - 任务失败时，按 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“失败排查”步骤处理。

## 限制和注意事项

- **不可逆性**：压缩后的模型**不支持继续微调**，也**不支持二次压缩**；如需调整，必须回退至上游全精度微调模型重新发起任务。
- **任务管理**：
  - 创建后配置不可修改；
  - 仅 `PENDING` 和 `RUNNING` 状态可停止；
  - 仅终态（`SUCCEEDED`/`FAILED`/`CANCELED`）任务可删除，删除不影响已产出模型。
- **计费说明**：压缩任务本身限时免费（截止时间以控制台公告为准）；压缩后模型的**部署费用始终按 MU 规格计费**，与压缩是否免费无关。
- **精度验证**：量化可能导致精度下降，强烈建议在免费期内对比多个模板效果，并使用真实业务测试集验证推理质量——具体实践方法见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) “如何利用免费期确定最佳压缩方案”章节。
