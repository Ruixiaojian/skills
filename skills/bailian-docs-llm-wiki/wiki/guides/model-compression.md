# model compression

模型压缩是百炼平台提供的量化优化能力，专用于将全精度微调模型转换为低精度版本，在保持推理能力的前提下显著降低部署所需的 MU 规格与成本。该功能属于模型生产链路中的可选环节（微调 → 压缩 → 部署），**仅支持量化**，不涉及剪枝、蒸馏等其他压缩范式。压缩操作不可逆，且对输入模型、地域和工作流有明确约束。

## 支持的模型与功能

- **适用模型**：仅支持通过百炼平台完成微调训练的**自定义模型**（即“微调产出模型”），不支持基础模型（如 `qwen3.5-flash-2026-02-23` 本身）、第三方模型或未完成微调的中间产物。  
- **当前支持系列**：以 Qwen 系列为主，例如 `qwen3.5-flash-2026-02-23` 微调模型经压缩后可从 MU1\*2（¥108/小时）降至 MU8\*1（¥47/小时），成本节省约 56% —— 具体支持列表请以控制台实时展示为准，详见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。  
- **核心功能**：提供多档量化模板（按 MU 编号区分规格）、可选校准数据注入、任务级日志追踪与状态管理；所有能力均集成于控制台「模型 > 模型训练 > 模型压缩」路径下。

## 关键参数

创建压缩任务时需配置以下必填参数（参见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中「创建压缩任务」章节）：

| 参数 | 说明 |
|------|------|
| **任务名称** | 最长 50 字符，建议含模型简称、量化方式与版本号（如 `qwen35-ft-awq-v2`） |
| **量化产出模型名后缀** | 仅小写字母+数字，最长 8 位（如 `awq8`），将拼接至源模型名后生成新模型 ID |
| **量化模板** | 卡片式选择，MU 编号越大表示部署规格越小、成本越低，但潜在精度损失可能增加；**切换源模型会自动清空已选模板** |
| **校准数据（条件选填）** | 仅当所选模板要求校准时出现；最多选 5 个已发布数据集（不支持 OSS 挂载），推荐语义贴近目标场景的数据（如客服问答模型优先选用对话类数据集） |

> **注意**：参数一旦提交即锁定，任务创建后不可修改 —— 请在单击「开始压缩」前严格核对量化模板与校准数据配置，详见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的「重要」提示。

## 使用方式

1. **前提**：确保工作空间中存在状态为「成功」的微调模型（参见[模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)）；  
2. **入口**：控制台 → **模型 > 模型训练 > 模型压缩** → **创建压缩任务**；  
3. **配置**：依次填写任务名称、选择源模型（仅显示可压缩微调模型）、设置后缀、选取量化模板、按需添加校准数据；  
4. **执行**：确认无误后点击「开始压缩」，任务进入 `PENDING` → `QUEUING` → `RUNNING` → `SUCCEEDED`/`FAILED` 生命周期；  
5. **验证**：任务成功后，压缩模型将出现在模型中心，可立即部署并使用业务测试集验证效果。

## 限制和注意事项

- **地域限制**：仅华北2（北京）地域可用；  
- **模型限制**：仅支持百炼平台内微调产出的自定义模型，基础模型或外部导入模型不可压缩；  
- **不可逆性**：压缩后的模型**不支持继续微调，也不支持二次压缩**；若需调整，必须回退至上游全精度微调模型重新发起任务；  
- **免费策略**：压缩任务当前限时免费（截止时间以控制台公告为准），但压缩后模型的**部署费用始终按 MU 规格计费**，与免费期无关；  
- **失败排查**：任务失败时，优先查看详情页错误信息，再切换至「日志」页签搜索 `ERROR` 级别日志，必要时下载全量日志提交工单。  

> **注意**：文档中多次强调“压缩不可逆”及“不支持二次压缩”，但未明确说明是否允许对同一微调模型并发创建多个不同模板的压缩任务。根据控制台实际行为与任务列表设计（支持多任务并行），该操作是被允许的 —— 此处无矛盾，属正常功能设计。
