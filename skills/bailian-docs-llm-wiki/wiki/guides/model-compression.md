# model compression

模型压缩是百炼平台提供的量化优化能力，通过降低模型参数精度（如 FP16 → INT4），在保持推理能力的前提下显著减少部署所需的 MU 资源与成本。该功能仅作用于百炼平台微调产出的自定义模型，属于模型生产链路中“微调 → 压缩 → 部署”的可选环节，且压缩操作不可逆。详细背景与设计原则请参阅 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持范围**：仅限百炼平台完成微调训练的自定义模型（即 `fine-tuned` 状态的模型），不支持基础模型、第三方模型或未发布模型。
- **技术范畴**：当前仅支持**后训练量化（Post-Training Quantization, PTQ）**，不包含结构剪枝、知识蒸馏等其他压缩技术；具体实现细节见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。
- **地域限制**：仅华北2（北京）地域可用。
- **典型收益**：以 `qwen3.5-flash-2026-02-23` 微调模型为例，压缩后部署规格从 `MU1*2` 降至 `MU8*1`，小时成本由 ¥108 降至 ¥47，节省约 56% —— 实际效果因模型与模板而异，建议结合业务测试集验证。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符；建议含模型简称、量化方式、版本号（如 `qwen35-ft-v1-int4`），便于追踪。 |
| **选择源模型** | 是 | 仅显示当前工作空间内状态为 `SUCCEEDED` 的微调模型；切换源模型会自动清空已选量化模板。 |
| **量化产出模型名后缀** | 是 | 仅小写字母+数字，≤8 位（如 `int4`）；将拼接至源模型名后生成新模型 ID（如 `my-qwen-ft-int4`）。 |
| **量化模板** | 是 | 卡片式选择，模板名中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失可能增加；模板列表动态依赖所选源模型。 |
| **校准数据** | 条件必填 | 仅当所选模板需校准输入时出现；最多选 5 个已发布数据集（不支持 OSS 挂载），推荐语义贴近目标场景的数据（如客服问答场景优先选用对话类数据集）——详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的校准数据建议。 |

> **注意**：文档中“压缩前部署规格”与“压缩后部署规格”均为示例值，实际规格需以控制台实时展示为准；不同模型系列的 MU 映射关系可能随平台迭代更新，请以 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 页面最新表格为准。

## 使用方式

1. **前提条件**：确保工作空间中存在状态为 `SUCCEEDED` 的微调模型（参见 [模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)）。
2. **创建任务**：
   - 控制台路径：**模型 > 模型训练 > 模型压缩** → **创建压缩任务**
   - 填写全部必填参数，确认无误后点击 **开始压缩**（按钮仅在所有必填项合法时启用）
3. **监控进度**：
   - 任务列表页查看状态（共 7 种状态，含 `PENDING`/`RUNNING`/`SUCCEEDED`/`FAILED` 等）
   - 进入详情页，切换 **日志** 页签：支持按行数筛选、ERROR 日志高亮、全量日志下载；失败时优先检查 ERROR 日志及详情页错误信息
4. **后续操作**：
   - 成功任务：`压缩后模型` 列可点击跳转至模型中心，用于部署
   - 失败任务：下载日志并提交工单（附任务 ID 和日志文件）
   - 终态任务（`SUCCEEDED`/`FAILED`/`CANCELED`）：支持删除（不影响已产出模型）

## 限制和注意事项

- **不可逆性**：压缩后的模型**不支持继续微调**，也**不支持二次压缩**；若需调整，必须基于原始全精度微调模型重新发起压缩任务。
- **地域与模型限制**：仅华北2（北京）可用；仅支持百炼微调产出模型，基础模型或导入模型不可选。
- **免费策略**：压缩任务本身限时免费（截止时间以控制台公告为准），但**压缩后模型的部署费用始终按 MU 规格计费**，与免费期无关。
- **模板选择建议**：MU 编号越大 ≠ 绝对更优，需权衡精度与成本；强烈建议在免费期内对同一源模型尝试多个模板，部署后用真实业务测试集验证效果 —— 具体方法参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“如何利用免费期确定最佳压缩方案”章节。
- **API 支持**：如需自动化管理，可使用 [模型压缩 API 参考](https://help.aliyun.com/zh/model-studio/model-compression-api#h1-e183f6b9)，但 API 行为与控制台一致，受相同限制约束。
