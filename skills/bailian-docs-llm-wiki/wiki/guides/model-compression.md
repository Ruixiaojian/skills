# model compression

模型压缩是百炼平台提供的量化优化能力，通过降低模型参数精度（如 FP16 → INT4），在可控精度损失前提下显著减少推理部署所需的 MU 资源与成本。该功能仅作用于百炼平台微调产出的自定义模型，属于模型生产链路中的可选环节（微调 → 压缩 → 部署），且压缩操作不可逆。详细背景与适用场景请参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持模型**：仅限通过百炼平台完成微调训练的自定义模型（如 `qwen3.5-flash-2026-02-23`），不支持基础模型、第三方模型或非百炼微调产出的模型。具体支持列表以控制台实时展示为准。
- **功能范围**：当前仅支持**后训练量化（PTQ）**，不包含结构剪枝、知识蒸馏等其他压缩技术；详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“功能概述”章节。
- **地域限制**：仅华北2（北京）地域可用。

> **注意**：文档中示例 `qwen3.5-flash-2026-02-23` 的压缩前后规格（MU1\*2 → MU8\*1）为示意数据，实际支持模型及对应规格请以控制台创建页面动态加载结果为准；部分新上线模型可能尚未同步至文档示例表中，最新兼容性请参考 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的“支持压缩的模型”小节。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符，建议含模型简称、量化方式、版本号（如 `qwen35-fp16-to-int4-v1`） |
| **选择源模型** | 是 | 仅显示当前工作空间内状态为“成功”的微调模型；切换源模型将自动清空已选量化模板 |
| **量化产出模型名后缀** | 是 | 仅小写字母+数字，≤8 位（如 `int4`），将拼接至源模型名后形成新模型 ID（如 `my-qwen35-int4`） |
| **量化模板** | 是 | 卡片式选择，模板名中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失风险越高 |
| **校准数据** | 条件必填 | 仅当所选模板需校准输入时出现；最多选 5 个已发布数据集（不支持 OSS 挂载），推荐与目标推理场景语义一致的数据 |

## 使用方式

1. **前提**：确保工作空间中存在状态为“成功”的微调模型；若无，请先完成 [模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)。
2. **入口**：控制台 → **模型** > **模型训练** > **模型压缩** → **创建压缩任务**。
3. **配置**：按上述关键参数填写，特别注意：
   - 量化模板选定后不可修改；
   - 校准数据须提前在[数据管理](https://help.aliyun.com/zh/model-studio/manage-data/#9d2f7039bfo1a)中创建并发布；
   - 所有必填项完成后，“开始压缩”按钮才可点击。
4. **监控**：任务创建后进入列表页，单击任务名称查看**详情**（含状态、配置）与**日志**（支持 ERROR 级别筛选、全量下载）。
5. **管理**：支持对 PENDING/RUNNING 任务执行**停止**；仅 SUCCEEDED/FAILED/CANCELED 状态任务可**删除**（删除记录不影响已产出模型）。

## 限制和注意事项

- **不可逆性**：压缩后的模型**不支持继续微调**，也**不支持二次压缩**；如需调整，必须从原始全精度微调模型重新发起压缩任务 —— 此限制在 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) “重要”提示中明确强调。
- **计费说明**：压缩任务本身限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按 MU 规格单独计费，与压缩是否免费无关。
- **失败排查**：任务失败时，优先在**详情**页查看错误信息，再在**日志**页搜索 `ERROR`，必要时下载全量日志提交工单。
- **免费期策略**：建议利用免费期对同一源模型尝试多个量化模板，分别部署并用业务测试集验证效果，综合精度与成本选择最优方案 —— 具体实践方法见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) “如何利用免费期确定最佳压缩方案”小节。
