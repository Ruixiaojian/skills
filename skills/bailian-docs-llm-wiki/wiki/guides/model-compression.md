# model compression

模型压缩是百炼平台提供的量化优化能力，专用于将全精度微调模型转换为低精度版本，在保障推理效果的前提下显著降低部署所需的 MU 规格与成本。该功能属于模型生产链路中的可选环节，必须在完成模型微调后执行，且压缩操作不可逆。详细背景和设计目标请参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持范围**：仅限通过百炼平台完成微调训练的自定义模型（即“微调产出模型”），不支持基础模型、第三方模型或未完成微调的中间模型。
- **模型示例**：当前明确支持 `qwen3.5-flash-2026-02-23` 等 Qwen 系列微调模型；实际可用模型以控制台动态列表为准，详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的表格说明。
- **功能边界**：百炼模型压缩特指**后训练量化（PTQ）**，不包含结构剪枝、知识蒸馏等其他压缩技术。如需了解技术定位差异，请参考 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的“量化与剪枝、蒸馏有什么区别？”章节。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符；建议含模型简称、量化方式、版本号（如 `qwen35-flash-w4a16-v1`） |
| **量化产出模型名后缀** | 是 | 仅小写字母+数字，≤8 位；将拼接至源模型名后（如源模型 `my-qwen-ft` + 后缀 `w4a16` → 输出 `my-qwen-ft-w4a16`） |
| **量化模板** | 是 | 卡片式选择；模板名中 MU 编号越大（如 `MU8` > `MU4`），部署规格越小、成本越低，但潜在精度损失可能越高 |
| **校准数据** | 条件必填 | 仅当所选模板要求校准时显示；最多选 5 个已发布数据集（不支持 OSS 挂载），语义应贴近目标推理场景 |

> **注意**：切换源模型会自动清空已选量化模板——因不同模型支持的模板集合不同，此行为已在 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中明确说明。

## 使用方式

1. **前提**：确保工作空间中存在状态为“成功”的微调模型（参见 [模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)）；
2. 控制台路径：**模型** > **模型训练** > **模型压缩** > **创建压缩任务**；
3. 填写全部必填参数，确认无误后单击**开始压缩**（按钮仅在所有必填项合法时启用）；
4. 任务创建后不可修改配置，可通过任务列表页查看状态、日志及详情；
5. 成功后，压缩模型将出现在模型中心，可直接用于[模型部署](https://help.aliyun.com/zh/model-studio/model-deployment-1/#3bc53b23c7shc)。

## 限制和注意事项

- **地域限制**：仅华北2（北京）地域可用；
- **不可逆性**：压缩后的模型**不支持继续微调**，也**不支持二次压缩**；如需调整，必须回退至原始微调模型重新发起任务；
- **任务管理**：
  - 仅 `PENDING` / `RUNNING` 状态可停止；
  - 仅终态（`SUCCEEDED` / `FAILED` / `CANCELED`）可删除；
  - 删除任务记录不影响已产出的压缩模型；
- **计费**：压缩任务当前限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按 MU 规格单独计费，与压缩是否免费无关；
- **精度验证**：量化必然引入一定精度损失，强烈建议在免费期内对同一源模型尝试多个量化模板，并使用**业务真实测试集**验证推理效果后再上线。

> **注意**：文档中“压缩前部署规格 MU1\*2（¥108/小时）→ 压缩后 MU8\*1（¥47/小时）”为示例数据，实际规格与价格请以控制台实时展示为准；若发现控制台与 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的规格数值不一致，应以控制台为准。
