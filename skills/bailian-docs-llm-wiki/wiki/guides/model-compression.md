# model compression

模型压缩是百炼平台提供的量化能力，用于将全精度微调模型转换为低精度版本，在保持推理能力基本稳定的前提下显著降低部署所需的 MU 规格与成本。该功能属于模型生产链路中的可选环节，位于[模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)之后、[模型部署](https://help.aliyun.com/zh/model-studio/model-deployment-1/#3bc53b23c7shc)之前。**注意：压缩不可逆，压缩后模型不支持继续微调或二次压缩**，相关说明详见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持模型类型**：仅限通过百炼平台完成微调训练的自定义模型（即“微调产出模型”），不支持基础模型（如 `qwen3.5-flash-2026-02-23` 原始版本）或第三方导入模型。
- **当前支持系列示例**：Qwen 系列（如 `qwen3.5-flash-2026-02-23`），压缩后部署规格可从 MU1\*2 降至 MU8\*1，成本节省约 56%（数据来源见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md)）。
- **功能范围**：当前仅支持**量化（Quantization）**，明确不包含结构剪枝、知识蒸馏等其他压缩技术；完整能力边界请参考 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“功能概述”章节。

## 关键参数

创建压缩任务时需配置以下必填参数：

| 参数 | 说明 |
|------|------|
| **任务名称** | 最长 50 字符，建议含模型简称、量化方式和版本号（如 `qwen35-fp16-to-int4-v1`）。 |
| **选择源模型** | 仅展示当前工作空间中状态为“成功”的微调模型；切换源模型会自动清空已选量化模板。 |
| **量化产出模型名后缀** | 仅支持小写字母+数字，最长 8 位（如 `int4`），将拼接至源模型名后生成新模型标识。 |
| **量化模板** | 卡片式选择，模板名中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失可能增加。须先选定源模型才可加载对应模板列表。 |
| **校准数据（条件选填）** | 仅当所选模板要求校准时出现；最多选 5 个已发布数据集（不支持 OSS 挂载），建议语义贴近目标推理场景。 |

> **注意**：所有参数在任务创建后不可修改，请务必在单击“开始压缩”前确认无误。

## 使用方式

1. **前提**：确保工作空间中存在状态为“成功”的微调模型（参见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“前提条件”）。
2. **入口**：控制台 → **模型** > **模型训练** > **模型压缩** → **创建压缩任务**。
3. **配置并提交**：按上述关键参数完成填写，全部必填项校验通过后，“开始压缩”按钮激活。
4. **监控进度**：在任务列表页点击任务名进入详情页，通过 **详情** 页签查看状态与配置，通过 **日志** 页签实时跟踪执行过程（支持 ERROR 搜索、全量日志下载等）。
5. **结果使用**：任务状态为 `SUCCEEDED` 后，压缩后模型将出现在模型中心，可直接用于部署。

## 限制和注意事项

- **地域限制**：仅华北2（北京）地域可用。
- **模型来源限制**：仅支持百炼平台内微调产出的自定义模型；基础模型、OSS 导入模型、API 创建的模型均不支持。
- **不可逆性**：压缩后模型**不支持继续微调、不支持二次压缩**，且无法还原为原始精度（此限制在 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中多次强调）。
- **任务管理**：
  - 仅 `PENDING` / `RUNNING` 状态可停止；
  - 仅终态（`SUCCEEDED` / `FAILED` / `CANCELED`）可删除；
  - 删除任务记录不影响已产出的压缩模型。
- **计费**：压缩任务当前限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按 MU 规格单独计费，与压缩是否免费无关。
