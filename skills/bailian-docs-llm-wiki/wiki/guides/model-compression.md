# model compression

模型压缩是百炼平台提供的量化能力，用于将全精度微调模型转换为低精度版本，在保持推理能力的前提下显著降低部署所需的 MU 规格与成本。该功能属于模型生产链路中的可选环节，必须在完成模型微调后执行，且压缩操作不可逆。详细背景与设计目标请参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持模型**：仅限通过百炼平台微调产出的自定义模型（如 `qwen3.5-flash-2026-02-23`），不支持基础模型、第三方模型或非微调来源模型。  
- **功能范围**：当前仅支持**后训练量化（PTQ）**，不包含结构剪枝、知识蒸馏等其他压缩技术；详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“功能概述”章节。  
- **地域限制**：仅华北2（北京）地域可用。

> **注意**：文档中示例 `qwen3.5-flash-2026-02-23` 的压缩前后规格（MU1\*2 → MU8\*1）为示意数据，实际支持模型列表及对应规格以控制台实时展示为准，请务必在创建任务前确认源模型状态和模板兼容性 —— 参考 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的“支持压缩的模型”表格。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符，建议含模型简称、量化方式、版本号（如 `qwen35-fp16-to-int4-v1`） |
| **选择源模型** | 是 | 仅显示已成功完成微调的自定义模型；切换源模型会自动清空已选量化模板 |
| **量化产出模型名后缀** | 是 | 仅小写字母+数字，≤8 位（如 `int4`），将拼接至源模型名后生成新模型标识 |
| **量化模板** | 是 | 卡片式选择，模板名中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失可能增加 |
| **校准数据** | 条件选填 | 仅当所选模板需校准输入时出现；最多选 5 个已发布数据集（不支持 OSS 挂载） |

## 使用方式

1. 确保工作空间中存在**状态为“成功”的微调模型**（参见 [模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)）；  
2. 控制台路径：**模型 > 模型训练 > 模型压缩** → 单击**创建压缩任务**；  
3. 按上述关键参数完成配置，特别注意：**量化模板选定后不可修改**，创建前须充分验证；  
4. 单击**开始压缩**，任务进入 `PENDING` 状态；  
5. 通过任务列表页或详情页监控状态（支持 `PENDING`/`QUEUING`/`RUNNING`/`SUCCEEDED`/`FAILED`/`CANCELING`/`CANCELED` 七种状态）；  
6. 成功后，压缩模型自动出现在模型中心，可直接用于部署 —— 部署流程详见 [模型部署](https://help.aliyun.com/zh/model-studio/model-deployment-1/#3bc53b23c7shc)，其计费按 MU 规格独立计算。

## 限制和注意事项

- **不可逆性**：压缩后的模型**不支持继续微调**，也**不支持二次压缩**；若需调整，必须回到上游全精度微调模型重新发起任务（[原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 明确强调此限制）。  
- **数据依赖**：校准数据必须在百炼平台内创建并**发布**（非仅上传），且仅支持平台内置数据集，不支持外部 OSS 路径。  
- **失败排查**：任务失败时，优先查看详情页错误信息，再切换至**日志**页签搜索 `ERROR`，必要时下载全量日志并附任务 ID 提交工单。  
- **免费策略**：压缩任务本身限时免费（截止时间以控制台公告为准），但**压缩后模型的部署费用始终按 MU 规格实时计费**，与免费期无关。  
- **模板验证建议**：利用免费期对同一微调模型尝试多个量化模板，分别部署并用业务测试集验证效果，再择优上线 —— 此实践指南出自 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的“如何利用免费期确定最佳压缩方案”章节。
