# model compression

模型压缩是百炼平台提供的量化能力，用于将全精度微调模型转换为低精度版本，在保持可用推理能力的前提下显著降低部署所需的 MU 规格与成本。该功能属于模型生产链路中的可选环节（微调 → 压缩 → 部署），仅支持对百炼平台产出的自定义微调模型执行，且压缩操作不可逆。详细背景和设计约束请参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **适用模型**：仅支持通过百炼平台完成微调训练的自定义模型（如 `qwen3.5-flash-2026-02-23`），不支持基础模型、第三方模型或非百炼微调产出的模型。  
- **技术范畴**：当前仅实现**后训练量化（PTQ）**，不包含结构剪枝、知识蒸馏等其他压缩技术；详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“功能概述”部分。  
- **地域限制**：仅在华北2（北京）地域可用。  
- **输出标识**：压缩后模型名称由源模型名 + 用户指定的 `量化产出模型名后缀`（小写字母/数字，≤8位）自动拼接生成。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50字符，建议含模型简称、量化方式与版本号，便于追踪 |
| **选择源模型** | 是 | 仅展示当前工作空间内已完成且状态为“成功”的微调模型；切换源模型会清空已选量化模板 |
| **量化产出模型名后缀** | 是 | 决定压缩后模型的唯一标识，非法字符自动过滤 |
| **量化模板** | 是 | 卡片式选择，模板名中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失可能增加；需先选定源模型才可加载对应模板列表 |
| **校准数据** | 条件必填 | 仅当所选模板要求校准时显示；最多选 5 个已发布数据集（不支持 OSS 挂载），推荐与目标推理场景语义一致的数据 |

> **注意**：文档中多次强调“压缩不可逆”，且明确指出“压缩后的模型不支持继续微调，也不支持二次压缩”。该限制在 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的“重要”提示及“常见问题”中均一致，无矛盾。

## 使用方式

1. **前提条件**：确保工作空间中存在状态为“成功”的百炼微调模型；若无，请先完成 [模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)。  
2. **入口路径**：控制台 → **模型** > **模型训练** > **模型压缩** → **创建压缩任务**。  
3. **配置并提交**：按上述关键参数填写，所有必填项完成后“开始压缩”按钮方可点击；提交后配置不可修改。  
4. **监控与排查**：在任务详情页的 **详情** 页签查看状态与配置，在 **日志** 页签分析运行过程（支持 ERROR 级别高亮、全量日志下载等）；失败时优先检查错误信息与日志中的 `ERROR` 行。  
5. **管理任务**：支持按状态（PENDING/QUEUING/RUNNING/SUCCEEDED/FAILED/CANCELING/CANCELED）、量化模板、时间范围等筛选；仅终态任务（SUCCEEDED/FAILED/CANCELED）可删除，PENDING 和 RUNNING 状态可手动停止。

## 限制和注意事项

- **不可逆性**：压缩为单向操作，压缩后模型无法继续微调，亦不支持二次压缩；任何调整均需回退至上游全精度微调模型重新发起任务。  
- **地域与模型来源强约束**：仅华北2（北京）可用；仅限百炼微调产出模型，基础模型或导入模型不可选。  
- **免费期策略**：压缩任务本身限时免费（截止时间以控制台公告为准），但压缩后模型的部署费用始终按 MU 规格计费，不受免费期影响；建议利用免费期对比多模板效果，详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“如何利用免费期确定最佳压缩方案”。  
- **校准数据限制**：仅支持控制台数据管理中已创建并发布的数据集，不支持 OSS 路径或未发布数据集。  
- **API 支持**：如需自动化集成，可参考 [模型压缩 API 参考](https://help.aliyun.com/zh/model-studio/model-compression-api#h1-e183f6b9)，其能力与控制台一致。
