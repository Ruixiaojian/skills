# model compression

模型压缩是百炼平台提供的量化优化能力，通过降低模型参数精度（如 FP16 → INT4/INT8），在保持推理能力的前提下显著减少部署所需的 MU 规格与成本。该功能仅作用于百炼平台微调产出的自定义模型，属于模型生产链路中的可选环节（微调 → 压缩 → 部署），且压缩操作不可逆。详细背景与设计原则请参阅 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持模型**：仅限通过百炼平台完成微调训练的自定义模型，当前明确支持 `qwen3.5-flash-2026-02-23` 等 Qwen 系列微调模型；基础模型、第三方模型或未在百炼完成微调的模型均不支持。具体可用模型列表以控制台实时展示为准。
- **功能范围**：当前仅支持**后训练量化（Post-Training Quantization, PTQ）**，不包含结构剪枝、知识蒸馏等其他压缩技术。详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“功能概述”章节。
- **地域限制**：仅华北2（北京）地域可用。

> **注意**：原始文档中“支持压缩的模型”表格仅列出单个示例模型，但正文中明确说明“具体以控制台展示为准”。实际支持范围可能随平台迭代扩展，开发者应以控制台模型选择弹窗的实时选项为唯一权威依据，而非静态表格。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符，建议含模型简称、量化方式、版本号（如 `qwen35-ft-int4-v1`） |
| **量化产出模型名后缀** | 是 | 仅小写字母+数字，≤8 位（如 `int4`），将拼接至源模型名后生成新模型 ID |
| **量化模板** | 是 | 卡片式选择，模板名中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失可能增加。切换源模型会清空已选模板。 |
| **校准数据** | 条件选填 | 仅当所选模板需校准输入时显示；最多选 5 个已发布数据集（不支持 OSS 挂载），推荐使用与目标场景语义一致的数据（如客服问答场景选对话数据集） |

## 使用方式

1. **前提条件**：确保工作空间中存在状态为“成功”的微调模型（参见 [模型调优](../../raw/model-user-guide/model-compression/model-compression-introduction.md)）。
2. **创建任务**：
   - 控制台路径：**模型 > 模型训练 > 模型压缩** → **创建压缩任务**
   - 完整填写必填参数，确认量化模板无误（创建后不可修改）
   - 单击**开始压缩**（按钮仅在所有必填项合法时启用）
3. **监控与排查**：
   - 任务详情页含 **详情**（状态、配置、错误信息）和 **日志**（可筛选级别、下载全量、自动刷新）两个页签
   - 任务失败时，优先查看详情页错误信息，再搜索日志中 `ERROR` 行，必要时提交工单并附任务 ID 与日志文件

## 限制和注意事项

- **不可逆性**：压缩后的模型**不支持继续微调**，也**不支持二次压缩**。请务必在压缩前确认量化模板与校准数据选择。
- **模型来源限制**：仅支持百炼平台微调产出的自定义模型，基础模型或导入的 Hugging Face 模型不可用。
- **任务管理**：
  - 仅 `PENDING` 和 `RUNNING` 状态可停止；仅终态（`SUCCEEDED`/`FAILED`/`CANCELED`）可删除
  - 删除任务记录不影响已产出的压缩后模型
- **计费说明**：压缩任务本身限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按 MU 规格单独计费，与压缩是否免费无关。成本节省效果因模型与模板而异（例如 `qwen3.5-flash-2026-02-23` 压缩后部署成本可降约 56%，详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)）。
- **精度权衡**：量化必然引入精度损失。强烈建议在免费期内对同一微调模型尝试多个量化模板，并使用业务测试集验证推理效果，再选定最优方案上线。
