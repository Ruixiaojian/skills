# model compression

模型压缩是百炼平台提供的量化优化能力，通过降低模型参数精度（如 FP16 → INT4），在保持推理能力的前提下显著减少部署所需的 MU 资源与成本。该功能仅作用于百炼平台微调产出的自定义模型，属于模型生产链路中可选但关键的一环：[模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634) → 模型压缩 → [模型部署](https://help.aliyun.com/zh/model-studio/model-deployment-1/#3bc53b23c7shc)。压缩操作不可逆，且不支持后续微调或二次压缩。

## 支持的模型与功能

- **支持模型**：仅限通过百炼平台完成微调训练的自定义模型（如 `qwen3.5-flash-2026-02-23`），不支持基础模型、第三方模型或 OSS 直接上传模型。具体支持列表以控制台实时展示为准，详见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。
- **功能范围**：当前仅支持量化（Quantization），**不包含结构剪枝、知识蒸馏等其他压缩技术**。所有量化模板均基于校准感知（Calibration-aware）的后训练量化（PTQ）实现。
- **地域限制**：仅华北2（北京）地域可用。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符；建议含模型简称、量化方式（如 `int4`）、版本号，便于追踪。 |
| **选择源模型** | 是 | 仅显示已成功微调且状态为 `SUCCEEDED` 的自定义模型；切换源模型将自动清空已选量化模板。 |
| **量化产出模型名后缀** | 是 | 仅小写字母+数字，≤8 位；将拼接至源模型名后（如源模型 `my-qwen-ft` + 后缀 `int4` → `my-qwen-ft-int4`）。 |
| **量化模板** | 是 | 卡片式选择；模板名中 MU 编号越大（如 `MU8` vs `MU2`），部署规格越小、成本越低，但潜在精度损失可能越高。须先选定源模型后才可加载对应模板列表。 |
| **校准数据** | 条件必填 | 仅当所选模板要求校准时显示；最多选 5 个已发布数据集（需在[数据管理](https://help.aliyun.com/zh/model-studio/manage-data/#9d2f7039bfo1a)中创建并发布），不支持 OSS 挂载数据集。 |

> **注意**：量化模板的 MU 编号与实际部署规格严格对应（如 `MU8*1`），但不同模型系列的 MU 编号不可跨系列横向比较性能。请以 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的示例（`qwen3.5-flash-2026-02-23` 压缩前后规格对比）为基准验证效果。

## 使用方式

1. **前提**：确保工作空间中存在状态为 `SUCCEEDED` 的微调模型（参见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“前提条件”章节）。
2. **入口**：控制台 → **模型** > **模型训练** > **模型压缩** → **创建压缩任务**。
3. **配置**：按上述关键参数填写，特别注意：
   - 量化模板一旦选定不可修改；
   - 校准数据必须与目标推理场景语义一致（如客服场景优先选用客服对话数据集）；
   - 所有必填项完成后，“开始压缩”按钮才可点击。
4. **监控**：任务创建后，在列表页点击任务名称进入详情页，通过 **详情** 和 **日志** 页签跟踪状态与错误（日志支持 ERROR 级别高亮、全量下载）。
5. **验证**：任务状态变为 `SUCCEEDED` 后，压缩模型将出现在模型中心；**务必使用业务测试集进行推理验证**，确认精度满足要求后再部署。

## 限制和注意事项

- **不可逆性**：压缩后的模型不支持继续微调，也不支持二次压缩。如需调整，请从原始全精度微调模型重新发起压缩任务。
- **地域与模型限制**：仅华北2（北京）可用；仅支持百炼微调产出的自定义模型。
- **任务管理**：
  - PENDING/RUNNING 状态可手动停止（停止后不可恢复）；
  - 仅终态（`SUCCEEDED`/`FAILED`/`CANCELED`）任务可删除，删除不影响已产出模型；
  - 任务配置创建后不可修改。
- **计费**：压缩任务当前限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按实际 MU 规格计费，与压缩是否免费无关。
- **精度权衡**：量化必然引入一定精度损失。若验证发现精度不达标，应更换量化模板或补充校准数据重试，而非尝试修复压缩模型。
