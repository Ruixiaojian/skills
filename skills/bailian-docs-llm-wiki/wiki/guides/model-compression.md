# model compression

模型压缩是百炼平台提供的量化优化能力，通过降低模型参数精度（如 FP16 → INT8），在保持推理能力基本不变的前提下显著减少部署所需的 MU 资源和成本。该功能仅作用于百炼平台微调产出的自定义模型，属于模型生产链路中“微调→压缩→部署”的可选环节，且压缩操作不可逆。详细背景与设计目标请参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持范围**：仅限通过百炼平台完成微调训练的自定义模型（即 `fine-tuned` 状态的模型），不支持基础模型、第三方模型或未完成微调的中间检查点。  
- **技术范畴**：当前仅支持**后训练量化（Post-Training Quantization, PTQ）**，不包含结构剪枝、知识蒸馏等其他压缩技术。具体能力边界详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。  
- **地域限制**：仅华北2（北京）地域可用。  
- **典型收益**：以 `qwen3.5-flash-2026-02-23` 微调模型为例，压缩后部署规格从 `MU1*2` 降至 `MU8*1`，小时成本由 ¥108 降至 ¥47，节省约 56% —— 实际效果因模型与模板而异，建议结合业务测试集验证，参考 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的免费期实践建议。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符；建议含模型简称、量化方式、版本号（如 `qwen35-ft-v1-int8`），便于追踪。 |
| **选择源模型** | 是 | 仅展示当前工作空间内状态为 `succeeded` 的微调模型；切换源模型会自动清空已选量化模板。 |
| **量化产出模型名后缀** | 是 | 仅小写字母+数字，≤8 位（如 `int8`）；将拼接至源模型名后生成新模型 ID（如 `my-qwen-ft-int8`）。 |
| **量化模板** | 是 | 卡片式选择；模板名中 `MU` 编号越大，部署规格越小、成本越低，但潜在精度损失可能增加。须先选定源模型才可加载对应模板列表。 |
| **校准数据** | 条件必填 | 仅当所选模板要求校准时显示；最多选 5 个已发布数据集（不支持 OSS 挂载），需语义贴近目标推理场景（如客服场景用对话数据集）。 |

> **注意**：文档中“校准数据”字段标注为“条件选填”，但实际逻辑为“所选模板若含校准输入参数则必填”。该行为与控制台 UI 一致，开发者应以创建页动态提示为准，而非静态描述。

## 使用方式

1. **前提**：确保工作空间中存在状态为 `succeeded` 的微调模型（参见 [模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)）。  
2. **入口**：控制台 → **模型** > **模型训练** > **模型压缩** → **创建压缩任务**。  
3. **配置**：按上述关键参数填写，特别注意量化模板与校准数据的联动关系。  
4. **提交**：所有必填项完成后点击**开始压缩**；任务创建后**不可修改配置**，请务必确认再提交。  
5. **监控**：在任务列表页点击任务名进入详情页，通过**详情**页查看状态与配置，通过**日志**页（支持 ERROR 级别高亮、全量下载）排查问题。任务状态共 7 种，含 `PENDING`/`QUEUING`/`RUNNING`/`SUCCEEDED`/`FAILED`/`CANCELING`/`CANCELED`，详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 限制和注意事项

- **不可逆性**：压缩后的模型**不支持继续微调**，也**不支持二次压缩**；如需调整，必须回退至原始微调模型重新发起任务。  
- **模型依赖**：仅支持百炼平台微调产出的模型，基础模型（如 `qwen3.5-flash-2026-02-23` 原始版）无法直接压缩。  
- **计费说明**：压缩任务本身限时免费（截止时间以控制台公告为准），但压缩后模型的**部署阶段仍按 MU 规格正常计费**。  
- **失败处理**：任务失败时，优先查看详情页错误信息，再搜索日志中的 `ERROR` 条目；必要时下载全量日志并附任务 ID 提交工单。  
- **模板选择建议**：不要仅依据 MU 编号盲目追求低成本；应在免费期内对同一源模型尝试多个模板，部署后使用真实业务测试集验证效果，平衡精度与成本 —— 具体方法见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的实践指南。
