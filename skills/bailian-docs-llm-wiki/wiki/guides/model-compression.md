# model compression

模型压缩是百炼平台提供的量化能力，用于将全精度微调模型转换为低精度版本，在保障推理效果的前提下显著降低部署所需的 MU 规格与成本。该功能属于模型生产链路中的可选环节，必须在完成模型微调后执行，且压缩操作不可逆。详细背景与设计边界请参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持范围**：仅限通过百炼平台完成微调训练的自定义模型（即“微调产出模型”），不支持基础模型、第三方模型或未完成微调的中间模型。
- **技术范畴**：当前仅支持**量化（Quantization）**，明确不包含结构剪枝、知识蒸馏等其他压缩技术；此限定已在 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中明确定义。
- **典型收益**：以 `qwen3.5-flash-2026-02-23` 微调模型为例，压缩后部署规格可从 `MU1*2` 降至 `MU8*1`，小时成本由 ¥108 降至 ¥47，节省约 56%。

> **注意**：文档中“压缩前部署规格”与“压缩后部署规格”的 MU 表达存在歧义（如 `MU1*2` vs `MU8*1`）。实际含义为：前者需 2 个 MU1 实例并行，后者仅需 1 个 MU8 实例；二者算力总量接近，但 MU8 单实例成本更低。该细节需结合 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的计费说明交叉理解，避免误读为算力降级。

## 关键参数

创建压缩任务时需配置以下必填参数：

| 参数 | 说明 |
|------|------|
| **任务名称** | 最长 50 字符，建议含模型简称、量化方式、版本号（如 `qwen35f-awq-mu8-v1`） |
| **量化产出模型名后缀** | 仅小写字母+数字，最长 8 位；将拼接至源模型名后生成新模型 ID（如源模型 `my-qwen-ft-001` + 后缀 `awq8` → `my-qwen-ft-001-awq8`） |
| **量化模板** | 卡片式选择，名称中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失可能增加；**切换源模型会自动清空已选模板**（因模板与模型强绑定） |
| **校准数据** | 条件选填：仅当所选模板要求校准时才显示；最多选 5 个已发布数据集（不支持 OSS 挂载），推荐选用与目标推理场景语义一致的样本 |

## 使用方式

1. **前提**：确保工作空间中已存在状态为 **SUCCEEDED** 的微调模型；若无可选模型，请先完成 [模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)。
2. **入口**：控制台 → **模型** > **模型训练** > **模型压缩** → **创建压缩任务**。
3. **配置与提交**：填写任务名称、后缀、选择源模型（触发模板加载）、选定量化模板、按需添加校准数据，确认无误后单击 **开始压缩**。
4. **监控**：任务创建后不可修改配置；可通过详情页查看状态（含 PENDING / RUNNING / SUCCEEDED 等 7 种状态）与日志（支持 ERROR 搜索、全量下载）；失败时优先检查详情页错误信息及日志中 `ERROR` 行。
5. **管理**：支持对终态任务（SUCCEEDED / FAILED / CANCELED）执行删除；PENDING 或 RUNNING 任务可手动停止（不可恢复）。

完整操作流程与界面说明详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 限制和注意事项

- **地域限制**：仅华北2（北京）地域可用。
- **模型来源限制**：仅支持百炼平台内微调产出的自定义模型；基础模型（如 `qwen3.5-flash-2026-02-23` 原始版）不可直接压缩。
- **不可逆性**：
  - 压缩后的模型**不支持继续微调**；
  - **不支持二次压缩**；
  - 所有配置在提交后不可修改——务必在单击“开始压缩”前确认量化模板与校准数据。
- **免费策略**：压缩任务本身限时免费（截止时间以控制台公告为准），但**压缩后模型的部署费用始终按 MU 规格实时计费**，不受免费期影响。
- **精度权衡**：量化必然引入精度损失；若部署验证不达标，应更换模板或补充校准数据重新压缩，而非尝试修复已产出模型。

如需通过程序化方式管理任务，请参考 [模型压缩 API 参考](https://help.aliyun.com/zh/model-studio/model-compression-api#h1-e183f6b9)，其能力与控制台功能严格对齐。
