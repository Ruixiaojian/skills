# model compression

模型压缩是百炼平台提供的量化能力，用于将全精度微调模型转换为低精度版本，在保持推理能力基本稳定的前提下显著降低部署所需的 MU 规格与成本。该功能属于模型生产链路中的可选环节，位于[模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)之后、[模型部署](https://help.aliyun.com/zh/model-studio/model-deployment-1/#3bc53b23c7shc)之前。**注意：压缩不可逆，压缩后模型不支持继续微调或二次压缩**，相关说明详见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持模型类型**：仅限通过百炼平台完成微调训练的**自定义模型**（即微调产出的模型），不支持基础模型（如 `qwen3.5-flash-2026-02-23` 原始版本）或第三方模型。
- **当前支持系列**：Qwen 系列微调模型（例如 `qwen3.5-flash-2026-02-23` 微调版），具体可用模型以控制台实时列表为准。
- **功能范围**：当前仅支持**后训练量化（PTQ）**，不包含结构剪枝、知识蒸馏等其他压缩技术；完整能力边界请参考 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“功能概述”章节。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符，建议含模型简称、量化方式和版本号（如 `qwen35-ft-awq-v1`） |
| **选择源模型** | 是 | 仅展示当前工作空间中状态为“成功”的微调模型；切换源模型将自动清空已选量化模板 |
| **量化产出模型名后缀** | 是 | 仅支持小写字母+数字，≤8 位（如 `awq`），将拼接至源模型名后生成新模型 ID（如 `my-qwen-ft-awq`） |
| **量化模板** | 是 | 卡片式选择，模板名中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失可能增加；不同源模型支持的模板不同 |
| **校准数据** | 条件必填 | 仅当所选模板需校准时显示；最多选 5 个已发布数据集（不支持 OSS 挂载），推荐与目标场景语义一致的数据 |

> **注意**：量化模板选择直接影响部署规格与精度表现，建议在免费期内多模板对比验证——该实践建议源自 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的“如何利用免费期确定最佳压缩方案”小节。

## 使用方式

1. **前提条件**：确保工作空间中存在状态为“成功”的微调模型（参见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) “前提条件”部分）；
2. 控制台路径：**模型 > 模型训练 > 模型压缩** → 单击**创建压缩任务**；
3. 完成上述关键参数配置，确认无误后单击**开始压缩**（按钮仅在所有必填项有效时启用）；
4. 任务创建后不可修改配置，可通过任务列表页或详情页查看状态（7 种状态：`PENDING`/`QUEUING`/`RUNNING`/`SUCCEEDED`/`FAILED`/`CANCELING`/`CANCELED`）及日志；
5. 任务成功后，压缩模型自动出现在模型中心，可直接用于部署。

## 限制和注意事项

- **地域限制**：仅支持华北2（北京）地域；
- **模型来源限制**：仅支持百炼平台内微调产出的自定义模型，基础模型或导入模型不可压缩；
- **不可逆性**：压缩后模型**不支持继续微调、不支持二次压缩**，且无法还原为原始精度模型；
- **校准数据限制**：仅支持平台内已创建并发布的数据集，不支持 OSS 路径或未发布数据；
- **计费说明**：压缩任务本身限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按 MU 规格单独计费，与压缩是否免费无关；
- **失败排查**：任务失败时，优先查看详情页错误信息，再结合日志页签中 `ERROR` 级别日志分析；必要时下载全量日志并提交工单（附任务 ID）。
