# model compression

模型压缩是百炼平台提供的量化能力，通过降低模型参数精度（如 FP16 → INT4），在保持推理能力基本不变的前提下显著减少部署所需的 MU 资源和成本。该功能仅作用于百炼平台微调产出的自定义模型，属于模型生产链路中“微调 → 压缩 → 部署”的可选环节，且压缩操作不可逆。详细背景与设计目标请参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持模型**：仅限百炼平台微调完成的自定义模型（如 `qwen3.5-flash-2026-02-23`），不支持基础模型、第三方模型或未完成微调的中间模型。  
- **支持功能**：当前仅提供**量化（Quantization）**，不含结构剪枝、知识蒸馏等其他压缩技术；量化模板以 MU 规格（如 MU8）标识部署资源需求，MU 编号越大，部署成本越低，但潜在精度损失可能增加。  
- **校准能力**：部分量化模板支持校准（Calibration），需从已发布数据集中选择 ≤5 个语义相关数据集（不支持 OSS 挂载），用于提升量化后模型的精度稳定性。具体支持情况请参考 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的模板卡片说明。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符，建议含模型简称、量化方式、版本号（如 `qwen35-int4-v1`） |
| **量化产出模型名后缀** | 是 | 仅小写字母+数字，≤8 位，将拼接至源模型名后（如源模型 `my-qwen-ft` + 后缀 `int4` → `my-qwen-ft-int4`） |
| **量化模板** | 是 | 模板名称隐含部署规格（如 `MU8-INT4`），须先选择源模型后才可加载对应模板列表；切换源模型会清空已选模板 |
| **校准数据** | 条件必填 | 仅当所选模板要求校准时显示；必须为已在[数据管理](https://help.aliyun.com/zh/model-studio/manage-data/#9d2f7039bfo1a)中创建并发布的数据集 |

> **注意**：文档中提及“压缩不可逆”与“不支持继续微调/二次压缩”，但未明确说明压缩后模型是否支持直接用于 LoRA 微调下游任务。实际行为以 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的最新运行时验证为准——当前平台强制禁止对压缩模型发起任何微调任务提交。

## 使用方式

1. **前提条件**：确保工作空间中存在状态为 `SUCCEEDED` 的微调模型（参见 [模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/#73749f1ee5634)）；  
2. 控制台路径：**模型 > 模型训练 > 模型压缩** → 单击**创建压缩任务**；  
3. 配置参数（重点确认量化模板与校准数据）→ 单击**开始压缩**（所有必填项完成后按钮才启用）；  
4. 任务创建后不可修改配置，可通过任务列表页查看状态（共 7 种状态，含 `PENDING`/`RUNNING`/`SUCCEEDED`/`FAILED` 等）；  
5. 成功后，压缩模型自动注册至模型中心，可直接用于部署；失败时需结合 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的“失败排查”流程分析日志。

## 限制和注意事项

- **地域限制**：仅华北2（北京）地域可用；  
- **模型来源限制**：仅支持百炼平台微调产出的自定义模型，基础模型（如 `qwen2.5-7b`）或导入模型不可压缩；  
- **不可逆性**：压缩后模型**不支持继续微调、不支持二次压缩、不支持反向还原为全精度模型**；  
- **计费说明**：压缩任务本身限时免费（截止时间以控制台公告为准），但压缩后模型的部署费用按 MU 规格实时计费，与免费期无关；  
- **校准数据限制**：仅支持平台内已发布数据集，不支持 OSS 路径或未发布数据；  
- **模板兼容性**：不同源模型支持的量化模板不同，切换源模型时会自动清空模板选择——此行为已在 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中明确说明，开发者需重新评估模板适配性。
