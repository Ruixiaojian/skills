# model compression

模型压缩是百炼平台提供的量化能力，用于将全精度微调模型转换为低精度版本，在保持推理能力的前提下显著降低部署所需的 MU 规格与成本。该功能属于模型生产链路中的可选环节（微调 → 压缩 → 部署），仅作用于百炼平台产出的自定义微调模型，不支持结构剪枝或知识蒸馏等其他压缩范式。压缩操作不可逆，且压缩后模型不可继续微调或二次压缩。

## 支持的模型与功能

- **支持范围**：仅限通过百炼平台完成微调训练的自定义模型（即“微调产出模型”），不支持基础模型、第三方模型或 OSS 直接加载模型。当前明确支持 `qwen3.5-flash-2026-02-23` 等 Qwen 系列微调模型，具体可用模型以控制台实时列表为准。  
- **功能边界**：百炼模型压缩特指**后训练量化（PTQ）**，不含剪枝、蒸馏、稀疏化等技术。详见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“功能概述”章节。  
- **地域限制**：仅华北2（北京）地域可用。

## 关键参数

创建压缩任务时需配置以下核心参数（均在控制台表单中填写）：

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符；建议含模型简称、量化方式、版本号（如 `qwen35-flash-w4a4-v1`） |
| **量化产出模型名后缀** | 是 | 仅小写字母+数字，≤8 位；将拼接至源模型名后（如源模型 `my-qwen-ft` + 后缀 `w4a4` → `my-qwen-ft-w4a4`） |
| **量化模板** | 是 | 卡片式选择；模板名中 MU 编号越大（如 `MU8` > `MU4`），部署规格越小、成本越低，但潜在精度损失可能增加。切换源模型会清空已选模板。 |
| **校准数据** | 条件必填 | 仅当所选模板要求校准时显示；最多选 5 个已在[数据管理](https://help.aliyun.com/zh/model-studio/manage-data/#9d2f7039bfo1a)中创建并发布的数据集，不支持 OSS 挂载数据。 |

> **注意**：参数配置在任务创建后不可修改，请务必在单击“开始压缩”前确认。详细字段说明见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的“创建压缩任务”章节。

## 使用方式

1. **前提条件**：确保工作空间中已存在状态为“成功”的微调模型（参见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) “前提条件”部分）。
2. **入口路径**：百炼控制台 → **模型** > **模型训练** > **模型压缩** → **创建压缩任务**。
3. **执行流程**：
   - 选择源模型（仅展示可压缩微调模型）；
   - 配置任务名称、后缀、量化模板（模板列表动态加载）；
   - 如需校准，添加对应数据集；
   - 点击**开始压缩**（所有必填项校验通过后按钮才启用）。
4. **监控与排查**：
   - 任务详情页含 **详情**（状态、配置、错误信息）和 **日志**（可筛选级别、下载全量、自动刷新）两个页签；
   - 失败时优先查看详情页错误提示，再搜索日志中 `ERROR` 行，必要时提交工单并附任务 ID 与日志。

## 限制和注意事项

- **不可逆性**：压缩后模型不支持继续微调、不支持二次压缩，也不支持恢复为全精度模型。
- **状态约束**：
  - 仅 `PENDING` 和 `RUNNING` 状态可停止；
  - 仅终态（`SUCCEEDED`/`FAILED`/`CANCELED`）可删除；删除任务记录不影响已产出模型。
- **计费说明**：压缩任务当前限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按实际 MU 规格计费，与压缩是否免费无关。
- **精度权衡**：量化必然引入精度损失。若部署后效果不达预期，应更换量化模板或补充校准数据重试，而非调整压缩后模型本身。
- **模板选择建议**：在免费期内对同一微调模型尝试多个模板，结合业务测试集验证精度与成本平衡点——这是确定最优方案的推荐实践。
