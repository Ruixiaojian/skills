# model compression

模型压缩是百炼平台提供的量化能力，通过降低模型参数精度（如 FP16 → INT4/INT8），在保持推理能力基本不变的前提下显著减少部署所需的 MU 资源与成本。该功能仅作用于百炼平台微调产出的自定义模型，属于模型生产链路中的可选环节（微调 → 压缩 → 部署），且压缩操作不可逆。详细背景与定位请参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 支持的模型与功能

- **支持范围**：仅限通过百炼平台完成微调训练的自定义模型（即“微调产出模型”），不支持基础模型（如 `qwen3.5-flash-2026-02-23` 本身）、第三方上传模型或 OSS 模型。
- **技术范畴**：当前仅支持**量化（Quantization）**，明确不包含结构剪枝、知识蒸馏等其他压缩技术。详见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“功能概述”章节。
- **典型效果**：以 `qwen3.5-flash-2026-02-23` 微调模型为例，压缩后部署规格可从 `MU1*2`（¥108/小时）降至 `MU8*1`（¥47/小时），成本节省约 56%。

> **注意**：文档中示例模型 `qwen3.5-flash-2026-02-23` 的命名含未来日期（2026年），实际可用模型列表以控制台实时展示为准；请务必在创建任务前确认源模型状态为“训练成功”，否则将无法出现在模型选择弹窗中 —— 参考 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) “创建压缩任务”前提条件部分。

## 关键参数

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| **任务名称** | 是 | ≤50 字符，建议含模型简称、量化方式、版本号（如 `qwen35-ft-v1-int4`） |
| **选择源模型** | 是 | 仅显示当前工作空间中状态为“成功”的微调模型；切换源模型会自动清空已选量化模板 |
| **量化产出模型名后缀** | 是 | 小写字母+数字，≤8 位（如 `int4`），将拼接至源模型名后生成新模型 ID（如 `my-qwen-ft-int4`） |
| **量化模板** | 是 | 卡片式选择，模板名中 MU 编号越大，部署规格越小、成本越低，但潜在精度损失可能增加 |
| **校准数据** | 条件必填 | 仅当所选模板需校准时出现；最多选 5 个已在[数据管理](https://help.aliyun.com/zh/model-studio/manage-data/#9d2f7039bfo1a)中发布完成的数据集 |

## 使用方式

1. **前提**：确保工作空间中存在状态为“成功”的微调模型（参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) “前提条件”）；
2. 控制台路径：**模型 > 模型训练 > 模型压缩** → 单击**创建压缩任务**；
3. 完成上述关键参数配置，确认无误后单击**开始压缩**（按钮仅在所有必填项填写完成后启用）；
4. 创建后不可修改配置，可通过任务列表页查看状态（PENDING / RUNNING / SUCCEEDED / FAILED 等 7 种状态）及日志；
5. 任务成功后，压缩模型自动注册至模型中心，可直接用于部署。

## 限制和注意事项

- **地域限制**：仅支持华北2（北京）地域；
- **不可逆性**：压缩后的模型**不支持继续微调**，也**不支持二次压缩**；如需调整，请基于原始全精度微调模型重新发起压缩任务；
- **数据要求**：校准数据必须在百炼平台内创建并**发布完成**，不支持未发布数据集或 OSS 挂载路径；
- **计费说明**：压缩任务本身限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按实际 MU 规格单独计费，与压缩是否免费无关；
- **失败排查**：任务失败时，优先查看详情页错误信息，再结合日志页签中 `ERROR` 级别日志分析；必要时下载全量日志并提交工单（附任务 ID）。
