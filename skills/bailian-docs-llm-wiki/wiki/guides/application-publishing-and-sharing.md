# application publishing and sharing

阿里云百炼支持将已创建的智能体或工作流应用通过多种渠道发布和分享，包括网页链接、UI 应用、钉钉机器人、微信公众号、组件复用以及音视频实时互动。开发者可根据业务场景选择合适的发布方式，将 AI 能力快速集成到不同平台。所有通过分享链接产生的费用由应用创建者（主账号）承担。

## 前提条件

- 已创建并发布智能体应用或工作流应用。
- 已获取用于调用百炼服务的 API Key。
- 百炼应用、API Key 和 UI 设计需归属于**同一业务空间**。

## 支持的发布渠道

根据 [分享智能体应用](../../raw/application-user-guide/application-publishing-and-sharing/share-an-application.md)，智能体应用支持以下五种发布方式：

| 发布渠道 | 适用应用类型 | 说明 |
|---------|------------|------|
| 官方网页版 | 仅智能体应用 | 生成分享链接，默认有效期 7 天，持有链接的阿里云用户可访问 |
| UI 应用（魔笔） | 智能体/工作流应用 | 通过 UI 设计器构建自定义界面，发布为网页应用 |
| 钉钉机器人 | 智能体应用 | 需授权 AppFlow 服务，配置钉钉 Client ID/Secret 和卡片模板 |
| 微信公众号 | 智能体应用 | 需授权 AppFlow 服务，配置微信开发者 AppID |
| 组件 | 智能体/工作流应用 | 发布为可复用组件，供其他应用引用 |
| 音视频实时互动 | 图文对话类应用（智能体/工作流） | 支持 H5/APP 扫码和 SDK 集成两种方式 |

## 官方网页版分享

1. 在应用管理页面点击目标应用的**发布**，选择**官方网页版**，点击**创建**。
2. 可选启用**应用观测**以统计 Token 消耗。
3. 复制链接分享给其他用户，点击**网页下线**可停止服务。

> **注意**：官方网页版仅支持智能体应用，不支持工作流应用。

## UI 应用（UI 设计器）

根据 [UI设计器](../../raw/application-user-guide/application-publishing-and-sharing/ui-designer.md)，百炼 UI 设计器集成了阿里云魔笔低代码平台能力，支持通过拖放组件可视化构建应用界面。

### 快速发布

1. 在应用发布渠道页选择 **UI 应用**，点击**创建**。
2. 系统自动填充基础信息（标题、API Key、智能体等），确认后点击**立即创建**。
3. 创建完成后通过链接体验，链接有效期 24 小时。

### 通过设计器创建

1. **创建 UI**：在 UI 设计器页面选择模板（提供智能出行助手、智能体门户、AI 基础对话、企业 AI 知识库 Lite 及空白模板）。
2. **编辑 UI**：通过拖放组件搭建页面，配置布局和样式。
3. **发布与分享**：发布到开发环境（免费，24 小时失效）或生产环境（需订阅付费套餐，长期有效）。

> **注意**：对于工作流应用，如果配置了文件类型的自定义参数，需要在 UI 设计器中指定 `{{{file_name:files[0]}}}` 格式的自定义参数，才能正确读取用户上传的文件。

### 环境对比

| 对比项 | 开发环境 | 生产环境 |
|-------|---------|---------|
| 用途 | 开发、调试和验证 | 终端用户实际使用 |
| 有效期 | 24 小时后失效 | 长期有效 |
| 费用 | 免费 | 需订阅付费套餐 |
| 域名 | 平台提供 | 支持自定义域名 |

## 钉钉/微信发布

### 钉钉机器人

1. 首次使用需授权 AppFlow 服务（包含 SLR 关联和 API Key 加密传输授权）。
2. 在钉钉开放平台创建应用，获取 Client ID 和 Client Secret。
3. 创建消息卡片模板（AI 卡片类型），获取模板 ID，并授予 `Card.Streaming.Write` 和 `Card.Instance.Write` 权限。
4. 将上述凭据填入百炼配置面板，完成发布后获取回调地址。
5. 在钉钉应用中配置机器人（消息接收模式选择 **HTTP 模式**），粘贴回调地址，发布版本后即可在群聊中使用。

### 微信公众号

1. 如已授权 AppFlow 则无需重复授权。
2. 从微信公众号后台获取开发者 AppID，在百炼配置面板完成凭据配置。
3. 发布完成后分享公众号二维码。

## 发布应用为组件

根据 [使用智能体或工作流作为组件](../../raw/application-user-guide/application-publishing-and-sharing/use-agent-or-workflow-as-component.md)，智能体或工作流可发布为模块化组件，供其他应用复用。

### 发布方式

- **发布应用时同步发布**：在发布应用时勾选**发布应用组件**。
- **在发布渠道页创建**：进入已发布应用的发布渠道页，创建组件。
- **通过组件管理面板**：在控制台的组件管理页面创建、查看、修改或删除组件。

### 组件参数配置

组件预设了以下系统参数（不可删除，但可隐藏）：

| 参数 | 用途 |
|-----|------|
| query | 传递用户输入的文本 |
| imageList | 传递用户输入的图像公网地址列表（仅图像/视频理解模型有效） |

关键配置项：

| 配置项 | 说明 |
|-------|------|
| 组件名称/描述 | 接入智能体时，大模型会根据描述自动判断是否调用 |
| 别名 | 避免参数名冲突，调用者只能看到别名 |
| 是否可见 | 用于隐藏不需要的参数（如文本模型隐藏图像参数） |
| 传参方式 | **业务透传**：由使用者或上游节点提供；**模型识别**：由大模型自动推断填充 |

> **注意**：在工作流中引用组件时，即使参数设置为**模型识别**，也不会自动推断参数值，必须从上游节点明确提供输入。

### 接入组件

- **智能体应用**：在技能中选择已发布的组件，大模型根据用户问题自动决定是否调用。业务透传参数可在测试时手动填入或通过 API 的 `biz_param` 参数传入。
- **工作流应用**：拖入组件节点，手动连接上游节点为参数赋值，支持智能体组件和工作流组件。

## 音视频实时互动

仅支持图文对话类应用。在应用的 **AI 实时互动**页签配置后发布，支持两种渠道：

- **H5/APP 扫码**：生成带有效期的分享链接。
- **SDK 集成**：支持快速集成和开发集成两种模式。

## 限制和注意事项

- **组件自动更新**：应用重新发布后，组件也会自动更新。
- **避免嵌套调用**：A 调用 B、B 调用 A 会导致重复调用，功能不可用。
- **避免多级调用**：A → B → C 的调用链容易因运行时间限制产生超时错误。
- **费用归属**：所有通过分享链接产生的费用由应用创建者 UID 账号承担。
- **首次钉钉/微信发布**：需授权 AppFlow 服务，包括 SLR 关联和 API Key 加密传输。
- **钉钉机器人消息模式**：仅支持 HTTP 模式，选择 Stream 模式会导致无法返回消息。
- **UI 设计器计费**：功能本身免费，但模型调用、文件存储和生产环境发布可能产生费用。
