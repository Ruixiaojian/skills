# test 1

阿里云百炼平台提供多种模型服务的计费方式，包括按量付费、模型训练与部署计费，以及节省计划和资源包等优惠方案。本文汇总了百炼平台的计费规则、免费额度、成本优化方案和账单管理方法，帮助开发者高效管理模型调用成本。

## 免费额度

首次开通阿里云百炼时，平台会自动为**中国内地版**模型发放新人专属免费额度，其他地域无免费额度。详细规则参见 [新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

### 核心规则

- **有效期**：30～90 天（自 2025 年 9 月 8 日起，新开通用户有效期调整为 90 天）。
- **适用范围**：仅抵扣模型**实时推理**费用，不支持 Batch 调用、上下文缓存、模型调优、模型部署及自定义模型。
- **共享机制**：主账号与 RAM 子账号共享同一免费额度。
- **额度用尽保护**：建议开启**免费额度用完即停**功能，防止免费额度耗尽后自动按量扣费。

## 模型调用计费

### 按量付费（实时推理）

模型调用按输入 Token 和输出 Token 分别计费。部分模型实行阶梯计费——单价取决于单次请求的输入 Token 总量，所有 Token 按对应阶梯单价结算。具体价格参见 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。

**主要模型系列示例（中国内地）**：

| 模型系列 | 代表模型 | 输入单价（每百万Token） | 输出单价（每百万Token） |
|---------|---------|---------------------|---------------------|
| 千问 Max | qwen3.7-max | 12 元 | 36 元 |
| 千问 Plus | qwen3.6-plus | 2 元（≤256K） | 12 元 |
| 千问 Plus | qwen-plus | 0.8 元（≤128K） | 2 元（非思考）/ 8 元（思考） |

**影响计费的因素**：
- **Batch 调用**：支持的模型，输入和输出单价按实时推理价格的 50% 计费。
- **上下文缓存**：仅输入 Token 享有折扣，与 Batch 调用不能同时生效。
- **部署范围**：全球、国际、欧盟、美国等非中国内地部署范围下的模型无免费额度，且部分地域单价不同。

### 模型训练计费

训练费用 =（训练数据 Token 总数 + 混合训练数据 Token 总数）× 循环次数 × 训练单价。训练完成后的新模型需先完成**模型部署**才能调用。支持的训练模型包括千问系列（Qwen3.5、Qwen3、Qwen2.5 等）和千问 VL 系列，训练单价从 ¥0.003/千Token 到 ¥0.15/千Token 不等。详见 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

### 模型部署计费

部署计费方式包括：
- **预置吞吐（按使用时长）**：费用 = 使用时长 × (输入 TPM 单价 × 输入 TPM + 输出 TPM 单价 × 输出 TPM)。
- **模型单元（按使用时长）**：费用 = 使用时长（小时）× 模型单元数量 × 模型单元单价，支持后付费和包月预付费。
- **按模型 Token 使用量**：仅限对基础模型完成 SFT 高效训练后的自定义模型。

> **注意**：模型部署的预付费订单无法提前终止服务；后付费场景下账户欠费后资源保留 24 小时后自动释放。当输入超过最长输入 Token 或超出购买的 TPM 时，调用将自动切换为按量付费模式。

## 成本优化方案

### AI 通用型节省计划（推荐）

通过承诺每月消费金额换取阶梯式折扣，最高可享 **5.3 折**优惠。详见 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

- **覆盖范围**：可抵扣阿里直供的全部模型（A/B/C 三类），支持模型调用、工具调用、上下文缓存、批量推理等费用。
- **不支持抵扣**：模型调优、模型部署、MCP 广场和模型体验的联网搜索。
- **承诺周期**：3/6/12/24 个月，月承诺额度 1000 元起。每月额度独立，未用完自动清零。
- **C 类模型（DeepSeek、Kimi、GLM 等）**：目前无折扣。

### 其他节省计划

| 计划类型 | 适用模型 | 折扣 |
|---------|---------|------|
| 大语言模型推理 | Token 计费的文本生成模型 | 无折扣 |
| 万相模型 | 图像/视频生成 | 最高 9 折 |
| 千问语音模型 | TTS/ASR 模型 | 最高 8 折 |
| 向量及排序模型 | Embedding/Rerank | 最高 7 折 |

### 资源包

预购具体 Token 数量，用于抵扣特定模型超出免费额度后的实时推理用量。购买后立即生效。

### 抵扣顺序

**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**

## 账单查询与成本管理

### 出账周期

- **大模型推理**：分钟级出账（调用后约 2～10 分钟生成）。
- **其他服务**（批量推理/模型训练/知识库等）：小时级出账。

### 账单查询方式

- **查询特定模型费用**：在账单详情页选择**商品名称**为**百炼大模型推理**，通过实例 ID 列定位模型。
- **查询 Token 消耗量**：在账单详情页导出账单 CSV 文件查看。
- **分账管理**：通过标签功能对业务空间进行标记，将费用归属到不同部门或项目（T+1 天生效）。

### 账单字段解读

`实例 ID（出账粒度）` 字段格式：`ApiKeyID;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识`。不含 ApiKeyID 时通常表示通过控制台调用产生。

## 欠费与停止计费

### 欠费影响

- 账户可用额度 < 0 即为欠费，可能导致模型无法调用。
- 有免费额度或节省计划/资源包余额的模型仍可继续使用。
- Coding Plan 和 Token Plan 额度独立于账户余额，欠费不影响使用，但会导致自动续费失败。

### 停止计费

| 服务类型 | 操作方式 |
|---------|---------|
| 模型推理 | 停止 API 调用，删除 API-Key |
| 模型训练 | 确保无进行中的训练任务 |
| 模型部署（按量） | 下线已部署的模型 |
| 模型部署（包月） | 下线模型后在退订管理页面退订 |

## 限制和注意事项

- 免费额度仅限**中国内地版**模型，北京地域的免费额度需通过中国内地版控制台获取。
- 同一模型的不同版本（如 `qwen-max` 和 `qwen-max-latest`）免费额度**不共享**。
- 控制台的免费额度数据为**分钟级更新**且需手动刷新，操作前应确认最新数据。
- 按量付费采用"预占+月结"模式，非实时扣款。
- 节省计划的月承诺额度每月独立，未使用完的部分自动清零，不可累积。
