# test 1

本主题聚合阿里云百炼平台与**计费、成本治理**相关的全部用户指南，覆盖模型调用价格、新人免费额度、模型训练与部署计费、节省计划与资源包、以及账单查询与分账管理。开发者可据此快速判断单次调用成本、申领免费配额、选择长期优化方案，并定位账单中每一项费用的来源。

## 计费体系总览

百炼平台的费用按"产生方式"划分为三类：

- **按量计费**：模型实时推理、Batch 调用、模型原生工具调用（Function Call、联网搜索、网页抓取等）、上下文缓存——发生调用即出账。
- **订阅型费用**：节省计划、资源包、Token Plan、预置吞吐、模型单元——一次性或周期性购买，自动抵扣按量费用。
- **任务型费用**：模型调优（按训练 Token）、模型部署（按实例规格 / 时长），详见 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

抵扣顺序固定为：**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。

## 新人免费额度

首次开通**中国内地版**百炼时，平台自动发放各模型的新人专属免费推理额度，其他地域无此福利。详细规则见 [新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

关键规则：

| 维度 | 说明 |
| --- | --- |
| 有效期 | 30~90 天，自开通或模型申请通过之日起计算 |
| 抵扣范围 | 仅**实时推理**，不抵扣 Batch 调用、模型调优、模型部署、自定义模型 |
| 账号范围 | 主账号与所有 RAM 子账号**共享**同一额度 |
| 查看入口 | 控制台 → 模型用量 → 免费额度页签；或模型广场进入模型详情页 |

> **注意**：自 **2026 年 9 月 8 日 11 点**起，新开通用户的免费额度有效期由 30~90 天统一调整为 **90 天**；该日期之前已开通的账号沿用原有效期，不会自动续延。

## 模型调用价格

模型调用以 **Token** 为最小计费单位，输入与输出分开计价，单价随模型与请求规模变化。完整价目见 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。

### 阶梯计费规则

部分模型（如 qwen-plus 系列）按**单次请求的输入 Token 总量**划分阶梯：当请求落入某一区间，该次请求的全部 Token 均按对应区间单价结算，不会跨档拆分。

示例：模型设两档 `0 < Token ≤ 32K` 与 `32K < Token ≤ 128K`，若一次请求输入 100K Token，则 **全部 100K Token** 按第二档单价计算。

### 影响单价的因素

- **Batch 调用**：支持 Batch 的模型，输入与输出单价均按实时推理价 **50%** 结算。
- **上下文缓存**：仅对**输入 Token** 享有折扣。
- **互斥**：Batch 与上下文缓存折扣**不能同时生效**。
- **思维链 / 思考模式**：千问 Max 等推理模型按"思维链 + 回答"合并计费，单价与非思考模式可能不同。

### 部署范围

中国内地部署的模型推理资源仅在华北 2（北京）；静态数据存于用户所选地域。海外版本及计费单位（USD vs CNY）以模型广场上的实际页签为准。

## 模型训练与部署计费

训练完成的模型必须**先部署**才可评测与调用，因此训练费用与部署费用**串联产生**。完整公式与价目见 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

### 训练费用

按训练 Token 计费，公式：

```
模型训练费用 = (训练数据 Token 总数 + 混合训练数据 Token 总数) × 循环次数 × 训练单价
```

最小计费粒度 **1 Token**。控制台创建训练任务时会显示**预估训练费用**，点击"计算详情"可看到 Token 总数、循环次数、训练单价的分项。

典型千问系列训练单价（每千 Token）：

| 模型 | 单价 |
| --- | --- |
| qwen3-1.7B / qwen3-8B | 约 ¥0.006~¥0.008 |
| qwen3-14B / qwen3-30B-A3B-Instruct | ¥0.03 |
| qwen3-32B | ¥0.04 |
| qwen3.5-9B | ¥0.02 |
| qwen3.5-27B / qwen3.5-Flash / qwen3.6-Flash | ¥0.05 |

### 部署费用

部署按**实例规格 × 在线时长**计费（具体单价见原文档），停机即停止计费。**节省计划与免费额度均不抵扣**模型部署费用，需单独计入预算。

## 节省计划与资源包

为长期使用场景提供的成本优化方案，三种类型按推荐顺序如下，详细对比见 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

### AI 通用型节省计划（推荐）

通过**承诺月度消费金额** + **承诺周期（3 / 6 / 12 / 24 个月）** 换取阶梯折扣，最高 **5.3 折**。

- **覆盖范围**：阿里直供的全部模型，一次购买跨模型生效。
- **金额起步**：每月承诺额 **1000 元起**，以 10 元为单位调整，无上限。
- **承诺周期机制**：以**月**为单位独立结算，月内未用完额度**到月底自动清零**，**不可累积**到下一周期。例：订阅 3 个月、月承诺 1000 元，实际获得 3 个独立的 1000 元月度额度，而非 3000 元总池。
- **抵扣分类**：
  - **A 类**：千问（不含 qwen3.6-max-preview）、千问-开源、向量、排序、行业模型、原生工具调用
  - **B 类**：图像生成、语音合成、语音识别与翻译、视频生成与编辑
  - **C 类**：qwen3.6-max-preview、DeepSeek、Kimi、GLM、MiniMax、HappyHorse
- **可抵扣**：调用 Tokens、原生工具调用、上下文缓存、Batch 推理。
- **不可抵扣**：模型调优、模型部署、MCP 广场与模型体验中的联网搜索。
- **适用地域**：华北 2（北京）、美国（弗吉尼亚）、新加坡、德国（法兰克福）。

### 其他模型节省计划

一次性购买固定金额，仅抵扣特定模型系列（如语音类）。折扣通常不如 AI 通用型，按需选用。

### 资源包

一次性购买具体资源量（Tokens、生成图片数等），仅抵扣**单一模型**（如 qwen-plus 专用包）。灵活性最低，仅在用量高度集中于某个模型时考虑。

### 选型口径

| 场景 | 推荐 |
| --- | --- |
| 多模型混合使用、月消费稳定 ≥ 1000 元 | AI 通用型节省计划 |
| 仅密集使用某语音 / 特种模型 | 对应的其他模型节省计划 |
| 仅密集使用单个文本模型，预算固定 | 该模型的资源包 |
| 用量起伏极大、无法承诺月消费 | 仅按量付费 + 免费额度 |

## 账单查询与成本管理

详见 [账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

### 出账时延

- **大模型推理**：分钟级出账（通常 2~10 分钟）
- **批量推理 / 模型训练 / 知识库**：小时级出账
- 业务高峰期以系统最终出账时间为准

### 费用概览页

在百炼控制台 → 费用概览中，可：

- 查看当月**总消费**，自动拆分为**订阅购买费用**与**账单费用**
- 按**模型**或 **API Key ID** 过滤查询
- 将**分组**设为"产品分类"对比部署 / 推理 / 训练支出走势
- 在"账单费用"卡片设置**月度限额 + 阈值告警**（邮件 / 短信），避免欠费停服

### 账单详情字段

下载账单后，关键字段 **"实例 ID（出账粒度）"** 用 `;` 分隔，格式：

```
ApiKeyID;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识
```

调用渠道枚举：

| 渠道 | 含义 |
| --- | --- |
| `app` | 应用程序（代码）调用 |
| `bmp` | 控制台「模型体验」调用 |
| `assistant-api` | Assistant API 调用 |

若 `ApiKeyID` 为空，通常表示该费用来自控制台操作而非代码调用。

### 分账（标签）

给**业务空间**绑定标签即可按部门 / 项目归集费用：

1. 在「业务空间管理」获取 Workspace ID（如 `llm-xxx`）与地域。
2. 在「标签管理」选择"输入多个资源 ID"，产品选「大模型服务平台百炼:业务空间」，填入 Workspace ID 并绑定标签。
3. 在「费用标签」启用对应标签键。
4. 分账账单 **T+1 天**生效，在账单详情的「实例标签」列验证。

标签字段格式：`key:test1 value:test1; key:test2 value:test2`，多个标签用 `;` 分隔。

### 欠费与停服

- 当账户余额不足以支付当期账单时，平台将按欠费规则停止后续调用，请在「费用概览」开启**消费告警**以提前预警。
- 免费额度用尽后将按"用完即停"标识决定是否自动转按量付费——可通过该标识控制是否在额度耗尽时自动停用。

## 常见踩坑

- 误以为节省计划月度额度可累积——实际**月末清零**。
- 误以为免费额度可抵 Batch / 训练 / 部署——**仅实时推理**可用。
- 主账号与 RAM 子账号**共享**免费额度，多人开发时务必先看剩余余量。
- 阶梯计费按**单次请求的输入 Token 总量**判档，拆分大请求为多次小请求可能落入更低单价区间，但会增加调用开销，需自行权衡。
- 模型部署费用**不被任何节省计划 / 免费额度抵扣**，长期部署需单独预算。
