# test 1

阿里云百炼平台采用多层次的计费体系，涵盖模型推理（按量付费）、模型训练、模型部署等场景，并提供免费额度、节省计划、资源包等成本优化手段。本文汇总了百炼平台计费相关的核心规则、价格参考和成本管理方法，帮助开发者快速理解费用构成并合理控制支出。

## 计费方式概览

百炼平台的费用主要来自以下三类场景：

| 场景 | 计费方式 | 说明 |
|------|---------|------|
| 模型推理（调用） | 按 Token 用量 / 按次 / 按时长 | 最常见的费用来源，支持阶梯计费 |
| 模型训练（调优） | 按训练 Token 用量 | 训练完成后需先部署才能调用 |
| 模型部署 | 按使用时长 / 按 Token 用量 / 按实例时长 | 根据部署类型（预置吞吐/模型单元等）有不同计费模式 |

详细的推理价格请参考 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)，训练与部署费用请参考 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

## 模型推理价格要点

### 阶梯计费

部分模型（如千问 Max、千问 Plus）实行阶梯计费：单价取决于**单次请求的输入 Token 总量**，该请求的所有 Token 均按所在阶梯的单价结算。例如 `qwen3-max` 在中国内地地域：

- 0 < Token ≤ 32K：输入 2.5 元/百万 Token，输出 10 元/百万 Token
- 32K < Token ≤ 128K：输入 4 元/百万 Token，输出 16 元/百万 Token
- 128K < Token ≤ 256K：输入 7 元/百万 Token，输出 28 元/百万 Token

### Batch 调用与上下文缓存

- **Batch 调用**：支持的模型输入和输出单价均按实时推理价格的 **50%** 计费。
- **上下文缓存**：仅输入 Token 享有折扣。
- 两者**不能同时生效**。

### 地域差异

- **中国内地**（华北2-北京）：享有免费额度，价格最低。
- **全球/国际/欧盟/美国**等部署范围：无免费额度，价格通常高于中国内地。

## 新人免费额度

首次开通阿里云百炼时，平台会自动发放各模型的新人专属免费额度。详细规则见 [新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

**核心规则：**

- **适用范围**：仅中国内地版模型，仅抵扣实时推理费用。不支持 Batch 调用、上下文缓存、模型调优、模型部署等场景。
- **有效期**：30～90 天（自开通或模型申请通过之日起）。
- **共享机制**：主账号与 RAM 子账号共享免费额度。

> **注意**：自 2025 年 9 月 8 日 11 点起，新用户免费额度有效期调整为 90 天，此前已开通的用户不受影响。

**防意外扣费建议**：开启「免费额度用完即停」功能。开启后，额度耗尽时返回错误码 `AllocationQuota.FreeTierOnly`，不会继续扣费。

## 成本优化方案

百炼提供三种预付费优惠方案，抵扣顺序为：**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。详情见 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

### AI 通用型节省计划（推荐）

- **原理**：承诺每月消费金额（1000 元起），换取阶梯式折扣，最高 **5.3 折**。
- **覆盖范围**：阿里直供的全部模型（A/B/C 三类不同折扣），支持抵扣模型调用、工具调用、上下文缓存、批量推理等费用。
- **不支持抵扣**：模型调优、模型部署、MCP 广场和模型体验的联网搜索。
- **承诺周期**：3/6/12/24 个月，每月额度独立，未用完不累积。

> **注意**：C 类模型（如 DeepSeek、Kimi、GLM 等）在 AI 通用型节省计划中**无折扣**（全周期均为原价抵扣）。三方直供模型不支持抵扣。

### 其他模型节省计划

针对特定模型系列（万相、千问语音、向量及排序等）的一次性购买方案，适合用量较小或高度集中于某一模型的场景。注意其不支持抵扣工具调用、上下文缓存、批量推理等费用。

### 资源包

预购具体 Token 数量，用于抵扣特定模型超出免费额度后的实时推理用量。购买后立即生效，有效期根据档位不同。

## 账单查询与成本管理

### 出账周期

- **模型推理**：分钟级出账（调用后约 2～10 分钟生成）。
- **其他服务**（批量推理/模型训练/知识库等）：小时级出账。

### 关键查询操作

| 需求 | 操作入口 |
|------|---------|
| 查看具体模型推理费用 | 账单详情页 → 商品名称选"百炼大模型推理" → 按实例 ID 筛选 |
| 查看百炼总费用趋势 | 成本分析页 → 产品选"大模型服务平台百炼" |
| 查看 Token 消耗量 | 账单详情页 → 导出账单 CSV |
| 查看模型调用统计 | 控制台 → 模型监控（数据按小时更新） |

### 账单实例 ID 格式

账单中 `实例 ID（出账粒度）` 字段格式为：`ApiKeyID;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识`。

- 控制台调用时 ApiKeyID 为空（以分号开头）。
- 调用渠道：`app`（API 调用）、`bmp`（控制台模型体验）、`assistant-api`（Assistant API）。

### 分账管理

通过对**业务空间**绑定标签，可将费用归属到不同部门或项目。配置完成后 T+1 天生效。

## 停止计费

| 场景 | 操作 |
|------|------|
| 模型推理 | 停止 API 调用，删除 API-Key 防止意外调用 |
| 模型训练 | 确保无进行中的训练任务 |
| 模型部署（按量/按时长） | 在控制台下线已部署的模型 |
| 模型部署（包月预付费） | 下线模型后，前往退订管理退订资源实例 |
| Coding Plan | 到期自动停止，如需提前停止则关闭自动续费 |

## 限制和注意事项

- 免费额度仅限中国内地版模型，`qwen-max` 和 `qwen-max-latest` 的免费额度**不共享**。
- 控制台显示的免费额度为**分钟级更新**且需手动刷新页面，存在显示延迟。
- 账户欠费时，即使模型仍有免费额度也无法调用（Coding Plan 和 Token Plan 套餐额度除外）。
- 按量付费采用「预占 + 月结」模式，并非实时扣款。
- 模型部署使用预置吞吐时，若超出购买的 TPM 量，调用将自动切换为按量付费模式，响应 Header 会包含 `x-dashscope-ptu-overflow:true`。
