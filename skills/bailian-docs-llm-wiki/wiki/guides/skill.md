# skill

Skill 是百炼平台提供的可插拔能力包，用于扩展智能体在对话中自动处理特定任务（如文件解析、数据清洗等）的能力，无需开发者编写集成代码。官方 Skill 开箱即用，自定义 Skill 支持通过 ZIP 包上传实现业务定制。其核心机制依赖 `SKILL.md` 中的语义描述驱动智能体自动识别与调用，因此描述质量直接影响调用准确性 [原文标题](../../raw/application-user-guide/skill/introduction-to-skill.md)。

## 支持的模型/功能

- **官方 Skill**：由平台预置并维护，覆盖常见文件处理场景（如 `xlsx`、`pdf`、`csv` 等），无需配置即可添加使用，且已接入智能体的自动路由系统 [原文标题](../../raw/application-user-guide/skill/introduction-to-skill.md)。  
- **自定义 Skill**：通过上传符合规范的 ZIP 包创建，适用于官方 Skill 未覆盖的垂直场景（如行业专用格式解析、私有 API 封装等）。ZIP 包必须包含根目录下的 `SKILL.md` 文件，并满足命名唯一性、10 MB 大小限制等要求 [原文标题](../../raw/application-user-guide/skill/introduction-to-skill.md)。  
- 当前所有 Skill 均不依赖特定大模型底座，调用逻辑由百炼平台统一调度，与底层模型解耦。

## 关键参数

| 参数 | 位置 | 必填 | 说明 |
|------|------|------|------|
| `name` | `SKILL.md` YAML 字段 | 是 | Skill 唯一标识符，仅支持小写字母、数字和连字符（如 `invoice-parser`），同一账号下不可重复。 |
| `description` | `SKILL.md` YAML 字段 | 是 | 决定智能体是否触发该 Skill 的核心依据。需明确输入类型、支持操作、典型触发关键词及**明确排除的不适用场景**（避免误调用）。 |
| 版本号 | 上传时自动生成 | 否 | 每次重新上传同名 ZIP 包即生成新版本；官方 Skill 版本由平台自动更新，自定义 Skill 需手动重传。 |

> **注意**：`description` 字段不是简单功能说明，而是面向意图识别的语义提示。若描述未覆盖用户可能使用的口语化表达（如“那个我刚发的表格”），或未排除歧义场景（如“转成 Word”却声明输出为 Excel），将导致调用失败或错误 —— 这是实践中最常见的问题根源。

## 使用方式

1. **创建 Skill**  
   - 官方 Skill：直接在 [Skill 管理](https://bailian.console.aliyun.com/?tab=app#/skill) 页面查看并添加。  
   - 自定义 Skill：准备 ZIP 包（含合规 `SKILL.md`），进入控制台 **组件 > Skill 管理 > 自定义 Skill > 上传**，等待约 2 分钟自动审查。  

2. **添加到智能体**  
   - 方式一：在 Skill 详情页点击 **添加到智能体**，选择目标应用。  
   - 方式二：进入智能体 **应用配置 > 技能** 区域，点击对应 Skill 右侧 `+` 添加。  

3. **验证效果**  
   在应用配置页右侧对话窗格中发送典型测试语句（如 `把附件里的销售数据按城市汇总成表格`），观察是否自动调用并返回预期结果（如生成 `.xlsx` 文件）。

## 限制和注意事项

- **大小限制**：ZIP 包总大小 ≤ 10 MB，超限将被拒绝上传。  
- **调用粒度**：Skill 以单次对话轮次为单位触发，不支持跨轮次状态保持；如需多步交互，请在 Skill 内部实现状态管理逻辑。  
- **版本生效**：自定义 Skill 更新后，已添加该 Skill 的智能体会**自动切换至最新版本**，无需重新配置；但历史对话记录中的旧版本调用行为不受影响。  
- **调试建议**：若 Skill 未被触发，优先检查 `description` 是否遗漏关键触发词或未明确排除干扰场景；可通过控制台 Skill 详情页的 **更新记录** 对比版本变更。  
- **安全约束**：自定义 Skill 运行于沙箱环境，禁止访问外网、读写本地文件系统或执行系统命令；所有 I/O 仅限平台提供的标准接口（如 `input_files`、`output_files`）。
