# skill

Skill 是百炼平台提供的可插拔能力包，用于扩展智能体在对话中自动处理特定任务的能力（如文件解析、数据清洗等），无需开发者编写集成代码。官方 Skill 由平台预置并维护，自定义 Skill 则通过符合规范的 ZIP 包上传实现。其核心机制依赖 `SKILL.md` 中的语义描述驱动智能体自动识别与调用，因此描述质量直接影响调用准确率 [原文标题](../../raw/application-user-guide/skill/introduction-to-skill.md)。

## 支持的模型/功能

- **官方 Skill**：覆盖常见文件处理场景（如 `.xlsx`, `.csv`, `.pdf`, `.docx` 等格式的读写、转换、清洗），由平台统一维护，添加后即用，且已接入智能体的自动路由系统 [原文标题](../../raw/application-user-guide/skill/introduction-to-skill.md)。  
- **自定义 Skill**：支持用户上传 ZIP 包实现业务定制能力，例如行业专用报表生成、私有协议解析等。需严格遵循 ZIP 结构与 `SKILL.md` 规范，否则无法通过审查 [原文标题](../../raw/application-user-guide/skill/introduction-to-skill.md)。  
- **不支持模型绑定**：Skill 本身不关联特定大模型，而是作为独立能力模块被智能体调度；其执行逻辑由 Skill 内部代码（如 Python 脚本）定义，与底层模型解耦。

## 关键参数

所有 Skill 的行为由 `SKILL.md` 中的两个必填字段控制：

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | 是 | Skill 唯一标识符，仅允许小写字母、数字和连字符（如 `invoice-parser`），同一账号下不可重名。 |
| `description` | 是 | **决定调用准确性的核心字段**。必须明确说明：① 支持的输入类型（如 `.xlsx`, JSON 表格）；② 可执行操作（如“清洗缺失值”“导出为 CSV”）；③ 典型触发关键词（如“整理表格”“转成 Excel”）；④ 明确排除的场景（如“不处理图片中的表格”）。描述越具体，误触发率越低。 |

> **注意**：`description` 不是 UI 展示文案，而是供智能体推理使用的语义指令。模糊描述（如“处理数据”）将导致调用失败或错误，务必参考 [原文标题](../../raw/application-user-guide/skill/introduction-to-skill.md) 中 xlsx Skill 的完整示例编写。

## 使用方式

1. **添加 Skill**  
   - 方式一：在 [Skill 管理](https://bailian.console.aliyun.com/?tab=app#/skill) 页面点击目标 Skill 卡片 → “添加到智能体” → 选择应用。  
   - 方式二：进入目标智能体的**应用配置** → 左侧“技能”区域 → 点击 `+` → 从列表勾选。  

2. **测试验证**  
   在应用配置页右侧对话窗格中发送典型请求（如 `把附件里的销售数据按季度汇总成表格`），观察是否触发 Skill 并返回预期结果（如生成 `.xlsx` 文件）。  

3. **更新自定义 Skill**  
   修改本地 ZIP 包（含更新后的 `SKILL.md`）→ 在“自定义 Skill”标签页重新上传同名包 → 审查通过后，已绑定该 Skill 的智能体**自动生效新版本**（无需重启或重新配置）。

## 限制和注意事项

- **ZIP 包限制**：单个包 ≤ 10 MB；根目录必须包含 `SKILL.md`；禁止包含可执行二进制文件或外部网络调用逻辑（平台沙箱环境禁止外网访问）。  
- **版本管理**：官方 Skill 版本由平台自动升级，用户不可干预；自定义 Skill 每次上传同名包即创建新版本，历史版本可在详情页“概览”中切换查看。  
- **调试建议**：若 Skill 未被调用，优先检查 `description` 是否覆盖用户提问的语义（如是否遗漏触发词）、输入文件类型是否匹配、以及智能体是否已启用 Skill 能力（确认应用配置中已勾选）。  
- **安全约束**：自定义 Skill 运行于隔离沙箱，无法访问本地文件系统、数据库或用户会话以外的数据；所有输出必须通过标准接口返回结构化结果（如文件 URL 或 JSON）。
