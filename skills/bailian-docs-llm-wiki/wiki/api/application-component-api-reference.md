# application component api reference

本 API 参考文档面向开发者，系统性地描述了百炼平台中应用组件（Application Component）的核心能力接口，涵盖数据连接（原应用数据）、知识库（Index）及辅助功能三大模块。所有接口均基于 ROA 风格设计，支持通过官方 SDK 或自签名方式调用，并严格遵循 RAM 权限控制模型。开发者需在业务空间上下文中操作资源，并注意各接口的幂等性、限流策略与状态依赖关系。

## 支持的模型/功能

API 覆盖三类核心能力：

- **数据连接管理**：提供类目（Category）、文件（File）、连接器（Connector）和表格（Table）的全生命周期操作，包括 `AddCategory`、`ListFile`、`AddConnector`、`AddTable` 等。其中，类目用于组织非结构化文件，连接器用于对接外部存储（如 OSS），表格用于结构化数据接入。详细说明见 [API概览](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-overview.md)。
- **知识库（Index）管理**：支持创建（`CreateIndex`）、更新（`UpdateIndex`）、查询（`ListIndices`）、删除（`DeleteIndex`）知识库，以及提交构建任务（`SubmitIndexJob`）、追加文档（`SubmitIndexAddDocumentsJob`）、检索（`Retrieve`）等关键操作。知识库类型包括文档搜索、数据查询、图片问答和音视频搜索四类。
- **高级功能**：包括切片（Chunk）级细粒度操作（`AddChunk`、`ListChunks`、`UpdateChunk`、`DeleteChunk`）、解析器配置（`GetAvailableParserTypes`、`ChangeParseSetting`）、监控（`GetIndexMonitor`）及支付宝打赏集成（`GetAlipayUrl`）等。

> **注意**：文档 20（`AddConnector`）中授权信息误标为 `sfm:AddCategory`，实际应为 `sfm:AddConnector`，该错误已在 [AddConnector - 新增连接器](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-data-connection-original-application-data/api-bailian-2023-12-29-addconnector.md) 中修正。

## 关键参数

- **WorkspaceId**：所有接口的路径参数，标识业务空间，是资源隔离和权限控制的基础。必须通过控制台或 `ListWorkspaces` 接口获取，不可猜测。
- **CategoryId / FileId / IndexId / ConnectorId**：各资源的唯一标识符，通常由上游接口（如 `AddCategory`、`AddFile`、`CreateIndex`）返回，部分接口（如 `DescribeFile`、`GetIndexJobStatus`）要求显式传入。
- **Parser**：`AddFile` 接口的关键请求参数，指定文档解析策略，可选值包括 `DOCMIND`、`DOCMIND_LLM_VERSION`、`AUTO_SELECT` 等，直接影响知识提取质量。
- **Query**：`Retrieve` 接口的请求体参数，即用户输入的原始检索文本，无长度限制，但需注意响应延迟。
- **Time Range Parameters**：`GetIndexMonitor` 接口要求 `StartTimestamp` 和 `EndTimestamp`（秒级 Unix 时间戳），且时间跨度不得超过 30 天。

## 使用方式

1. **环境准备**：使用 RAM 子账号并授予最小权限策略（如 `AliyunBailianDataFullAccess`），避免使用主账号 AccessKey；配置 SDK 或按 ROA 规范实现自签名。
2. **典型流程**：
   - 数据接入：`ApplyFileUploadLease` → 上传文件 → `AddFile` → （可选）`ChangeParseSetting` → `ListFile`
   - 知识库构建：`CreateIndex` → `SubmitIndexJob` → `GetIndexJobStatus`（轮询）→ `Retrieve`
   - 切片管理：`AddChunk` → `ListChunks` → `UpdateChunk` / `DeleteChunk`
3. **调试与验证**：所有接口均支持在 [OpenAPI Explorer](https://api.aliyun.com) 直接调试，可自动生成多语言 SDK 示例代码。
4. **分页与幂等**：`ListCategory`、`ListFile` 等列表接口支持 `NextToken` 分页；`ListCategory`、`DeleteCategory`、`DescribeFile` 等接口明确声明具有幂等性，可安全重试。

## 限制和注意事项

- **限流策略**：多数接口有严格 QPS 限制（如 `AddCategory` 5 次/秒，`ApplyFileUploadLease` 10 次/秒），超限将返回 429 错误，需实现退避重试逻辑。
- **状态依赖**：`SubmitIndexJob` 必须在 `CreateIndex` 成功后调用；`SubmitIndexAddDocumentsJob` 要求文件已通过 `AddFile` 导入且状态为 `PARSE_SUCCESS`；`DeleteIndex` 前需解除与应用的关联（仅控制台支持）。
- **功能边界**：`AddCategory` 不支持创建数据表；`DeleteFiles` 仅能删除 `PARSE_FAILED` 或 `PARSE_SUCCESS` 状态的文件；`UpdateChunk` 仅适用于文档搜索类知识库，不支持数据查询/图片问答类 [UpdateChunk - 修改切片](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-knowledge-base/api-bailian-2023-12-29-updatechunk.md)。
- **安全与合规**：OSS 导入需确保同账号授权，且 Bucket 不得为归档/冷归档类型；Referer 防盗链需白名单 `*.console.aliyun.com`；临时文件上传租约（`ApplyTempStorageLease`）仅限高代码部署场景。
