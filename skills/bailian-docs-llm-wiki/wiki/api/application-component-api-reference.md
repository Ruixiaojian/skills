# application component api reference

本 API 参考文档面向开发者，系统性地描述了百炼平台 Application Component（应用组件）层提供的核心 OpenAPI 能力，覆盖数据连接（应用数据）、知识库、[Prompt 工程](../concepts/prompt-engineering.md)三大功能域。所有接口均基于 ROA 签名机制，推荐使用官方 SDK 进行调用以简化认证流程。开发者需预先配置 RAM 权限与业务空间成员身份方可访问。

## 支持的模型/功能

Application Component API 主要提供三类能力：

- **数据连接（原应用数据）**：管理非结构化文件与结构化表格。支持类目（`Category`）的增删查（`AddCategory`、`DeleteCategory`、`ListCategory`），文件的上传（`ApplyFileUploadLease` + `AddFile`）、批量导入（`AddFilesFromAuthorizedOss`）、状态查询（`DescribeFile`）、列表（`ListFile`）及标签管理（`UpdateFileTag`、`BatchUpdateFileTag`）。同时支持连接器（`AddConnector`、`GetConnector`、`UpdateConnector`）和表格（`AddTable`、`UpdateTableFromAuthorizedOss`）操作。详细说明见 [API概览](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-overview.md)。

- **知识库（Index）**：支持知识库全生命周期管理，包括创建（`CreateIndex`）、提交构建任务（`SubmitIndexJob`）、查询状态（`GetIndexJobStatus`）、更新配置（`UpdateIndex`）、列表（`ListIndices`）、删除（`DeleteIndex`）；支持知识库内文件级操作，如查询（`ListIndexDocuments`、`ListIndexFileDetails`）、删除（`DeleteIndexDocument`）；以及底层文本切片（Chunk）的查询（`ListChunks`）、修改（`UpdateChunk`）和删除（`DeleteChunk`）。检索能力由 `Retrieve` 接口提供。

- **[Prompt 工程](../concepts/prompt-engineering.md)**：提供 Prompt 模板的 CRUD 操作，包括创建（`CreatePromptTemplate`）、获取单个（`GetPromptTemplate`）、列表（`ListPromptTemplates`）、更新（`UpdatePromptTemplate`）和删除（`DeletePromptTemplate`）。

> **注意**：文档 1 中明确指出“不支持通过 API 新增数据表”，但文档 20 的 `AddTable` 接口存在且具备完整定义。经交叉验证，`AddTable` 是真实可用的接口，该矛盾源于文档 1 的概述性描述未及时同步最新能力，应以具体接口文档（如 [AddTable - 添加表格](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-data-connection-original-application-data/api-bailian-2023-12-29-addtable.md)）为准。

## 关键参数

- **通用路径参数**：几乎所有接口均需 `WorkspaceId`（业务空间 ID），用于隔离资源范围，必须通过控制台或相关 API 获取。
- **类目与文件标识**：`CategoryId`（来自 `AddCategory` 响应）、`FileId`（来自 `AddFile` 响应）是多数数据操作的核心标识符。
- **知识库标识**：`IndexId`（来自 `CreateIndex` 响应）是知识库操作的必需参数，`JobId`（来自 `SubmitIndexJob` 响应）用于查询任务状态。
- **解析器选择**：`AddFile` 接口的 `Parser` 参数决定文档解析策略，可选值包括 `DOCMIND`、`DOCMIND_LLM_VERSION`、`AUTO_SELECT` 等，具体支持列表需结合 `GetAvailableParserTypes` 接口动态查询。
- **分页控制**：`List*` 类接口普遍支持 `MaxResults`（每页数量）和 `NextToken`（分页凭证）进行分页。

## 使用方式

1. **环境准备**：确保已开通百炼服务，创建 RAM 用户并授予最小权限策略（如 `AliyunBailianDataFullAccess`），加入目标业务空间。详情请参阅 [授权信息](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-ram.md)。
2. **接入点配置**：根据地域选择对应的服务接入地址，例如华北2（北京）为 `bailian.cn-beijing.aliyuncs.com`，新加坡为 `bailian.ap-southeast-1.aliyuncs.com`。完整列表见 [服务接入点](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-endpoint.md)。
3. **调用流程**：
   - 文件上传：先调用 `ApplyFileUploadLease` 获取租约，再使用租约 ID 调用 `AddFile` 完成导入。
   - 知识库构建：先调用 `CreateIndex` 初始化，再调用 `SubmitIndexJob` 启动构建，最后用 `GetIndexJobStatus` 轮询状态。
   - 检索：直接调用 `Retrieve`，传入 `Query` 文本即可。
4. **调试与开发**：强烈建议使用 [OpenAPI Explorer](https://api.aliyun.com/) 进行在线调试，并自动生成各语言 SDK 代码示例。

## 限制和注意事项

- **权限与安全**：RAM 用户必须显式授权（如 `sfm:AddCategory`）并加入业务空间；阿里云账号虽默认有权限，但出于安全最佳实践，**严禁在生产环境直接使用主账号 AccessKey**，必须遵循最小权限原则配置子账号。
- **幂等性**：`DeleteCategory`、`ListCategory`、`DescribeFile`、`DeleteFile`、`GetIndexJobStatus` 等读/删操作具有幂等性；而 `AddCategory`、`AddFile`、`CreateIndex` 等写操作不具备幂等性，重复调用可能产生冗余资源。
- **限流策略**：不同接口限流阈值不同，例如 `AddCategory` 为 5 次/秒，`ApplyFileUploadLease` 为 10 次/秒，`ListIndexDocuments` 为 15 次/秒。超限将返回 HTTP 429，需实现客户端重试逻辑。
- **数据一致性**：`DeleteFile` 仅删除应用数据中的文件，不影响已构建的知识库；反之，`DeleteIndexDocument` 仅删除知识库中的索引，不影响原始应用数据。两者互不干扰，需按需调用。
- **版本与变更**：API 版本为 `2023-12-29`，其变更历史（如 `CreateIndex` 入参变更、`DescribeFile` 返回结构变更）已在 [版本说明](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-changeset.md) 中明确记录，集成前务必核查。
