# application component api reference

本参考文档汇总了百炼平台 Application Component（应用组件）相关的 OpenAPI 接口，覆盖数据连接（应用数据）、知识库、Prompt 模板三大核心能力。所有接口均基于 `bailian/2023-12-29` 版本，采用 ROA 签名机制，支持多语言 SDK 封装调用。开发者需通过 RAM 子账号配合最小权限策略进行安全接入，避免直接使用主账号 AccessKey。

## 支持的模型/功能

Application Component API 主要提供三类能力：

- **数据连接（原应用数据）**：管理非结构化文件与结构化表格，包括类目（Category）、文件（File）、连接器（Connector）的增删查改，以及 OSS 数据导入、解析设置配置等。例如 `AddCategory`、`AddFilesFromAuthorizedOss`、`ChangeParseSetting` 等接口均属于此范畴，详见 [API概览](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-overview.md)。
- **知识库（Index）**：支持创建、更新、删除知识库，提交构建/追加任务，执行检索（`Retrieve`），以及对知识库内文件、切片（Chunk）进行细粒度管理。注意知识库类型区分：`document`（文档搜索）、`table`（数据查询）、`image`（图片问答）、`multimedia`（音视频搜索），不同类型的接口支持范围存在差异，例如 `AddChunk` 明确不支持 `multimedia` 类型，而 `UpdateChunk` 仅支持 `document` 类型。
- **Prompt 工程**：提供 Prompt 模板的创建与获取能力（`CreatePromptTemplate`、`GetPromptTemplate`），当前暂不支持文生图类模板，该限制在 [CreatePromptTemplate - 创建Prompt模板](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-prompt-engineering/api-bailian-2023-12-29-createprompttemplate.md) 中有明确说明。

> **注意**：文档 25 (`AddConnector`) 的授权信息中错误地列出了 `sfm:AddCategory` 权限点，而实际应为 `sfm:AddConnector`。该错误已在 [AddConnector - 新增连接器](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-data-connection-original-application-data/api-bailian-2023-12-29-addconnector.md) 的“授权信息”表格中得到修正，开发者应以该文档为准。

## 关键参数

- **`WorkspaceId`**：所有接口的路径参数，标识业务空间，是资源隔离和权限控制的核心维度，必须通过控制台或 `ListWorkspaces`（未在原始文档中列出，但为通用前提）获取。
- **`CategoryId` / `FileId` / `IndexId` / `PromptTemplateId`**：各类资源的唯一标识符，通常由上游接口（如 `AddCategory`、`AddFile`、`CreateIndex`、`CreatePromptTemplate`）返回，后续操作需依赖此 ID。
- **`Parser`（文件解析器）**：`AddFile` 接口的关键请求参数，指定文档解析方式，可选值包括 `DOCMIND`、`DOCMIND_LLM_VERSION`、`AUTO_SELECT` 等，其可用性需结合文件类型通过 `GetAvailableParserTypes` 查询。
- **`DocumentStatus`（文件状态过滤）**：`ListIndexDocuments` 和 `ListIndexFileDetails` 的可选请求参数，用于按导入状态（如 `FINISH`、`INSERT_ERROR`）筛选结果，提升查询效率。
- **`PipelineId`**：`AddChunk`、`UpdateChunk`、`DeleteChunk` 等切片操作的必填参数，即知识库 ID（`IndexId`），部分文档（如文档 37）使用 `PipelineId` 字段名，与 `IndexId` 含义完全一致。

## 使用方式

1. **环境准备**：首先在阿里云 RAM 控制台创建子用户，授予 `AliyunBailianDataFullAccess`（读写全量）或 `AliyunBailianDataReadOnlyAccess`（只读）策略，并确保该子用户已加入目标业务空间。详细步骤见 [授权信息](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-ram.md)。
2. **SDK 调用（推荐）**：下载并初始化对应语言的百炼 SDK（版本 `2023-12-29`），传入 AccessKey ID/Secret 和 `RegionId`（如 `cn-beijing`），SDK 自动处理签名与 endpoint 路由。服务接入点列表见 [服务接入点](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-endpoint.md)。
3. **自签名调用（备选）**：若需自定义签名，必须严格遵循 ROA 规范，计算 `Authorization` 头。由于流程复杂且易出错，官方强烈建议加入钉钉群（147535001692）获取技术支持，而非自行实现。
4. **典型工作流示例**：
   - **上传文件并构建知识库**：`ApplyFileUploadLease` → 上传至临时存储 → `AddFile` → `CreateIndex` → `SubmitIndexJob`。
   - **更新知识库内容**：`AddFile`（新文件）→ `SubmitIndexAddDocumentsJob`；或 `ListChunks` → `UpdateChunk`/`DeleteChunk`。
   - **管理 Prompt 模板**：`CreatePromptTemplate` → `GetPromptTemplate`。

## 限制和注意事项

- **限流策略**：各接口均有明确 QPS 限制，例如 `ListCategory`、`DeleteCategory` 为 5 次/秒，`AddFile`、`ApplyFileUploadLease` 为 10 次/秒，`ListIndexDocuments` 为 15 次/秒。超出限制将返回 HTTP 429，需实现指数退避重试。
- **幂等性**：`List*`、`Describe*`、`Get*` 类查询接口及 `Delete*`、`Update*` 类操作接口大多具有幂等性（如 `DeleteCategory`、`DescribeFile`），但 `Add*`、`Create*`、`Submit*` 类接口（如 `AddCategory`、`CreateIndex`、`SubmitIndexJob`）不具备幂等性，重复调用可能产生冗余资源，建议通过 `List*` 先校验再操作。
- **资源关联约束**：删除知识库（`DeleteIndex`）前，必须先解除其与智能体/工作流应用的关联，此操作目前仅支持控制台完成；删除知识库中的文件（`DeleteIndexDocument`）不会影响应用数据中的源文件，反之亦然。
- **功能边界**：API 不支持直接新增/删除数据表（`AddTable` 仅用于表格连接器，非通用建表），也不支持通过 API 查询数据表（`ListCategory` 等接口明确说明“暂不支持通过 API 查询数据表”）。此类操作需通过控制台完成。
