# application component api reference

本 API 参考文档面向开发者，提供百炼平台应用组件（Application Component）的核心 OpenAPI 接口规范，涵盖数据连接（应用数据）、知识库、Prompt 模板三大能力模块。所有接口均基于 `bailian/2023-12-29` 版本，采用 ROA 签名机制，支持通过官方 SDK 或自签名方式调用。建议优先使用 [阿里云百炼 SDK](https://api.aliyun.com/api-tools/sdk/bailian?version=2023-12-29) 以简化接入。

## 支持的模型/功能

API 覆盖以下核心功能域：

- **数据连接（原应用数据）**：管理类目（`AddCategory`/`ListCategory`/`DeleteCategory`）、文件（`AddFile`/`ListFile`/`DescribeFile`/`DeleteFile`）、连接器（`AddConnector`/`GetConnector`）及解析策略（`ChangeParseSetting`/`GetAvailableParserTypes`）。支持从本地临时存储或已授权 OSS Bucket 导入文件（[AddFilesFromAuthorizedOss](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-data-connection-original-application-data/api-bailian-2023-12-29-addfilesfromauthorizedoss.md)），但**不支持通过 API 新增或删除数据表**（见 [AddCategory](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-data-connection-original-application-data/api-bailian-2023-12-29-addcategory.md) 和 [DeleteFiles](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-data-connection-original-application-data/api-bailian-2023-12-29-deletefiles.md) 文档说明）。
- **知识库（Index）**：支持创建（`CreateIndex`）、提交构建任务（`SubmitIndexJob`）、追加文档（`SubmitIndexAddDocumentsJob`）、检索（`Retrieve`）、查询列表（`ListIndices`）及管理文件与切片（`ListIndexDocuments`/`AddChunk`/`UpdateChunk`/`DeleteChunk`）。注意 `DeleteIndexDocument` 仅作用于知识库索引层，**不影响应用数据中的原始文件**（见 [DeleteIndexDocument](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-knowledge-base/api-bailian-2023-12-29-deleteindexdocument.md) 文档说明）。
- **Prompt 工程**：提供 Prompt 模板的全生命周期管理（`CreatePromptTemplate`/`GetPromptTemplate`/`UpdatePromptTemplate`/`DeletePromptTemplate`），但**暂不支持文生图类 Prompt 模板**（见 [CreatePromptTemplate](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-prompt-engineering/api-bailian-2023-12-29-createprompttemplate.md) 文档说明）。

> **注意**：文档 4 中记录的 `CreateIndex` 接口在 `2026-03-30` 和 `2026-03-27` 两次变更均涉及“入参发生变更”，但原始文档未提供具体变更内容。开发者应以最新版 OpenAPI Explorer 或 SDK 生成的代码为准，避免依赖过时参数结构。

## 关键参数

- **`WorkspaceId`**：所有接口的必需路径参数，标识业务空间 ID，获取方式见 [如何使用业务空间](https://help.aliyun.com/zh/model-studio/use-workspace)。
- **`CategoryId` / `FileId` / `IndexId` / `promptTemplateId`**：资源标识符，通常由上游接口（如 `AddCategory`、`AddFile`、`CreateIndex`、`CreatePromptTemplate`）返回，用于后续操作定位目标资源。
- **`LeaseId`**：`AddFile` 接口必需请求参数，由 `ApplyFileUploadLease` 接口返回，用于关联上传租约。
- **`Parser`**：`AddFile` 接口必需请求参数，指定文档解析器类型（如 `DOCMIND`、`AUTO_SELECT`），取值需与 `GetAvailableParserTypes` 返回结果一致。
- **`Query`**：`Retrieve` 接口的可选请求参数，为检索文本，长度无硬性限制，但需考虑服务端处理性能。
- **分页参数**：`ListCategory`、`ListFile`、`ListIndices` 等列表接口支持 `MaxResults`（每页条数）和 `NextToken`（翻页凭证）实现分页。

## 使用方式

1. **准备凭证**：使用 RAM 用户（非主账号）并配置最小权限策略（PoLP），推荐策略 `AliyunBailianDataFullAccess`；主账号可直接调用。详见 [API概览](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-overview.md) 中的安全指引。
2. **选择接入点**：根据地域选择公网或 VPC 接入地址，例如华北2（北京）为 `bailian.cn-beijing.aliyuncs.com`（见 [服务接入点](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-endpoint.md)）。
3. **调用流程示例（知识库）**：
   - 调用 `CreateIndex` 初始化知识库；
   - 调用 `SubmitIndexJob` 提交构建任务；
   - （可选）调用 `SubmitIndexAddDocumentsJob` 追加文档；
   - 调用 `Retrieve` 执行检索。
4. **调试与开发**：所有接口均支持在 [OpenAPI Explorer](https://api.aliyun.com) 直接调试，并可自动生成各语言 SDK 代码示例。

## 限制和注意事项

- **限流策略**：各接口有独立 QPS 限制（如 `ListCategory` 5次/秒，`Retrieve` 无明确说明但需关注响应延迟），超限将返回错误。请合理设计重试逻辑。
- **幂等性**：多数查询类（`List*`、`Describe*`）和部分管理类（`DeleteCategory`、`DeleteIndex`）接口具备幂等性；而创建类（`AddCategory`、`CreateIndex`）和提交类（`SubmitIndexJob`）接口不具备幂等性，重复调用可能产生副作用。
- **状态依赖**：知识库相关操作（如 `SubmitIndexAddDocumentsJob`、`ListIndexDocuments`）要求知识库处于 `FINISH` 状态；文件操作（如 `DeleteFile`）仅允许对 `PARSE_SUCCESS` 或 `PARSE_FAILED` 状态的文件执行。
- **权限校验**：RAM 用户必须同时满足两项条件才能成功调用：① 具备对应 `sfm:*` 权限点（如 `sfm:ListFile`）；② 已被加入目标 `WorkspaceId` 所属的业务空间（见 [ListCategory](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-data-connection-original-application-data/api-bailian-2023-12-29-listcategory.md) 文档说明）。
- **资源隔离**：`DeleteIndex` 仅删除知识库元数据及索引，**不会删除应用数据中的源文件**；同理，`DeleteIndexDocument` 仅移除知识库索引中的文档引用，源文件保留在应用数据中。
