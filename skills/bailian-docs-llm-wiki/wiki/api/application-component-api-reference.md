# application component api reference

本 API 参考文档面向开发者，系统性地描述了百炼平台 Application Component（应用组件）层提供的核心 OpenAPI 能力，覆盖数据连接（原应用数据）、知识库、[Prompt 工程](../concepts/prompt-engineering.md)等关键模块。所有接口均基于 `bailian/2023-12-29` 版本，采用 ROA 签名机制，并通过 RAM 进行细粒度权限控制。建议优先使用官方 SDK 以简化签名与错误处理。

## 支持的模型/功能

Application Component API 主要提供三类能力：**数据连接管理**（文件与类目操作）、**知识库全生命周期管理**（创建、更新、检索、监控）和**Prompt 模板管理**。  
- **数据连接**：支持类目增删查（`AddCategory`/`DeleteCategory`/`ListCategory`）、文件上传与管理（`ApplyFileUploadLease`/`AddFile`/`AddFilesFromAuthorizedOss`）、解析器配置（`GetAvailableParserTypes`/`ChangeParseSetting`）及连接器管理（`AddConnector`/`GetConnector`）。  
- **知识库**：覆盖非结构化（文档/音视频）与结构化（数据查询/图片问答）两类知识库，提供创建（`CreateIndex`）、提交任务（`SubmitIndexJob`/`SubmitIndexAddDocumentsJob`）、检索（`Retrieve`）、文件与切片管理（`ListIndexDocuments`/`DeleteIndexDocument`/`ListChunks`/`UpdateChunk`）及监控（`GetIndexMonitor`）等完整链路。  
- **[Prompt 工程](../concepts/prompt-engineering.md)**：支持 Prompt 模板的创建（`CreatePromptTemplate`），但当前不支持文生图类模板 [CreatePromptTemplate - 创建Prompt模板](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-prompt-engineering/api-bailian-2023-12-29-createprompttemplate.md)。  
> **注意**：`AddTable` 和 `UpdateTableFromAuthorizedOss` 接口虽存在，但文档明确指出“不支持通过 API 新增数据表”且“暂不支持通过 API 查询数据表”，表明表格类功能在 API 层存在能力断层，实际使用需依赖控制台 [AddCategory - 新增类目](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-data-connection-original-application-data/api-bailian-2023-12-29-addcategory.md)。

## 关键参数

- **通用路径参数**：几乎所有接口均需 `WorkspaceId`（业务空间 ID），用于隔离资源域，获取方式见[如何使用业务空间](https://help.aliyun.com/zh/model-studio/use-workspace)。  
- **身份认证**：必须使用 AccessKey（推荐 RAM 子账号，遵循最小权限原则）或 API-Key（仅限 `Retrieve` 接口）进行鉴权 [API概览](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-overview.md)。  
- **核心业务参数**：  
  - 类目操作：`CategoryId`（由 `AddCategory` 返回）；  
  - 文件操作：`FileId`（由 `AddFile` 返回）、`LeaseId`（由 `ApplyFileUploadLease` 返回）；  
  - 知识库操作：`IndexId`（由 `CreateIndex` 返回）、`JobId`（由 `SubmitIndexJob` 返回）；  
  - 检索与监控：`Query`（文本输入）、`StartTimestamp`/`EndTimestamp`（秒级 Unix 时间戳，最大跨度 30 天）。  
- **幂等性控制**：`DeleteCategory`、`ListCategory`、`DescribeFile` 等读/删操作具有幂等性；而 `AddCategory`、`CreateIndex`、`ApplyFileUploadLease` 等创建类接口不具备幂等性，重复调用可能产生冗余资源。

## 使用方式

1. **环境准备**：  
   - 创建具备 `AliyunBailianDataFullAccess` 或更细粒度策略（如 `sfm:AddCategory`）的 RAM 用户，并加入目标业务空间；  
   - 获取接入点：根据地域选择公网或 VPC 地址，例如华北2（北京）为 `bailian.cn-beijing.aliyuncs.com` [服务接入点](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-endpoint.md)。  
2. **调用流程**：  
   - 文件上传：先调用 `ApplyFileUploadLease` 获取租约，再用租约 ID 调用 `AddFile`；  
   - 知识库构建：依次调用 `CreateIndex` → `SubmitIndexJob`（或 `SubmitIndexAddDocumentsJob`）→ `GetIndexJobStatus` 轮询状态；  
   - 检索：直接调用 `Retrieve`，传入 `Query` 即可。  
3. **调试与开发**：强烈推荐使用 [OpenAPI Explorer](https://api.aliyun.com/api/bailian/2023-12-29/) 在线调试并生成 SDK 代码示例，避免手动签名。

## 限制和注意事项

- **限流策略**：各接口有独立 QPS 限制（如 `AddCategory` 5次/秒，`Retrieve` 未明示但需合理设置超时重试），超出将返回限流错误，需实现退避重试逻辑。  
- **安全要求**：严禁使用主账号 AccessKey；RAM 策略必须精确到 `sfm:*` 操作级权限，禁止授予 `*:*` 全局权限。  
- **功能边界**：  
  - 不支持通过 API 管理数据表（`AddTable` 接口存在但文档明确禁止新增表）；  
  - `DeleteIndexDocument` 仅删除知识库索引，不影响原始应用数据；  
  - `UpdateChunk` 仅适用于文档搜索类知识库，对数据查询/图片问答类无效。  
- **版本兼容性**：`DescribeFile` 接口返回结构在 2026-01-15 发生变更，`CreateIndex` 参数在 2026-03-27 和 2026-03-30 两次变更，集成前务必核对最新文档 [版本说明](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-changeset.md)。
