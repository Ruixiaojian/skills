# application component api reference

本 API 参考文档面向开发者，系统性地描述了百炼平台 Application Component（应用组件）层提供的核心 OpenAPI 接口能力，涵盖知识库管理、数据连接（原应用数据）、切片操作、[Prompt 工程](../concepts/prompt-engineering.md)等关键功能模块。所有接口均基于 `bailian/2023-12-29` 版本，采用 ROA 签名机制，推荐通过官方 SDK 调用以简化鉴权流程。详细权限模型与资源级控制请参见 [授权信息](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-ram.md)。

## 支持的模型/功能

Application Component API 主要支撑以下四类核心能力：

- **知识库（Index）全生命周期管理**：支持创建（`CreateIndex`）、提交构建（`SubmitIndexJob`）、追加文档（`SubmitIndexAddDocumentsJob`）、检索（`Retrieve`）、查询列表（`ListIndices`）、更新配置（`UpdateIndex`）、删除（`DeleteIndex`）及监控（`GetIndexMonitor`）。知识库类型包括文档/音视频（非结构化）和数据查询/图片问答（结构化）两类，但需注意 `SubmitIndexAddDocumentsJob` 明确不支持数据查询/图片问答类知识库 [原文标题](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-knowledge-base/api-bailian-2023-12-29-submitindexadddocumentsjob.md)。
- **数据连接（原应用数据）管理**：提供类目（Category）、文件（File）、表格（Table）、连接器（Connector）的增删查改能力，以及文件解析设置（`GetParseSettings`, `ChangeParseSetting`）、OSS 导入（`AddFilesFromAuthorizedOss`, `UpdateTableFromAuthorizedOss`）等高级功能。其中，`AddTable` 和 `UpdateTableFromAuthorizedOss` 用于表格数据连接器，而 `AddCategory` 仅支持 `UNSTRUCTURED` 类型 [原文标题](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-data-connection-original-application-data/api-bailian-2023-12-29-addcategory.md)。
- **文本切片（Chunk）操作**：支持为文档/数据/图片类知识库新增（`AddChunk`）、查询（`ListChunks`）、删除（`DeleteChunk`）切片，但 `AddChunk` 明确不支持音视频搜索类（`multimedia`）知识库 [原文标题](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-knowledge-base/api-bailian-2023-12-29-addchunk.md)。
- **[Prompt 工程](../concepts/prompt-engineering.md)**：提供 Prompt 模板的创建（`CreatePromptTemplate`）与获取（`GetPromptTemplate`），当前不支持文生图类 Prompt 模板。

## 关键参数

- **业务空间 ID（WorkspaceId）**：几乎所有接口的路径参数，是资源隔离的核心维度，必须通过控制台或 API 获取，格式如 `llm-3z7uw7fwz0vexxxx`。
- **知识库 ID（IndexId）**：由 `CreateIndex` 返回，用于 `SubmitIndexJob`、`Retrieve`、`ListIndexDocuments` 等后续操作。
- **文件 ID（FileId）**：由 `AddFile` 返回，用于 `DescribeFile`、`DeleteFile`、`DeleteIndexDocument` 等操作。
- **类目 ID（CategoryId）**：由 `AddCategory` 返回，用于 `ApplyFileUploadLease`、`AddFile` 等操作。
- **租约 ID（LeaseId）**：由 `ApplyFileUploadLease` 返回，是 `AddFile` 的必需请求参数，用于安全上传。
- **解析器类型（Parser）**：`AddFile` 的关键请求参数，取值如 `DOCMIND`、`AUTO_SELECT` 等，决定文件解析策略；具体支持列表可通过 `GetAvailableParserTypes` 查询。

> **注意**：`ListIndexDocuments` 的 `DocumentStatus` 参数取值范围包含 `INSERT_ERROR`、`FINISH` 等状态，而 `DeleteFile` 的删除前提条件是文件状态为 `PARSE_FAILED` 或 `PARSE_SUCCESS`，二者状态枚举不一致，开发者需按各自接口文档严格校验。

## 使用方式

1. **环境准备**：
   - 获取 AccessKey（RAM 用户优先，主账号次选），并基于最小权限原则配置 RAM 策略（如 `AliyunBailianDataFullAccess`）[原文标题](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-overview.md)。
   - 根据地域选择接入点，例如华北2（北京）公网地址为 `bailian.cn-beijing.aliyuncs.com` [原文标题](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-endpoint.md)。
2. **调用流程（知识库为例）**：
   - 先调用 `CreateIndex` 初始化知识库；
   - 再调用 `SubmitIndexJob` 提交构建任务；
   - 通过 `GetIndexJobStatus` 轮询任务状态直至完成；
   - 最后调用 `Retrieve` 进行检索。
3. **SDK 与调试**：
   - 强烈推荐使用最新版 [阿里云百炼 SDK](https://api.aliyun.com/api-tools/sdk/bailian?version=2023-12-29)，自动处理签名与重试。
   - 开发阶段可直接在 [OpenAPI Explorer](https://api.aliyun.com/api/bailian/2023-12-29/) 中调试，生成各语言代码示例。

## 限制和注意事项

- **限流策略**：各接口有独立 QPS 限制，例如 `CreateIndex` 和 `SubmitIndexJob` 为 10 次/秒，`ListCategory` 为 5 次/秒。超限将返回错误，需实现退避重试逻辑。
- **幂等性**：`Retrieve`、`ListIndices`、`GetIndexJobStatus` 等查询类接口具备幂等性；`CreateIndex`、`AddCategory` 等创建类接口不具备幂等性，重复调用可能产生冗余资源，建议采用“先查后建”模式。
- **状态依赖**：`SubmitIndexJob` 必须在 `CreateIndex` 成功后调用；`DeleteIndexDocument` 仅支持删除状态为 `INSERT_ERROR` 或 `FINISH` 的文件；`DeleteFile` 仅支持删除 `PARSE_FAILED` 或 `PARSE_SUCCESS` 状态的文件。
- **权限与资源绑定**：所有操作均需在指定 `WorkspaceId` 下进行，且 RAM 策略中的 `Resource` 字段目前均为 `*`（全部资源），暂不支持细粒度资源级授权。
- **变更管理**：API 入参与返回结构会持续演进，例如 `CreateIndex` 在 2026-03-30 和 2026-03-27 均有入参变更，`DescribeFile` 在 2026-01-15 有返回结构变更，开发者应关注 [版本说明](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-changeset.md) 并及时适配。
