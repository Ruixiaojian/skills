# application component api reference

本 API 参考文档面向开发者，系统性地描述了百炼平台 Application Component 的核心能力接口。涵盖知识库全生命周期管理（创建、更新、检索、监控）、应用数据（类目、文件、连接器）操作、切片级精细控制以及 Prompt 模板工程等关键功能模块。所有接口均基于 ROA 签名机制，推荐使用官方 SDK 进行调用。

## 支持的模型/功能

Application Component 提供两类核心能力：**知识库（Index）管理**和**应用数据（Data Connection）管理**。

- **知识库管理**：支持创建、更新、删除非结构化（文档/音视频）及结构化（数据查询/图片问答）知识库；支持向知识库追加、删除、查询文件及文本切片；提供检索（`Retrieve`）、监控（`GetIndexMonitor`）等运行时能力。注意，`SubmitIndexAddDocumentsJob` 明确不支持数据查询/图片问答类知识库，相关更新需通过控制台操作 [原文标题](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-knowledge-base/api-bailian-2023-12-29-submitindexadddocumentsjob.md)。
- **应用数据管理**：覆盖类目（`AddCategory`, `ListCategory`）、文件（`AddFile`, `DescribeFile`, `DeleteFile`）、连接器（`AddConnector`, `UpdateConnector`）及表格（`AddTable`, `UpdateTableFromAuthorizedOss`）的增删改查。其中，`AddTable` 和 `UpdateTableFromAuthorizedOss` 用于表格数据连接器，而 `AddFile` 等接口仅处理非结构化文件 [原文标题](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-data-connection-original-application-data/api-bailian-2023-12-29-addfile.md)。
- **[Prompt 工程](../concepts/prompt-engineering.md)**：提供 `CreatePromptTemplate`、`GetPromptTemplate`、`UpdatePromptTemplate` 和 `DeletePromptTemplate` 四个接口，支持 Prompt 模板的全生命周期管理。当前版本暂不支持文生图 Prompt 模板的创建 [原文标题](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-dir/api-bailian-2023-12-29-dir-prompt-engineering/api-bailian-2023-12-29-createprompttemplate.md)。

> **注意**：`DeleteIndexDocument` 接口明确不支持删除数据查询/图片问答类知识库中的数据，必须通过控制台操作；而 `DeleteFile` 仅删除应用数据中的文件，不影响已构建的知识库。两者用途和作用域有本质区别，开发者需严格区分。

## 关键参数

- **`WorkspaceId`**：几乎所有接口的必需路径参数，标识业务空间 ID。获取方式请参见[如何使用业务空间](https://help.aliyun.com/zh/model-studio/use-workspace)。
- **`IndexId`**：知识库唯一标识，由 `CreateIndex` 接口返回，是 `SubmitIndexJob`、`Retrieve`、`DeleteIndex` 等知识库操作的核心参数。
- **`FileId`**：文件唯一标识，由 `AddFile` 接口返回，用于 `DescribeFile`、`DeleteFile`、`UpdateFileTag` 等文件操作。
- **`CategoryId`**：类目唯一标识，由 `AddCategory` 接口返回，用于 `ListFile`、`ApplyFileUploadLease` 等类目关联操作。
- **`ChunkId`**：文本切片唯一标识，由 `ListChunks` 接口返回的 `Node.Metadata._id` 字段获取，是 `UpdateChunk`、`DeleteChunk` 的必需参数。
- **`Parser`**：文件解析器类型，`AddFile` 接口必需参数，可选值包括 `DOCMIND`、`DOCMIND_LLM_VERSION`、`AUTO_SELECT` 等，直接影响文件解析效果。

## 使用方式

1. **环境准备**：确保已获取阿里云 AccessKey（推荐使用 RAM 子账号并配置最小权限策略），并安装最新版 [阿里云百炼 SDK](https://api.aliyun.com/api-tools/sdk/bailian?version=2023-12-29)。SDK 封装了复杂的签名逻辑，强烈建议优先使用。
2. **知识库创建流程**：
   - 调用 `CreateIndex` 初始化知识库（注意：此步仅初始化，不实际创建）。
   - 必须紧接着调用 `SubmitIndexJob` 提交创建任务，否则将得到空知识库。
   - 通过 `GetIndexJobStatus` 查询任务状态，直至完成。
3. **文件上传与导入流程**：
   - 先调用 `ApplyFileUploadLease` 获取上传租约。
   - 使用租约 ID (`LeaseId`) 调用 `AddFile` 将文件导入应用数据。
   - 若需将文件加入知识库，再调用 `SubmitIndexAddDocumentsJob`。
4. **权限配置**：所有 API 均需 RAM 权限。通用策略为 `AliyunBailianDataFullAccess`，其包含 `sfm:CreateIndex`、`sfm:AddFile` 等绝大多数操作权限点。具体授权信息详见各接口文档的“授权信息”章节。

## 限制和注意事项

- **限流策略**：不同接口有不同频率限制，例如 `AddCategory`、`ListCategory` 为 5 次/秒，`CreateIndex`、`Retrieve` 为 10 次/秒，`ListChunks` 为 10 次/秒。超出限制将被拒绝，需实现重试逻辑。
- **幂等性**：多数查询类接口（如 `ListCategory`, `DescribeFile`, `GetIndexJobStatus`）具有幂等性；而创建类（`AddCategory`, `CreateIndex`）和部分更新类（`ChangeParseSetting`）接口不具备幂等性，重复调用可能导致资源冗余或状态异常，建议采用“先查后建”逻辑。
- **状态依赖**：多个操作存在强前置依赖。例如 `SubmitIndexJob` 必须在 `CreateIndex` 之后调用；`DeleteIndexDocument` 要求文件状态为 `FINISH` 或 `INSERT_ERROR`；`DeleteFile` 仅支持 `PARSE_SUCCESS` 或 `PARSE_FAILED` 状态的文件。
- **地域与接入点**：服务支持多个地域，如华北2（北京）公网地址为 `bailian.cn-beijing.aliyuncs.com`，VPC 地址为 `bailian-vpc.cn-beijing.aliyuncs.com` [原文标题](../../raw/application-api-reference/application-component-api-reference/api-bailian-2023-12-29-endpoint.md)。调用前需确认所选地域的接入点。
- **安全最佳实践**：严禁在代码中硬编码主账号 AccessKey。务必创建 RAM 子账号，并基于最小权限原则（PoLP）授予 `AliyunBailianDataFullAccess` 或更细粒度的权限策略。
