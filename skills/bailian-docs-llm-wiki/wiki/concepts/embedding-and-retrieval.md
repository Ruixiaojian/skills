# 向量化与语义检索

向量化是将文本、图片、视频等非结构化数据通过 Embedding 模型转换为高维数值向量的过程；语义检索则是在向量空间中，基于余弦相似度等方法匹配语义相近的内容，从而实现"理解含义"而非"匹配关键词"的智能检索。两者构成了百炼平台 RAG（检索增强生成）流程的核心基础。

## 基本原理

向量化与语义检索的核心思路是：将数据和查询分别转换为同一语义空间中的向量表示，然后通过向量间的距离或相似度进行匹配。即使查询关键词与实际答案完全不同，只要语义相关，就能被正确召回。

典型流程分为两个阶段：

1. **离线索引阶段**：对文档进行解析、切片，再通过 Embedding 模型将每个切片转换为向量并存入向量存储。
2. **在线检索阶段**：将用户查询同样转换为向量，在向量存储中匹配语义最相近的切片，作为上下文提供给大模型生成回答。

## 在百炼平台中的使用场景

### 知识库（RAG）

知识库是向量化与语义检索最核心的应用场景。创建知识库时，平台会自动对上传文档进行切片和向量化处理；检索时根据用户查询的语义从向量索引中召回相关片段。知识库支持多种类型，不同类型使用不同的向量模型：

| 知识库类型 | 默认向量模型 | 说明 |
|-----------|------------|------|
| 文档搜索（基础/图文/极速） | text-embedding-v4 / v3 | 纯文本语义向量，512 维 |
| 文档搜索（视觉理解） | qwen3 多模态向量模型 | 理解复杂排版、图表、公式 |
| 图片问答 | multimodal-embedding-v1 | 1024 维图像向量 |

### 文本向量化 API

通过通用文本向量模型，开发者可直接调用 API 将文本转换为向量，用于自建检索系统、聚类、分类等下游任务。

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key",
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1"
)

result = client.embeddings.create(
    model="text-embedding-v4",
    input="待向量化的文本",
    dimensions=1024
)
```

### 多模态向量化

多模态向量模型将文本、图片和视频映射到同一语义空间，支持跨模态检索（以文搜图、以图搜视频等）。支持两种向量生成方式：

- **独立向量**：为每个输入分别生成向量，适用于逐项对比
- **融合向量**：将多模态输入融合为一个综合向量，适用于商品图文联合检索等场景

### 检索结果精排（Rerank）

语义检索召回的结果可通过 Rerank 模型进行二次精排，进一步提升准确率。百炼平台提供 `qwen3-rerank`（文本）和 `qwen3-vl-rerank`（多模态）两类排序模型。

### 框架集成

LlamaIndex 和 Spring AI Alibaba 均封装了向量化与语义检索流程，开发者可快速构建端到端 RAG 应用，无需手动管理向量索引。

## 关键参数与配置

### Embedding 模型选择

| 模型 | 维度 | 单行最大 Token | 适用场景 |
|------|------|--------------|---------|
| text-embedding-v4 | 64–2048（默认 1024） | 8,192 | 通用文本，100+ 语种 |
| text-embedding-v3 | 64–1024（默认 1024） | 8,192 | 通用文本，50+ 语种 |
| text-embedding-v2 | 1,536（固定） | 2,048 | 轻量场景 |
| qwen3-vl-embedding | 256–2560（默认 2560） | 32K | 跨模态检索 |

### 向量化参数

| 参数 | 说明 |
|------|------|
| `dimensions` | 输出向量维度，维度越高精度越高但存储和计算成本越大 |
| `text_type` | `query`（查询文本）或 `document`（底库文本），用于非对称检索场景区分编码策略。仅 DashScope 原生接口和批处理接口支持 |

### 检索参数

| 参数 | 说明 | 建议 |
|------|------|------|
| **相似度阈值** | 仅高于此阈值的结果才被召回 | 过高会丢弃相关内容，建议从 0.4 开始调整 |
| **TopK（召回片段数）** | 返回的最大切片数量，上限 20 | 增大可提升回答完整性，但增加 Token 消耗 |
| **Rerank top_n** | 精排后保留的结果数 | 通常设为 1–5 |

### 索引配置（创建知识库时设定，不可更改）

- **切片方式**：推荐「智能切分」，基于语义自适应切分；也可按固定长度切分
- **向量模型**：文档搜索类支持 text-embedding-v4/v3；图片问答类使用 multimodal-embedding-v1
- **Meta 信息抽取**：为切片附加元数据（常量、变量、正则、关键词等），可提升检索精度
