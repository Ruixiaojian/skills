# 检索增强生成

检索增强生成（Retrieval-Augmented Generation，RAG）是一种让大模型在生成回答前先从外部知识源中检索相关内容的技术架构，用于解决大模型在私有知识、实时信息等方面的不足，提升特定领域问答的准确性和可靠性。

## 工作原理

百炼平台中的 RAG 流程分为三个核心阶段：

1. **建立索引**：对文档进行解析、切片与向量化处理，将内容存储到向量数据库中
2. **检索召回**：根据用户查询，从向量存储中匹配并召回语义相关的知识片段
3. **生成答案**：大模型根据召回的知识片段和用户查询生成最终回答

知识库支持语义检索，即使查询关键词与实际答案用词完全不同，也能基于语义相似性找到相关内容。

## 在百炼平台中的使用场景

### 知识库问答（云端 RAG）

最常见的使用方式。在百炼控制台创建知识库，上传文档后平台自动完成解析、切片和向量化。知识库可直接关联到智能体应用或通过工作流节点接入，零代码即可实现私有领域问答。

- **智能体应用（Agent 2.0）**：知识库作为工具，由智能体自主规划何时调用检索
- **智能体应用（Agent 1.0）**：知识库检索先行执行，再决策是否调用其他工具
- **工作流应用**：在画布中添加知识库节点，支持固定选择或动态引入知识库

### 本地 RAG 应用

面向需要灵活控制检索流程的开发者。通过 LlamaIndex 或 Spring AI Alibaba 等框架，在本地环境中完成文档解析、向量化和检索，再调用百炼大模型生成回答。适用于自定义切分策略、使用本地嵌入模型等场景。

### 框架集成

| 框架 | 语言 | RAG 集成方式 |
|------|------|-------------|
| LlamaIndex | Python | `DashScopeParse` 解析文档 → `DashScopeCloudIndex` 创建云端知识库 → `DashScopeRerank` 重排结果 |
| Spring AI Alibaba | Java | `DashScopeDocumentRetriever` 检索百炼知识库，结合 `DocumentRetrievalAdvisor` 实现 RAG |

### 多渠道接入

通过 AppFlow 或 API 将 RAG 能力集成到网站、钉钉、企业微信、微信公众号等渠道，在应用配置中关联知识库即可启用。

## 关键参数与配置

### 索引阶段（创建时设定，不可更改）

| 参数 | 说明 |
|------|------|
| **切片方式** | 推荐「智能切分」，基于语义自适应切分；也可选择按长度切分。单个文本切片上限 6,000 [Token](token.md) |
| **向量模型（Embedding）** | 文档搜索类支持 text-embedding-v4（推荐）/ v3（512 维）；图片问答类使用 multimodal-embedding-v1（1024 维） |
| **Meta 信息抽取** | 为切片附加元数据（常量、变量、大模型提取、正则、关键词），提升检索精度 |
| **[多轮对话](multi-turn-conversation.md)改写** | 根据历史对话自动补全用户查询，创建后不可追加开启 |

> **注意**：切片方式、向量模型和 Meta 信息抽取在知识库创建后均无法更改，请在创建时慎重配置。

### 检索阶段（可动态调整）

| 参数 | 说明 |
|------|------|
| **相似度阈值** | 仅语义相似度高于此阈值的文本才会被召回，设置过高会丢弃相关内容，为 0 时不做剔除 |
| **召回片段数（TopK）** | 最终返回的切片数量，上限 20。增大可提升回答完整性，但增加 [Token](token.md) 消耗和成本 |
| **权重** | 多知识库场景下按重要程度分配，仅在同类型知识库之间生效 |
| **标签过滤** | 通过文件标签在向量检索前筛选目标文件 |

### 生成阶段

| 参数 | 说明 |
|------|------|
| **temperature** | 控制生成随机性，数值越高随机性越强 |
| **最长回复长度** | 模型生成的长度限制，不包含提示词 |
| **携带上下文轮数** | 控制历史对话参考轮数 |

### 代码中的典型配置

```python
# LlamaIndex RAG 参数示例
Settings.llm = DashScope(model_name="qwen-max")
similarity_top_k = 5       # 检索返回的最大结果数
similarity_cutoff = 0.4    # 最低相似度阈值
top_n = 1                  # 重排后返回的结果数
```

## 检索质量优化

RAG 效果可通过以下手段提升：

- **文本排序（Rerank）**：对检索召回的文档进行二次精排。推荐使用 qwen3-rerank 模型（文本场景）或 qwen3-vl-rerank（跨模态场景）
- **知识库类型选择**：根据文档特征选择合适的知识库类型（基础文档问答、图文并茂、视觉理解、极速问答等）
- **Meta 信息抽取**：为切片补充结构化元数据，提升检索精度
- **切分策略调优**：对高度结构化文档（FAQ、参数表）可选择极速问答类型；复杂排版文档选择视觉理解类型
- **Prompt 优化**：通过系统提示词限定回答范围，引导模型正确使用检索结果

## 云端 RAG 与本地 RAG 对比

| 维度 | 云端 RAG（百炼知识库） | 本地 RAG |
|------|----------------------|---------|
| 部署方式 | 零代码，控制台操作 | 需配置 Python/Java 环境 |
| 文档管理 | 通过百炼控制台上传管
