# 模型上下文协议

模型上下文协议（Model Context Protocol，简称 MCP）是阿里云百炼平台提供的标准化、安全、可扩展的工具接入协议，用于在大模型应用（如智能体、工作流）与外部能力（如地图、天气、搜索、知识图谱、自定义 API）之间建立统一的信息通道。它通过抽象工具调用语义与通信契约，屏蔽底层接口差异，使大模型能以自然语言理解意图、自主规划并结构化调用多源工具，开发者无需为每个工具重复编写适配逻辑。

## 在百炼平台的不同场景中，这个概念如何使用

- **智能体应用（Agent 2.0）**：MCP 是核心能力载体。开通的 MCP 服务自动注册为“可调度工具”，智能体基于用户输入动态决策是否调用、调用哪个（最多 5 个）、传入哪些参数，并支持多轮工具调用与结果融合。无需手动编排，全程由模型自主推理驱动。
  
- **工作流应用（Workflow）**：MCP 以独立节点形式存在，每个节点绑定**一个确定的 MCP 工具**（如 `amap_weather`）。需前置节点（如大模型或意图识别）将用户请求解析为结构化参数（通过变量引用，如 `input/location`），后置节点负责将工具返回的 JSON 结果转为自然语言输出。

- **高代码/外部系统集成**：MCP 服务可脱离平台独立调用。通过官方 `mcp` SDK（兼容 OpenAI `tool_calls` 协议），在任意 Python 项目中连接 `streamableHttp` 端点，显式管理工具发现、参数构造、调用循环与错误重试，适用于嵌入 Cherry Studio、Cursor 或自有 AI 平台。

- **知识库与多模态协同**：MCP 工具可与 RAG 知识库、文件解析结果并列作为上下文来源。例如，智能体可同时检索本地知识库 + 调用高德地图 API + 查询实时天气，再综合生成行程建议。

> ✅ 注意：MCP 已全面替代旧版“插件（Plug-in）”术语；所有新开发应基于 MCP 协议配置与调用，控制台中不再提供独立“插件”配置入口。

## 关键参数和配置

| 类别 | 参数/配置项 | 说明 | 必填性 |
|------|-------------|------|--------|
| **协议类型** | `type`：`streamableHttp`（推荐） / `sse` / `stdio` | 必须与端点严格匹配：`streamableHttp` 对应 `POST /mcp`，`sse` 对应 `GET /sse`；错配将触发错误码 `11200058` | ✅ 必填 |
| **服务地址** | `mcp_url`：`https://dashscope.aliyuncs.com/api/v1/mcps/{service-id}/mcp` | 外部 SDK 调用必需；需配合有效的 `DASHSCOPE_API_KEY` 使用 | ✅（外部调用） |
| **安全凭证** | KMS 加密凭据（如 `AMAP_MAPS_API_KEY`） | 敏感参数**必须**通过阿里云 KMS 创建凭据并引用，禁止明文写入配置或环境变量 | ✅（含敏感参数的自定义服务） |
| **部署模式** | 基础模式（按调用时长计费） / 极速模式（预热+按调用时长计费） | 极速模式降低冷启动延迟，适合高频、低延迟场景；费用结构不同，请按需选择 | ⚠️ 推荐明确指定 |
| **调用约束** | `ReAct 最大轮次`（1–50） | 控制单次请求中工具调用总次数上限，防止无限循环；超限后模型将终止调用并生成终答 | ✅（智能体中建议设为 5–10） |

## 面向开发者，简洁实用

- **快速上手三步走**：  
  1️⃣ **开通**：前往 [MCP 广场](https://bailian.console.aliyun.com/?tab=mcp#/mcp-market)，点击服务卡片 → “立即开通”（试用版免配 Key）；  
  2️⃣ **集成**：智能体中直接添加已开通服务；工作流中拖入 MCP 节点并绑定工具 ID；外部项目安装 `pip install mcp openai`，用 `streamablehttp_client` 连接；  
  3️⃣ **调试**：务必使用控制台“测试工具”验证连通性、参数解析与响应格式——这是避免 `130040`（描述缺失）、`130022`（Object 子属性为空）等常见错误的关键步骤。

- **避坑提示**：  
  - 自定义 MCP 服务运行于函数计算（FC），无固定出口 IP，访问 RDS/VPC 内资源需配置白名单或 VPC 打通；  
  - `GET` 方法不支持 `Object` 类型入参；`Object` 类型下所有子字段必须显式填写（不可为空）；  
  - 工具名称 ≤20 字符，且仅支持 ASCII 字母、数字、下划线；  
  - 外部调用时，`mcp_url` 中的 `{service-id}` 为控制台服务详情页显示的唯一 ID，非服务名称。

- **最佳实践**：  
  ✅ 优先选用 `streamableHttp` 协议（稳定、兼容生态、支持完整 OpenAI tool schema）；  
  ✅ 敏感参数一律走 KMS，杜绝硬编码；  
  ✅ 工作流中 MCP 节点的输入参数，尽量通过上游节点的变量引用传递，而非静态写死；  
  ✅ 智能体上线前，在控制台开启“展示回答来源”，验证工具调用是否真实生效并被正确引用。
