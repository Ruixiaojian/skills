# 百炼文档知识库

> [English →](README.md)

**阿里云百炼**平台的技术文档知识库 — 让 Agent 即时查阅模型规格、API 参考、错误码、定价、SDK 用法和平台指南。

## 功能简介

本技能提供结构化的离线优先知识库，Agent 通过读取其中的文件来回答百炼相关问题：

1. **模型规格** — 上下文窗口、QPM 限流、定价、每个基础模型的调用示例
2. **API 参考** — 请求/响应格式、参数说明、错误码
3. **平台指南** — 智能体、RAG、知识库、记忆、插件、多模态能力
4. **对比分析** — 同类模型或方案的结构化对比

## 适用场景

- 查询某个模型的规格、定价或限流
- 查看 API 参数、错误码、请求格式
- 了解百炼功能（RAG、智能体、知识库、记忆、插件）
- 了解 SDK / OpenAI 兼容接口用法
- 对比模型或能力
- Token 计费、免费额度等问题

**不适用：**
- 其他云厂商（OpenAI、Anthropic、Google）
- 通用编程 / 框架问题
- `bl` CLI 命令用法 → 使用 `bailian-cli` 技能
- 非百炼的阿里云产品（OSS、ECS、RDS）

## 目录结构

| 目录 | 内容 | 可信度 |
|------|------|--------|
| `models/` | 模型市场结构化数据（来自 console 网关） | 最高 — 最新最准 |
| `raw/` | 官方文档（爬取自 help.aliyun.com） | 高 — 权威来源 |
| `wiki/` | LLM 合成的 Wiki（主题页/概念页/对比页） | 中 — 可能滞后 |

**可信度优先级：** `models/` > `raw/` > `wiki/`

## 查找方式

| 问题类型 | 从这里开始 |
|----------|-----------|
| 模型规格、定价、QPM、上下文窗口 | `models/index.md` |
| API 文档、指南、概念 | `wiki/index.md` |
| 某个主题的深入了解 | 从 wiki 页面链接跳转到 `raw/` 源文件 |

## 前置要求

本技能依赖阿里云百炼 CLI（`bl`）。在使用本技能前，请先检查 `bl` 是否已安装：

```bash
bl --version
```

如果未安装或命令不存在，请阅读以下安装文档并按照说明完成安装：

> https://bailian.aliyun.com/cli/install.md
